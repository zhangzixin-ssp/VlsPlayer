I. Overview

VlsPlayer is a video subtitle player built specifically for language learning. It brings together audio/video playback, subtitle editing and proofreading, automatic timeline alignment, subtitle notes, shadowing, dictation, and AI-assisted analysis in one place. Based on SRT subtitles, it works with either the MPV or VLC playback engine and ships with a rich set of batch tools for SRT files. On ordinary PCs, it runs NVIDIA's Parakeet-TDT-0.6B-V2 model for fast and accurate speech recognition with automatic timeline alignment — a capable companion for learning languages through TV series and films, as well as for subtitle creation and proofreading.

Key Features:

  • A carefully designed, friendly interface with polished details — suited to long-term learners.
  • Notes, dictation, shadowing, and AI-assisted analysis — the essentials every learner needs.
  • Audio waveform visualization for intuitive timeline positioning and free selection of playback ranges.
  • Multiple playback modes: single-sentence playback, role-play dialogue, selection playback, and variable-speed playback.
  • Automatic Speech Recognition (ASR) for pronunciation-similarity scoring against subtitles, subtitle generation, and precise timeline calibration.
  • Recording and shadowing — record your own pronunciation and compare it with the original audio.
  • Optional background-noise mixing.
  • AI assistance: one-click activation of AI for sentence analysis or translation.
  • Annotate and tag subtitles, then filter and screen by tag or note.
  • SRT Toolbox: batch operations including merge, split, export, convert, and video segmentation.
  • TXT Toolbox: convert TXT to SRT for note-taking.
  • ASR Toolbox: generate high-accuracy SRT from scratch, or recalibrate the timeline of an existing SRT.
  • Export Anki cards, supporting both the Sentences and Series deck formats.
  • Multiple UI themes, fully customizable.

II. Interface Layout

  • Top toolbar: shortcut buttons for SRT folder management, playback control, subtitle editing, the toolbox, and settings.
  • Left file list: an SRT folder path dropdown on top; a list of SRT files in the current folder below. Click to load.
  • Subtitle table (upper-center): index, start time, end time, main subtitle text, secondary subtitle text, and tag bits of the current subtitle file. Click a row to jump the playback position.
  • Video area (lower-left center): displays the video with the same name as the subtitle. Fullscreen playback supported.
  • Subtitle editing area (lower-right center): shows the main subtitle of the current sentence (upper edit box) and notes/annotations/proofreading content (lower area). Text is directly editable.
  • Tag area (below the note editing area): seven colored tag bits. Click to toggle on/off for classifying sentences.
  • Recording waveform area: displays the recording waveform, with selection playback.
  • Bottom waveform editor: displays the audio waveform. Click to position, drag to select a playback range, add or delete subtitles, and fine-tune the timeline by hand.

III. Quick Start

Unlike a general media player, this software is designed specifically for language learners. Before using it, you must have an SRT subtitle file and a video file with the same name.

Unless your subtitles are of exceptionally high quality, we strongly recommend using this software's ASR Toolbox (large model) to generate a high-quality SRT, and using the original or official subtitles as a proofreading reference. Alternatively, use the ASR Toolbox to automatically recalibrate the timeline of your existing subtitles. You can also download SRT subtitles from subtitle websites — or subtitles in other formats and convert them to SRT — as a proofreading reference. Or extract subtitles from the video: many MKV files carry embedded text subtitles that can be exported with ffmpeg.

SRT files and video files must share the same name. Usually, you will need to organize and rename your video and subtitle files; many tools can do this for you. (Note: if you plan to export to Anki, we strongly recommend naming files in the form XXX_nn or YYY_SmmEnn, where mm is the season and nn the episode, numbered from 01 upward.)

The software ships with two playback engines, MPV and VLC. If one performs poorly, switch to the other. MPV is generally recommended. Note also that when using Bluetooth headphones, Bluetooth latency will affect the play/pause position in single-sentence mode.

Regarding ASR models: Win32 can only use the small and medium models, while the large model is only available on Win64. The large model is far more accurate, but the first load typically takes a dozen seconds or so. In addition, you must install Python and the following modules:
pip install numpy
pip install websockets

Notes, waveforms, and dictation files are generated in the same folder as the SRT file, under the same name. When you first open an SRT file, waveform generation usually takes a few seconds. Recording files are saved in the software's Record folder and can be large; delete them promptly when no longer needed.

Each subtitle supports seven color tags. Make good use of these tags — you can filter at any time by tag or note. Be aware that in filter mode, editing is limited: only the current row's subtitle content can be partially edited.

You can export Anki notes from the SRT Toolbox. You need to install the AnkiConnect add-on. Two carefully crafted Anki templates are built in: one for single-sentence notes, and one full series player.

About Anki media files: on Windows, Anki can only play video in the WebM format, while on other platforms Anki supports MP4. Because Anki cannot sync files larger than 100 MB, we recommend turning off Anki's media sync. Use ffmpeg to batch-convert media files, and try to keep each file under 100 MB. For AnkiMobile, you can create a small helper deck (for example, a deck named FriendsResource) and put contents like [sound:xx_s01e01.mp4][sound:xxx_s01e02.mp4]... on the front or back of a card, then export it — this packs the media files in one go. You can then import the resulting apkg into AnkiMobile. If FriendsResource already exists in AnkiMobile, delete it first, then import; the same approach lets you overwrite an individual media file.

On AnkiMobile, for both Anki templates, we recommend turning off the Top Bar and setting the Top Left tap to return to Decks — the layout looks better that way. In the Anki Series player, never tap Answer. If you tap it by mistake, Undo immediately.

Feel free to explore the other built-in features boldly — there's no need to list them all here.

VlsPlayer

一、ソフトウェア概要

VlsPlayer は、語学学習のために設計された動画字幕プレーヤーです。音声・動画の再生、字幕の編集、字幕校正、タイムラインの自動校正、字幕ノート、シャドーイング、ディクテーション、AI 支援など、多彩な機能を一つに統合しています。VlsPlayer は SRT 字幕を基盤とし、MPV または VLC の再生エンジンと組み合わせて使用できます。SRT 字幕の一括処理ツールを豊富に備え、一般的な PC 上で NVIDIA の Parakeet-TDT-0.6B-V2 モデルを用いて、高速かつ高精度な音声認識と自動タイムライン調整を実現します。ドラマや映画を通じた語学学習、および字幕の作成・校正における強力な相棒です。

主な機能：

  • 丁寧に設計された親しみやすいインターフェースと、細部まで磨き上げられた操作性。長期的な学習に最適です。
  • 学習者に必須のノート、ディクテーション、シャドーイング、AI 支援分析機能を提供します。
  • 音声波形の可視化により、文中のタイムラインを直感的に定位し、再生区間を自由に選択できます。
  • 多彩な再生モード：単文再生、キャラクター対話、選択区間再生、可変速再生。
  • 自動音声認識（ASR）により、字幕との発音類似度をスコアリング、字幕生成、タイムラインの精密校正が可能です。
  • 録音シャドーイング機能。自分の発音を録音し、原音と比較できます。
  • 背景ノイズのミキシングに対応。
  • AI 支援：ワンクリックで AI を呼び出し、文の分析や翻訳を行えます。
  • 字幕への注釈・マーク付けに対応し、マークやノートによる絞り込み・フィルタリングが可能です。
  • SRT ツールボックス：結合、分割、エクスポート、変換、動画分割などの一括操作。
  • TXT ツールボックス：TXT を SRT 形式に変換し、ノートとして使用できます。
  • ASR ツールボックス：高精度な SRT を自動生成、または現在の SRT のタイムラインを校正します。
  • Anki カードのエクスポートに対応。Sentences および Series デッキ形式をサポートします。
  • 多彩なインターフェーススタイルとカスタマイズ機能。

二、インターフェース構成

  • 上部ツールバー：SRT フォルダ管理、再生制御、字幕編集、ツールボックス、設定など、すべてのショートカットボタンを配置しています。
  • 左側ファイルリスト：上部は SRT フォルダパスのドロップダウン。下部は現在のフォルダ内の SRT 字幕ファイル一覧で、クリックで読み込みます。
  • 字幕テーブル（中央上部）：現在の字幕ファイルの番号、開始時刻、終了時刻、主字幕テキスト、副字幕テキスト、マークビットを表示します。行をクリックすると再生位置を切り替えます。
  • 動画再生エリア（中央左下）：字幕と同名の動画ファイルの映像を表示します。フルスクリーン再生に対応。
  • 字幕編集エリア（中央右下）：現在の文の主字幕（上部の編集ボックス）と、ノート・注釈・校正内容（下部エリア）を表示します。テキストは直接編集できます。
  • マークエリア（ノート編集エリアの下）：7 色のカラーマークビット。クリックでオン／オフを切り替え、文の分類マークとして使用します。
  • 録音波形エリア：録音波形を表示し、選択区間の再生に対応しています。
  • 下部波形エディター：音声波形を表示。クリックで定位、ドラッグで再生範囲を選択、字幕の追加・削除、タイムラインの直感的な精密調整が可能です。

三、クイックスタート

一般的なメディアプレーヤーとは異なり、本ソフトウェアは語学学習者専用に設計されています。使用する前に、SRT 字幕と同名の動画ファイルが必要です。

字幕の品質が極めて高い場合を除き、本ソフトウェアの ASR ツールボックス（大モデル）を使って高品質な SRT 字幕を生成し、元の字幕または公式字幕を校正の参考にすることを強くお勧めします。あるいは、ASR ツールボックスで既存字幕のタイムラインを自動校正することもできます。字幕サイトから SRT 字幕、または他形式の字幕をダウンロードして SRT に変換し、校正の参考にすることもできます。動画から字幕を抽出する方法もあります（例：多くの MKV 形式にはテキスト字幕が埋め込まれており、ffmpeg で抽出できます）。

SRT ファイルと動画ファイルは同名である必要があります。通常、動画ファイルと字幕ファイルを整理し、リネームする必要があります。これを支援するツールは多数あります。（注：Anki へエクスポートする場合は、XXX_nn または YYY_SmmEnn という形式で命名することを強くお勧めします。mm は Season、nn は Episode を表し、01 から順に番号を付けます。）

ソフトウェアには MPV と VLC の 2 つの再生エンジンが内蔵されています。一方の動作が良くない場合は、もう一方に切り替えてください。MPV エンジンの使用を推奨します。また、Bluetooth イヤホンを使用する場合、単文モードでは Bluetooth の遅延が音声の再生・一時停止位置に影響することに注意してください。

ASR モデルについて：Win32 では通常、中・小モデルのみが使用可能で、大モデルは Win64 専用です。大モデルは非常に高精度ですが、初回の読み込みには通常十数秒かかります。さらに、Python をインストールし、以下のモジュールを導入する必要があります：
pip install numpy
pip install websockets

ノート、波形、ディクテーションは、SRT ファイルと同じフォルダに同名のファイルとして生成されます。SRT を初めて開く際は、波形の生成に通常数秒かかります。録音ファイルは本ソフトウェアの Record フォルダに保存され、サイズが大きくなることがあります。不要になったら適時削除してください。

各字幕は 7 色のマークに対応しています。これらのマークを有効に活用し、マークやノートでいつでも絞り込みを行えます。なお、フィルターモードでは編集機能が制限され、現在の行の字幕内容のみ部分的に編集できます。

AI ツールや辞書について、内蔵のものが適さない場合は、INI ファイルに独自に追加できます。INI ファイルを誤って壊してしまった場合は、削除すればシステムが自動的に新しいものを生成します。

ディクテーション時には、ディクテーションエリアの下にあるボタンをクリックすると、字幕テキストと照合できます。

「SRT ツールボックス」から Anki ノートをエクスポートできます。AnkiConnect アドオンのインストールが必要です。丁寧に作り込まれた 2 種類の Anki テンプレート（単文ノート用と、完全なシリーズプレーヤー用）が内蔵されています。

Anki のメディアファイルについて：Anki の Windows 版では動画は webm 形式のみ再生可能で、他のプラットフォームでは mp4 に対応しています。Anki は 100M を超えるファイルの同期をサポートしていないため、Anki のメディア同期機能をオフにすることを推奨します。メディアファイルの一括変換には ffmpeg を使用し、1 ファイルあたり 100M 以下に抑えることをお勧めします。AnkiMobile の場合は、補助的な簡単なカード（例えば FriendsResource という名前のデッキ）を作成し、カードの表か裏に [sound:xx_s01e01.mp4][sound:xxx_s01e02.mp4]... のように記述してエクスポートすると、メディアファイルを一括でパッケージ化できます。その後、この apkg を AnkiMobile にインポートします。FriendsResource が既に AnkiMobile に存在する場合は、一度削除してからインポートしてください。同様に、特定のメディアファイルを上書きしたい場合もこの方法が使えます。

AnkiMobile では、これら 2 種類の Anki テンプレートを見栄え良くするために、上部ツールバー（Top Bar）をオフにし、左上（Top Left）のタップをデッキに戻る（Decks）に設定することをお勧めします。Anki Series プレーヤーでは、Answer を絶対にタップしないでください。誤ってタップした場合は、すぐに Undo してください。

その他の内蔵機能については、ぜひ大胆に試してみてください。ここでは割愛します。

四、ショートカット一覧

  • Ctrl + P：再生／一時停止
  • Ctrl + S：字幕ファイルを保存
  • Ctrl + N：新しい字幕行を挿入
  • Ctrl + L：現在の字幕行を削除
  • Ctrl + M：選択した字幕行を結合
  • Ctrl + Enter：フルスクリーン／フルスクリーン解除
  • Esc：フルスクリーン解除（フルスクリーンモード時）
