1. 这是什么

笔记卡是一张单句卡片。每张卡包含一段视频或音频、一句原文、一句译文、一条备注。

和 VlsPlayer Series 卡的区别：

对比项Series 卡Notes 卡（本卡）
单元一整季/整单元一句话
字幕区可滚动列表固定显示当前句
播放范围整集，可切换单元单句时间区间
典型用途刷剧、连续跟读精听、生词复习
正面/背面整个播放器在正面正面先播放，背面显示笔记

1.1 主要特征

  • 卡片正面自动播放目标句子（可关闭）
  • 隐藏译文，让学习者先听后看
  • 循环重复播放，设置次数与间隔
  • 拖动时间轴微调播放区间
  • 没有视频文件时自动降级为 TTS 朗读
  • 背面显示备注（Remark）与来源（From）
  • 控制条可拖动到任意位置
  • 选项保存在 localStorage 中

2. 卡片字段

2.1 五个字段

字段作用
Timeline媒体源 + 时间区间，格式见第 14 节
SrtText1字幕一（通常英文原文），可含 <f1>~<f7> 彩色标记
SrtText2字幕二（通常中文译文）
SrtNote备注内容，可多行
From来源标签，例如"某剧 S05E08 12:34"

2.2 制作来源

由桌面版 VlsPlayer 的"导出到笔记牌组"功能生成。每选一条字幕就生成一张卡片。也可以由 SRT 工具箱的 Anki 导出功能批量生成。

2.3 学习流程

  1. 显示正面：自动播放该句音频，字幕显示
  2. 你判断是否听懂
  3. 点击"显示答案"，翻到背面
  4. 背面显示备注和来源
  5. 选择"重来/困难/良好/简单"

3. 界面布局

3.1 三个区域

区域内容
顶部媒体区视频或音频（无视频时仅展示封面，或完全隐藏）
中部文本区
  • 关键短语（Key）：从 <fN> 标记提取
  • 字幕一（Text1）：主字幕
  • 字幕二（Text2）：译文，可选隐藏
  • 备注（Note）：仅背面显示
  • 来源（From）：仅背面显示，右下角
底部控制条可拖动的按钮 + 时间轴面板

3.2 字幕彩色标记

字幕一中的 <f1> 到 <f7> 标记会显示为不同颜色（与 Series 卡一致）：

标记颜色
f1红
f2绿
f3蓝
f4黄
f5洋红
f6橙
f7暗红

如果卡片有视频，这些标记会额外提取成"关键短语"列表显示在字幕上方。

3.3 备注格式

备注按行显示，每行前有一个圆点符号 •。空行自动忽略。

4. 控制条按钮

控制条是一个可拖动的悬浮面板，包含 7 个按钮和一条时间轴。

4.1 七个按钮

按钮图标功能
牌组▣返回牌组（仅 iOS/Android，单击无效，需配合手势）
播放速度菜单📊弹出速度选择菜单
播放 / 暂停▶ / ⏸主播放按钮
重播↺从起点重新播放
查询🔍词典/AI 查询
倍速切换0.5 / 1.0快捷切换播放速度
选项⚙打开选项面板

4.2 播放按钮图标变化

图标状态
▶已暂停，可播放
⏸正在播放
⏸ 旋转 90°等待中（在重复间隔内）

4.3 点击非按钮区域播放/暂停

在控制条以外的地方点击（按钮和时间轴滑块除外），会自动触发播放/暂停。这是为了方便快速操作。

5. 时间轴与拖动条

5.1 元素说明

元素颜色含义
◁ / ▷ 按钮黄微调起止时间各 0.5 秒
水平细线暗黄时间轴基准线
两个黄点黄原始起止时间（不可拖动）
两个黄滑块黄当前起止时间（可拖动）
白滑块灰白播放位置指示器（不可拖动）

5.2 拖动滑块

  • 拖动左侧滑块调整起始时间
  • 拖动右侧滑块调整结束时间
  • 拖动时立即生效，不需要确认
  • 拖动结束后自动保存到选项

5.3 微调按钮

  • 点击 ◁：起始时间后退 0.5 秒
  • 点击 ▷：结束时间前进 0.5 秒
  • 长按：没有效果，只能单击

5.4 时间轴自动缩放

时间轴总是以"原始起止时间"为中心，向两侧各留出 1/6 的余量。所以即使微调过起止时间，原始位置仍可以看到。这个缩放是自动的，不需要手动设置。

6. 播放与重复机制

6.1 播放流程

  1. 加载媒体文件
  2. 定位到起始时间
  3. 播放到结束时间
  4. 暂停，等待重复间隔
  5. 重复次数未到 → 回到起点继续
  6. 重复次数到了 → 停止，等待手动操作

6.2 重复次数

值行为
1 到 9固定次数
10无限循环，直到手动停止

6.3 重复间隔

值含义
1 到 30固定秒数
31句子时长（本句播放时间）

间隔会自动除以播放速度，所以加速播放时间隔也相应缩短。

6.4 重播按钮

点击 ↺ 按钮：

  • 立即停止当前播放
  • 把重复计数重置为 0
  • 从起点重新开始
  • 临时的重复次数被设为"无限"（不影响选项里的设置）

6.5 播放速度

  • 通过 0.5 / 1.0 按钮在 0.5x 和 1.0x 之间切换
  • 通过 📊 按钮弹出菜单选择 0.50x 到 2.00x
  • 速度调整立即作用于当前播放

7. 正反面显示逻辑

7.1 正面显示

  • 关键短语（若有彩色标记）
  • 字幕一（原文）
  • 字幕二（译文）—— 取决于选项"打开卡片时显示译文"

字幕二默认隐藏，让学习者先听原文。

7.2 背面显示

  • 关键短语
  • 字幕一
  • 字幕二（始终显示）
  • 备注（Note）
  • 来源（From）

7.3 正面自动播放

选项"打开卡片时自动播放"开启时（默认开启）：

  • 正面打开后，媒体加载完成即自动播放
  • 背面打开时不自动播放

7.4 关键短语的提取

字幕一里所有 <fN> 包裹的内容会被提取出来，逐行显示在字幕上方。例如：

SrtText1: "I <f1>couldn't agree more</f1> with you."

会显示为：

couldn't agree more
I couldn't agree more with you.

这是为了让学习者在看整句之前，先关注重点短语。

8. TTS 语音朗读

8.1 触发条件

当 Timeline 字段的扩展名为 NaN，或媒体文件缺失时，程序自动切换到 TTS 模式，用系统语音合成朗读字幕一。

8.2 语音选择

平台偏好语音
iOS / iPadOSSamantha（美式女声）
Windows / macOSDavid（美式男声）
Android任意美式英语语音

如果偏好语音不存在，则选第一个 en-US 语音，再次选任意 en 语音。

8.3 TTS 与媒体播放的差异

  • TTS 模式没有时间轴拖动功能（时间轴隐藏）
  • TTS 的重复和间隔逻辑与媒体播放一致
  • 速度按播放速度设置（0.1 到 10 之间）
  • 音量固定为 0.8

8.4 TTS 播放控制

  • 播放/暂停按钮同样适用于 TTS
  • 重播按钮会停止当前 TTS 并从头朗读
  • 切换卡片时自动停止 TTS

9. 词典与 AI 查询

9.1 使用方式

  1. 选中字幕中要查询的文字
  2. 点击 🔍 按钮

如果没有选中任何文字，默认查询字幕一的全部内容。

9.2 查询分流

条件行为
选中文本不含空格（单词）打开欧路词典
选中文本含空格（短语）调用 AI 分析

9.3 词典 URL

eudic://dict/选中文字

9.4 AI 分析

  • Windows：把 prompt + 文本复制到剪贴板，用户自行粘贴到 AI
  • iPhone / Android：调用豆包 App 直接发送

Prompt 固定为："请严格直译并分析其中短语及知识点："

9.5 选中文字的获取

  • 桌面版：在字幕区用鼠标选中，释放时记录
  • iOS / Android：用手指选中，点击查询按钮时读取

iOS 因为 touch 事件的特殊性，选中文字需要额外记录。

10. 选项面板

点击 ⚙ 打开。选项面板铺满整个屏幕，关闭后恢复控制条。

显示视频关视频是否显示画面。关闭时只播放音频

10.2 三个滑块

选项范围默认

10.3 颜色主题

五种颜色可选：黄、绿、橙、粉、白。见下一节。

10.4 关闭选项面板

点击左上角的 "Close" 或再次点击 ⚙。

12. 控制条拖动与定位

12.1 拖动方式

  • 长按按钮栏任意空白处（不是按钮本身）即可拖动
  • 拖动时页面滚动被禁止
  • 松手后自动保存新位置

12.2 位置边界

控制条不会超出屏幕边界。如果被拖出屏幕，下一次加载时会自动回到屏幕内。

12.3 位置持久化

控制条的位置保存在选项字符串的最后两个字段，下次打开卡片时恢复。

12.4 初始位置

首次打开时控制条位于屏幕水平居中、垂直方向大约 60% 位置（使用 top: 60vh）。

13. 选项持久化

13.1 保存位置

保存在浏览器的 localStorage，键名格式：

卡片ID_vp_notes_opts_1

卡片 ID 从 Timeline 字段的第一段取得。

13.2 保存内容

共 10 个字段，用 | 分隔：

序字段范围
0自动播放0 / 1
1先显示译文0 / 1
2显示视频0 / 1
3重复次数1 ~ 10
4重复间隔1 ~ 31
5视频高度32 ~ 320
6播放速度50 ~ 300（即 0.50x ~ 3.00x）
7颜色主题0 ~ 4
8控制条 X 坐标像素
9控制条 Y 坐标像素

13.3 保存时机

  • 关闭选项面板时
  • 调整播放速度时
  • 拖动控制条结束时
  • 调整时间轴滑块结束时

13.4 跨设备同步

localStorage 是本地的。如果卡片在多个设备上使用，选项需要分别设置。Anki 同步不会同步 localStorage。

14. Timeline 字段格式

14.1 基本格式

媒体前缀,季号,集号,标题,扩展名,-开始时间-结束时间

14.2 示例

示例解读
atomic_habits,,01,,.mp3-0029120-0032325atomic_habits_01.mp3，从 2.912s 到 3.2325s
cwe,,01,,-0005743-0006807-0006829-0007421cwe_01，多段区间
sf,s05,e08,某剧,.mp4-0012345-0023456sf_s05e08.mp4，从 1.2345s 到 2.3456s

14.3 字段说明

部分说明
媒体前缀媒体文件名前缀
季号可为空。为空时文件名格式为 前缀_集号
集号单元编号，如 01、053
标题可选。有值时用于 From 字段
扩展名媒体文件扩展名。NaN 表示纯 TTS 模式
时间区间多个 -时间，单位为毫秒。程序取第一个和最后一个

14.4 文件名生成规则

如果季号为空：

前缀_集号.扩展名

如果季号非空：

前缀_s季号e集号.扩展名

14.5 扩展名缺省

扩展名为空、.mp4 或 webm 时：

  • Windows 使用 .webm
  • 其他平台使用 .mp4

这解决了 Anki 同步时不同平台视频编码兼容问题。

14.6 多区间播放

一个 Timeline 可以包含多个时间点：

前缀,,01,,-0005743-0006807-0006829-0007421-0007710-0008596

程序会取第一个值和最后一个值，中间部分作为播放范围。用于把多个连续片段合并为一张卡片。

15. 平台差异

15.1 Windows

  • 字体：Segoe UI + STXihei，18px，左右各 12px 边距
  • 按钮栏高度 32 像素（略小）
  • 视频编码使用 .webm
  • AI 分析是复制到剪贴板，不自动跳转
  • 不支持录音

15.2 macOS

  • 使用默认系统字体
  • 视频编码使用 .mp4
  • AI 分析调用豆包 App

15.3 iOS / iPadOS

  • 控制条和菜单被移到 HTML 根节点，避免渲染问题
  • 使用 Pointer Events 而不是 Mouse Events
  • 字幕选中需要 touch 结束事件记录
  • 视频编码使用 .mp4
  • 支持录音

15.4 Android

  • 支持录音
  • 视频编码使用 .mp4
  • 字体大小略大

15.5 时间精度微调

非桌面平台会有一个 0.12 秒的微调偏移，用于补偿 iOS/Android 视频播放的延迟。桌面平台偏移为 0。

16. 常见问题

Q1：卡片打开后一片黑，只有一个控制条
检查：
  • Timeline 字段是否有效（逗号数量正确、有时间区间）
  • 媒体文件是否放在 collection.media 目录下
  • 扩展名是否匹配当前平台（Windows 用 .webm，其他用 .mp4）
Q2：卡片没有声音
  • 检查 Timeline 里的时间区间是否超出媒体实际长度
  • Windows 下 .mp4 无法播放，需要转成 .webm 或纯音频格式
  • 如果扩展名是 NaN，则使用系统 TTS，检查系统是否有可用的英语语音
Q3：视频画面显示不出来
在选项里打开"显示视频"开关。默认是关闭的，只播放音频。
Q4：正面看不到译文
这是设计行为。译文本应在背面显示。如果想在正面就显示，在选项里打开"先显示译文"。
Q5：控制条拖到屏幕外找不到了
刷新卡片。程序会在下一次加载时把控制条自动放回屏幕内。也可以清除 localStorage 恢复默认位置。
Q6：选项不能保存
  • 检查浏览器是否允许 localStorage（隐私模式会禁用）
  • 检查卡片 ID（Timeline 字段第一段）是否稳定
  • 清除浏览器缓存会丢失选项
Q7：点了查询按钮没反应
  • 检查设备是否安装了欧路词典（iOS）或豆包 App（Android/iOS）
  • Windows 下是复制到剪贴板，需要用户手动粘贴
  • 检查选中文字是否为空
Q8：TTS 朗读语言不对
TTS 固定使用英语朗读。如果 SrtText1 是其他语言，效果会很差。TTS 模式只建议用于英语内容。
Q9：时间轴滑块拖不动
  • 检查时间轴是否可见（TTS 模式下时间轴隐藏）
  • 检查触摸点是否准确落在滑块上（滑块比较小）
  • 尝试重新打开卡片
Q10：切换到下一张卡时声音还在响
正常情况不会。程序在加载新卡片时会自动停止上一张。如果出现这种情况，检查是否有其他扩展或浏览器行为干扰。刷新页面即可。
Q11：重复播放只播一次就停了
  • 检查"重复次数"选项是否为 1
  • 检查"重复间隔"是否设置得太长（31 = 句子时长）
  • 检查是否手动点过播放按钮（会重置计数）
Q12：时间轴上的黄点和滑块位置很奇怪
黄点代表原始起止时间，滑块代表你调整后的起止时间。如果黄点和滑块重合，说明没调整过。如果偏移很大，说明你大幅调整过时间范围。
Q13：关键短语区显示的内容不对
关键短语从 SrtText1 里的 <f1> 到 <f7> 标记提取。如果没有标记，只显示整句。如果想显示关键短语，需要在桌面版 VlsPlayer 里先用彩色标记标出短语。
Q14：控制条会挡住字幕
拖动控制条到屏幕底部或顶部。或者调整视频高度，为控制条留出空间。
