1. Program Overview

SRT Toolbox (VlsSrtTools) is a batch processing tool for SRT subtitles, used to perform common organization, conversion, and export tasks on a set of subtitle files.

Main capabilities:

  • Convert between subtitles and plain text (export, refill)
  • Merge, split, swap, and delete subtitle content
  • Simplified/Traditional Chinese conversion
  • Timeline extension
  • Generate text for AI translation / translation checking
  • Split video by subtitle timeline (generate ffmpeg batch files)
  • Export Anki player text, series cards, and sentence note cards

The program supports batch processing of multiple files, and all modifying operations automatically back up the original files.

3. Left Panel: Directory and Files

3.1 SRT Directory

  • Use the drop-down box to select a saved SRT directory.
  • Green + button: add an SRT directory.
  • Red − button: remove the current SRT directory.
  • Include subdirectories?: if checked, scanning includes subdirectories.

The program remembers each directory's configuration (including subtitle line type, Anki parameters, etc.) and restores it automatically when switching directories.

3.2 SRT File List

  • Lists all .srt files in the current directory.
  • Multi-select supported; batch operations target the selected files.
  • Click a single file to show its content in the right preview area; the status bar shows the subtitle count.
  • The list header shows the total count and the currently selected count.

4. Subtitle Line Types

Each subtitle in an SRT file may have only one line of text, or two lines for original and translation. The program needs to know how to split them into "Subtitle 1" and "Subtitle 2".

OptionSplitting Rule
Auto-detectJudged by language features: English lines go to Subtitle 1, the rest go to Subtitle 2
First line as Subtitle 1The first line of each subtitle goes to Subtitle 1, the rest are merged into Subtitle 2
All lines as Subtitle 1All text is treated as Subtitle 1; Subtitle 2 is left empty
Last line as Subtitle 2The last line of each subtitle goes to Subtitle 2, the rest are merged into Subtitle 1
Odd/even subtitle lines pairedLines 1 and 2 form a pair, lines 3 and 4 form a pair, etc. (default)
This option directly affects the results of all commands, especially operations that only process Subtitle 2, such as "Swap Subtitle 1 and Subtitle 2" and "Simplified/Traditional conversion". Choosing the wrong one will misalign the target of processing.

5. Middle Panel: 17 Commands

The middle is a group of command buttons, 17 commands in total. Hovering the mouse over a button highlights it and shows a tooltip. When hovering over Command 1, the Anki export panel is shown on the right.

The commands are divided into three groups by purpose:

  • Subtitle-text conversion: Commands 1–8
  • Subtitle content operations: Commands 9–15
  • Video splitting: Commands 16–17
Before executing any command, you must first select an SRT directory and select at least one SRT file; otherwise a dialog will prompt you.

6. Subtitle-Text Conversion (Commands 1-8)

1. Export Anki Player Text
This command does not perform the export itself; it displays the Anki settings panel on the right, and the export is done from that panel. See Section 9 for details.
2. Export Subtitle 1 to Text File
Export Subtitle 1 of the selected SRTs line by line as plain text. Each line is in the format line number|content, with line numbers starting from 1 and zero-padded to 4 digits.
Output file: *_1.txt (UTF-8)
Used to hand subtitles to external tools (such as AI or translation software) for modification, then use Command 4 to refill.
3. Export Subtitle 2 to Text File
Same as above, but exports Subtitle 2.
Output file: *_2.txt (UTF-8)
4. Update Subtitle 1 from Text
Read *_1.txt in the same directory and update Subtitle 1 by line number. The text format must be line number|content; only valid line numbers are updated, out-of-range ones are ignored.
Input file: *_1.txt
The original SRT is automatically backed up before processing.
5. Update Subtitle 2 from Text
Same as above, but updates Subtitle 2.
Input file: *_2.txt
6. Generate Text Needed for AI Translation
A Prompt input window pops up; after confirmation, text for AI translation is generated. Content = Prompt + all Subtitle 1 (in line number|content format). The Prompt is saved in the configuration and loaded automatically next time.
Output file: *_t.txt (UTF-8)
The default Prompt requires line-by-line literal translation, strictly forbids splitting or merging lines, and outputs in the format line number|translation. You can modify it yourself.
7. Generate Text Needed for AI Translation Check
A Prompt input window pops up; after confirmation, text for AI translation checking is generated. Content = Prompt + full SRT content (original + translation side by side).
Output file: *_c.txt (UTF-8)
The default Prompt asks the AI to find omissions, mistranslations, and areas for improvement, and to output only the corrected lines.
8. Export Selected SRTs to One Text
Merge all selected SRTs into a single text file. Each file starts with [file name], followed by lines in the format timestamp (MM:SS) Tab Subtitle 1. A blank line separates files.
Output file: _all.txt in the SRT directory (UTF-8)
Used for quickly browsing a whole season's subtitles or doing an overall proofread.

7. Subtitle Content Operations (Commands 9-15)

9. Swap Subtitle 1 and Subtitle 2
Swap the original text and translation of each subtitle.
The original is automatically backed up before processing. If the subtitle line type is set incorrectly, the swap result will be unexpected; check the settings in Section 4 first.
10. Delete Subtitle 2
Clear all Subtitle 2 content, keeping only Subtitle 1.
Suitable for scenarios where only the original text is kept.
11. Merge Sentence Fragments in Subtitles
Automatically detect adjacent subtitle lines that belong to the same sentence and merge them. Merge rules: time takes the union, text is joined with a space, translation is joined with a space. It can recognize abbreviations, unclosed quotes, endings with commas/semicolons, etc.
Used to repair overly fragmented ASR output or manually split subtitles.
12. Split Role Subtitle Lines by -
For each subtitle, split the text at - (space + hyphen) into two lines. Time is allocated proportionally by text length: the first half takes the earlier segment, the second half takes the later segment. If the translation also contains -, it is split in sync.
Used to roughly separate different characters' lines in the same time period before fine-tuning the timeline. If a subtitle does not contain -, it is left unchanged.
13. Extend Timeline
A time input window pops up; extend the start and end times of each subtitle by the specified offset. During extension, overlap with adjacent subtitles is automatically avoided; each side extends at most to the midpoint of the adjacent subtitle.
Used to fix subtitles whose time is too short and whose display duration is insufficient.
14. Convert Subtitle from Simplified to Traditional Chinese
Convert Subtitle 2 from Simplified to Traditional Chinese. Subtitle 1 is unchanged.
Only Subtitle 2 is processed; the conversion uses the system LCMapString and does not affect English subtitles.
15. Convert Subtitle from Traditional to Simplified Chinese
Convert Subtitle 2 from Traditional to Simplified Chinese. Subtitle 1 is unchanged.

8. Video Splitting (Commands 16-17)

16. Split into Multiple Videos by Subtitle
A media type selection window pops up (mp4, mkv, etc.). After confirmation, ffmpeg commands are generated sentence by sentence according to the subtitle timeline and written into a batch file. The media file is assumed to have the same name as the SRT, only with a different extension.
Output file: *_cut.bat
The batch file must be run manually by double-clicking. When running, ffmpeg must be installed and in PATH, or ffmpeg.exe must be in the same directory.
The split command uses -c copy and does not re-encode, so it is extremely fast.
17. Split into Two Subtitles and Videos
A media type + split time window pops up. After confirmation:
  • Split the SRT at the specified time point into *_1.srt and *_2.srt, with the latter's timeline shifted forward as a whole
  • Generate *_cut_2.bat containing two ffmpeg commands, cutting the first half and the second half of the video respectively
Output files: *_1.srt, *_2.srt, *_cut_2.bat
If the specified time point falls in the middle of a subtitle, the program automatically adjusts it to the gap between two adjacent subtitles.
If the time point is outside the subtitle range, that file is skipped.

When the mouse hovers over Command 1, Export Anki Player Text, the Anki export panel is shown on the right.

9.3 Export Content

  • Series deck: all subtitle text of a season, archived into the corresponding field by season
  • Note deck: exports only sentences with notes or format markers, as study cards

9.4 Steps

  1. Select the SRT files to export on the left.
  2. Hover the mouse over Command 1 to show the Anki panel.
  3. Set the deck, title, and season/episode number extraction parameters.
  4. Click the Export button at the top right of the panel.
  5. The log area shows the export result.

9.5 Prerequisites

  • Anki is running
  • AnkiConnect add-on is installed
  • Port 8765 is not occupied
If the note type does not exist, the program will try to create it automatically. If creation fails, the template file is missing; check the lib\anki\ subdirectory in the program directory.

10. FAQ

Q1: It says "Please select an SRT folder"
The SRT directory drop-down at the top is empty. Click the green + button to add a directory.
Q2: It says "Please select an SRT file"
No file is selected in the left file list. Click a file name to select it; multi-select is supported.
Q3: Processing is slow
There are many files, many subtitle lines, or Anki export is enabled. Process in batches.
Q4: Original/translation recognition is wrong
Manually specify the splitting method in Subtitle line type on the left; do not use "Auto-detect".
Q5: After exporting *_1.txt and modifying it, refilling did not take effect
Check whether the text format is line number|content (line number zero-padded to 4 digits, separated by a vertical bar), and whether the line numbers are within the valid range.
Q6: Anki export failed
Check whether Anki is running, whether the AnkiConnect add-on is installed, and whether the deck exists. Export failure does not affect the local SRT files.
Q7: Can changes be undone?
No. Modifying operations automatically back up the original files, and the backups are in the backup\ subdirectory of the same directory. To restore, manually rename the backup file back to the original name.
Q8: The media file cannot be found when splitting video
The program assumes the media file has the same name as the SRT, only with a different extension. If the media file name is different, rename it to match first.
Q9: How do I use the generated batch file?
Copy the batch file to the directory containing the media files and double-click to run. ffmpeg must be installed and in PATH, or ffmpeg.exe must be in the same directory.
Q10: What if the split time point falls in the middle of a subtitle?
The program automatically adjusts the split point to the gap between two adjacent subtitles. If there are no more subtitles after the whole segment, it uses the original time point.

11. Notes

  1. Before batch operations, it is recommended to back up the entire SRT directory.
  2. Modifying operations overwrite the original files; the program automatically backs up to the backup\ subdirectory, but the number of backups is limited.
  3. The AI translation and checking functions only generate text; they do not directly modify the SRT. You need to use the "Update subtitle from text" command to write the results back.
  4. The video splitting function only generates batch files; it does not directly execute ffmpeg. Confirm that paths and file names are correct before running the batch.
  5. Anki-related functions require the AnkiConnect add-on and a running Anki.
  6. The program saves the current directory, parameters, and window position when exiting, and restores them automatically next time.
  7. Simplified/Traditional conversion only processes Subtitle 2. If Subtitle 1 also needs conversion, use "Swap Subtitle 1 and Subtitle 2" first, convert, then swap back.

12. Appendix: File Naming Rules

SuffixMeaning
_1.txtText exported from Subtitle 1
_2.txtText exported from Subtitle 2
_t.txtText used for AI translation
_c.txtText used for AI translation checking
_series.txtAnki series text
_sentence.txtAnki sentence note text
_cut.batBatch file for splitting video sentence by sentence by subtitle
_cut_2.batBatch file for splitting into two videos by time point
_1.srt / _2.srtThe two subtitle files after splitting
_all.txtText merging all selected SRTs

Backup Directory

Before each modifying operation, the original file is automatically backed up to the backup\ subdirectory of the same directory, with a timestamped file name, for example:

Subtitle directory\backup\SomeSeries_20240101_1200.srt
