1. 程式簡介

語音辨識工具箱用於處理影片/音訊字幕，提供兩種工作模式：

模式作用輸出位置
ASR 產生 SRT 字幕檔用 ASR 模型辨識語音，產生字幕ASR 資料夾
對齊 SRT 字幕時間軸把已有 ASR 字幕與來源字幕對齊來源資料夾（覆寫原檔案）

程式支援多檔案批次處理，可中途取消。

2. 執行環境

  • Windows 系統
  • 程式目錄下需存在 lib\ffmpeg.exe
  • 使用產生模式時，需已下載對應 ASR 模型
  • ASR 模型分小、中、大三種，越大越準，也越慢

4. 快速開始

4.1 產生 SRT 字幕

  1. 選擇 ASR 產生 SRT 字幕檔
  2. 設定 來源資料夾（媒體檔案所在目錄）
  3. 設定 ASR 資料夾（SRT 輸出目錄）
  4. 在左側清單中選取要處理的媒體檔案（可多選）
  5. 視需要勾選 如果 ASR 產生的 SRT 檔存在，要覆寫嗎?
  6. 點擊 OK
  7. 觀察日誌區，等待處理完成
  8. 到 ASR 資料夾 取同名 .srt 檔

4.2 對齊 SRT 時間軸

  1. 選擇 對齊 SRT 字幕時間軸
  2. 設定 來源資料夾（內含待修正的 .srt）
  3. 設定 ASR 資料夾（內含同名 ASR .srt）
  4. 視需要勾選 在對齊時間軸之前合併句子碎片?
  5. 視需要調整四個對齊參數，或點 預設值
  6. 在左側清單中選擇檔案
  7. 點擊 OK
  8. 完成後，來源資料夾中的 .srt 被更新

5. 參數詳解

時間漂移視窗 (秒)

允許字幕時間戳與音訊之間的最大偏移。預設 30 秒。如果字幕整體偏移較大，可適當調大。

搜尋文字長度

對齊時用於匹配的文字視窗長度。預設 16。越大越穩，但越慢；越小越快，但可能匹配不準。

最小時間間隙 (毫秒)

兩句字幕之間允許的最小間隔。預設 1 毫秒。用於防止字幕在時間軸上重疊。

最大錯誤閾值

匹配時允許的最大錯誤率。預設 0.15。越大越寬鬆，越小越嚴格。

6. 處理流程

6.1 產生模式

  1. 開啟媒體檔案，讀取總時長
  2. 按 120 秒 一段切分
  3. 用 lib\ffmpeg.exe 抽取 16kHz 單聲道 wav
  4. 呼叫 ASR 模型辨識
  5. 非最後一段丟棄最後一句，避免與下一段重疊
  6. 全部完成後，寫入 ASR 資料夾

6.2 對齊模式

  1. 讀取來源 SRT 和 ASR SRT
  2. 如勾選，先合併句子碎片
  3. 按四個參數對齊
  4. 結果寫回來源 SRT

7. 常見問題

Q1：讀取媒體檔案資訊失敗
媒體檔案無法開啟或格式不支援。檢查檔案是否完整、路徑是否含特殊字元。
Q2：沒有 ASR 字幕檔
對齊模式下，ASR 資料夾裡沒有與來源 SRT 同名的檔案。先跑一次產生模式，或確認檔名一致。
Q3：自動辨識語音失敗
模型載入失敗或音訊抽取失敗。檢查模型是否已下載、lib\ffmpeg.exe 是否存在。
Q4：最後幾分鐘沒有結果
可能原因：媒體總時長讀取失敗或被低估；某段辨識失敗導致中斷；最後一段沒有辨識出內容。建議查看日誌最後幾行，確認停在哪一步。
Q5：來源資料夾裡的 SRT 會被覆寫嗎？
對齊模式會覆寫來源 SRT，建議先備份。產生模式下，ASR 資料夾已存在同名 SRT 時，未勾選「覆寫」則跳過。
Q6：可以中途取消嗎？
可以。點取消後當前段結束會停止，已辨識部分不會儲存。
Q7：為什麼檔案清單裡看不到某個檔案？
清單只顯示支援的副檔名。對齊模式只顯示 .srt；產生模式只顯示影片/音訊副檔名。若副檔名不在支援清單內，不會出現。
Q8：修改參數後沒生效？
參數在點擊 OK 時讀取。修改後直接點 OK 即可。若輸入值超出範圍，會彈窗提示並自動糾正。

8. 注意事項

  1. 處理長檔案耗時較長，建議先用短影片測試。
  2. 模型越大越準，也越慢、越吃記憶體。
  3. 暫存 wav 檔案會自動刪除，異常退出可能殘留。
  4. 對齊模式會直接改寫來源目錄中的 .srt，請先備份。
  5. 程式退出時會儲存目前設定，下次啟動自動恢復。
  6. 建議保持 lib\ffmpeg.exe 與程式版本匹配。
