1. 这是什么

这是一张特殊的 Anki 卡片，把整季或整单元的字幕数据装进一张卡里。复习时你不需要一集一集地翻卡片，而是在一张卡片里就能：

  • 看视频并同步显示字幕
  • 逐句跟读、精听、听写
  • 角色扮演：你念一个角色，让播放器念另一个角色
  • 闪播：变速快放整段，快速过一遍
  • 标记收藏句，回头集中复习
  • 录音对比

它和桌面版 VlsPlayer 不是一回事。VlsPlayer 是 Windows 应用程序，这个卡片模板是运行在 Anki 内部的 JavaScript，两边共享相同的字幕文件格式和字幕工具箱。

1.1 主要特征

  • 黑底黄键，为长时间看视频学习设计
  • 按钮面板可拖动、可停靠顶部/底部、可收起为两行
  • 设置全部保存在卡片字段里，或 iOS 端的 localStorage 中
  • 支持桌面、iPhone、iPad、Android、macOS
  • Windows 下需要 Anki 插件 1020366288 提供剪贴板 API

2. 卡片字段与制作

2.1 卡片字段

字段作用
Title剧集标题，由三段组成：主标题、季/章节、集/单元
Media媒体扩展名 + 海报（可选），用 | 分隔
Options选项字符串（仅桌面 Anki 使用，见第 17 节）
Srts_00索引/总览轨道，无字幕，只记录单元数
Srts_01 到 Srts_10最多 10 个频道，每个频道是同一集的多语言/多季字幕
Tags选项也存储在这里（用 base62 编码）

2.2 制作来源

卡片由桌面版 VlsPlayer 的"Anki 播放器文本"导出功能生成，或由 SRT 工具箱的 Anki 导出功能生成。字段内容自动填充，不需要手写。

2.3 加载流程

  1. 显示卡片正面（其实整个播放器就在正面）
  2. 解析 Title 和 Media
  3. 扫描 Srts_01 到 Srts_10，建立频道列表
  4. 读取 Srts_00 里的单元号范围
  5. 加载上次的选项和播放位置
  6. 打开上次所在的频道和单元
  7. 200 毫秒后自动开始播放

3. 界面布局

3.1 三个区域

区域内容
顶部媒体区视频画面。无视频的音频卡片显示一个唱片图标
中部字幕区按行显示字幕，可滚动。每行有颜色圆点表示角色
底部按钮区播放控制和选项入口，可拖动和停靠

3.2 字幕行的视觉编码

颜色行类含义

绿色圆点srt2角色 2
灰色圆点srtN旁白

粉色圆点srtG其他标记

每条字幕行右侧有一个心形图标：空心 ♡ 表示未收藏，实心 ♥ 表示已收藏。点击即可切换。

3.3 字幕内的彩色标记

字幕行内可包含 <f1> 到 <f7> 标记，渲染为不同颜色：

标记颜色
f1红
f2绿
f3蓝
f4黄
f5洋红
f6橙
f7暗红

3.4 时间信息

点一下视频画面，底部会显示：

  • 左侧：当前播放时间（hh:mm:ss）
  • 右侧：总时长
  • 中间：进度条，可拖动定位

5 秒后自动隐藏。

4. 按钮面板

按钮面板有三行，可以收起为两行，也可以拖到窗口顶部或底部。所有设置都保存在卡片选项里，下次打开卡片时自动恢复。

4.1 三行布局

默认三行，从左到右：

行按钮
第一行 － / ＋ 收起/展开   1.0 / 2.0 倍速切换   ⏮ 上一句   ↺ 重播   ⏭ 下一句   AB 播放已选区   🔍 词典/AI
第二行 M 播放模式   0.5 / 1.5 倍速切换   ⬆AB 从屏幕顶行播到当前行   ▶ 播放/暂停   ⬇AB 从当前行播到屏幕底行   ⚡² 从顶部闪播   N 噪音
第三行 📊 播放速度菜单   ♡ 收藏切换   ▶🎤 播放录音   🎤 录音   🌐 显隐译文   ⚡ 闪播   ⚙ 选项

4.2 两行布局

在选项里选"两行按钮"后，布局变为两行，按钮更大、更易点。适合手机竖屏。

4.3 无媒体卡片

当卡片只有音频、或媒体文件缺失时，按钮面板收缩为一行，只保留：

  • 返回牌组
  • 收藏切换
  • 词典/AI
  • 显隐译文
  • 选项

4.4 拖动面板

在按钮面板上长按任意按钮（上下句按钮除外）1.5 秒，进入拖动模式。可以：

  • 拖到窗口底部 → 自动停靠在底部
  • 拖到窗口顶部 → 自动停靠在顶部（按钮会上下翻转）
  • 拖到中间 → 悬浮

4.5 收起/展开

点击 － 或 ＋ 在三行与两行之间切换。展开时，原本"重播"按钮会变成"播放"按钮。

5. 单句模式与时间轴

单句模式下，按钮面板上方会出现一条时间轴，显示当前句的可调整播放范围。

5.1 时间轴元素

元素颜色含义
两个黄点黄色原始播放区间
两个灰色滑块灰当前可调整的起止时间
白色滑块白播放位置指示器
两端短竖线暗黄时间轴的边界装饰
◁ ▷ 按钮黄起止时间各前后微调 0.5 秒

5.2 调整起止时间

  • 拖动左侧灰色滑块调整起始时间
  • 拖动右侧灰色滑块调整结束时间
  • 点击 ◁ 起始时间后退 0.5 秒
  • 点击 ▷ 结束时间前进 0.5 秒

调整后立即生效，下次播放从新位置开始。

5.3 与"扩展时间轴"选项配合

选项里的"扩展时间轴"会以毫秒为单位，把每条字幕的起止时间向两侧各扩展一点，避免字幕边界太紧导致的声音截断。扩展量不会超过相邻字幕间距的一半。

6. 播放模式

点击 M 按钮弹出菜单，选择播放模式。当前模式字母会显示在按钮上。

6.1 五种模式

按钮模式行为
M普通模式顺序播放整段，自动滚动字幕
Ms单句模式逐句播放，每句结束按重复设置处理
Mo扮演奇数行播放到奇数行（srt1）静音，你念
Me扮演偶数行播放到偶数行（srt2）静音，你念
Ma扮演全部行全部静音，你念

6.2 模式切换的影响

  • 在普通/单句模式与扮演模式之间切换时，会重新加载当前单元
  • 在其他情况下，只重新选中当前行，不重新加载
  • 单句模式下时间轴可见，其他模式隐藏

7. 循环模式与频道/单元

7.1 频道与单元

  • 一张卡片最多包含 10 个频道（对应 Srts_01 到 Srts_10）
  • 每个频道有多个单元（对应集数或章节）
  • 当前播放的单元显示在字幕区顶部

7.2 切换频道/单元

在选项面板底部有频道和单元选择器：

  • 左侧是频道列表（若只有一个频道，列表自动隐藏）
  • 右侧是单元网格，点选即可切换

切换后自动跳转到该单元并从头播放。

7.3 循环模式

决定播放到单元末尾时的行为：

模式行为
当前单元播完后回到本单元开头
当前频道播完后跳到下一单元，频道末尾后回到本频道开头
所有内容跨频道连续播放，到末尾回到第一个频道

在选项面板中选择循环模式。

8. 跟读与角色扮演

8.1 角色判定

字幕的角色由行内标记推断：

标记角色
[n]旁白（不被扮演）
[t]歌词/字幕组（不被扮演）
[g]其他（不被扮演）
[a]延续上一行角色
[s]新场景开始
[p]段落分隔
无标记交替 srt1 / srt2

8.2 扮演流程

选好扮演模式（奇数/偶数/全部）后，播放时：

  1. 播放到你要念的行 → 自动暂停并静音 → 该行加 speaking 高亮
  2. 你念完后再次点击播放 → 从该行结束处继续
  3. 若选项里开启了"扮演后重播原声"，会倒回该行开始位置，播放原声
  4. 原声播放完毕后继续下一句

8.3 跳过空白区

"扮演时跳过空白区时长"选项：当两句之间的静音间隔超过设定秒数时，自动跳过。例如设为 5 秒，则间隔大于 5 秒的部分会被跳过，节省时间。

8.4 角色字幕显示

"角色字幕"选项决定扮演行的高亮方式：

选项效果
默认扮演行整行高亮
译文显示译文，隐藏原文
隐藏每个单词加边框，隐藏具体内容

"隐藏"模式适合听写练习：你能看到句子长度和断词，但看不到具体单词。

9. 闪播

闪播是一种变速快放整段的功能，用于快速过一遍已经熟悉的内容。

9.1 两种闪播

按钮行为
⚡从当前句开始，逐块变速快放
⚡²从屏幕顶部行开始，逐块变速快放

9.2 分块机制

  • 把字幕按"至少 N 秒一块"切分（N 由"闪播块最小时长"决定）
  • 每块按不同速度播放（速度列表由"闪播播放速度"决定）
  • 块与块之间有间隔（由"多行重复间隔"决定）

9.3 闪播速度列表

最多支持 6 个速度，每个速度在 1.00x 到 3.00x 之间。默认 4 个：1.25x、2.00x、2.25x、2.50x。

也可以使用快捷模板：

  • A：块 10 秒，速度 1.25x / 1.75x
  • B：块 20 秒，速度 1.25x / 1.75x / 2.00x
  • C：块 30 秒，速度 1.25x / 1.75x / 2.00x / 2.00x

9.4 结束条件

闪播到最后一个速度后，回到块起点，重新开始新一轮，直到手动停止。

10. 重复播放与间隔

10.1 重复次数

单句模式下，每句重复播放的次数：

  • 1 到 9：固定次数
  • 10：无限循环，直到手动停止

10.2 单句间隔

单句重复之间的间隔：

值含义
1 到 30固定秒数
31本句时长（念完后停等一会儿）
32下一句时长
33停止播放（等用户点播放才继续）

10.3 多行间隔

当一段有多个连续句时（例如你选了从屏幕顶行到当前行播放），段与段之间的间隔，单位秒，范围 1 到 30。

10.4 典型配置

场景重复次数单句间隔多行间隔
逐句跟读1本句时长—
精听新内容无限暂停3 秒
快速过一遍11 秒1 秒

11. 收藏

11.1 添加收藏

每条字幕行右侧有一个心形图标，点击即可切换：

  • 空心 ♡ → 实心 ♥：把该句加入收藏
  • 实心 ♥ → 空心 ♡：取消收藏

收藏点保存的是该句的时间中点，因此即使字幕内容修改，只要时间还在同一区间，收藏依然有效。

11.2 只看收藏

点击 ♡ 按钮切换到 ♥，只显示收藏的字幕。再点一次恢复全部显示。

11.3 收藏范围

收藏按频道和单元分别保存。切换到其他单元时，只显示该单元的收藏。

11.4 保存方式

  • iPhone/iPad：保存在 localStorage，按卡片 ID + 频道 + 单元划分
  • Android：同上
  • 桌面版：调用 Anki 插件写入卡片字段

12. 字幕显示与语言

12.1 显示模式

"显示字幕"选项控制：

模式显示
英文只显示原文
译文只显示译文
双语原文 + 译文同时显示

12.2 快速切换

点击 🌐 按钮：

  • 短按：切换当前行的显示语言（英文 → 译文 → 双语循环）
  • 长按 1.5 秒：对屏幕顶部到当前行之间的所有行执行同样切换

12.3 字幕位置

"字幕位置"选项控制当前行滚动到屏幕的哪个位置：

模式行为
默认仅当当前行不在可视区时才滚动
顶部总是把当前行滚到屏幕顶部
中部总是把当前行滚到屏幕中部

12.4 字幕字体

在选项中可切换 4 种字体：默认、Verdana、Helvetica、Times New Roman。

12.5 字体大小

4 个等级：默认（18px）、稍大（19.5px）、较大（21px）、最大（22.5px）。

13. 录音与噪音

13.1 录音

点击 🎤 按钮开始录音：

  • 需要浏览器授权麦克风权限
  • 录音中图标变为停止录制图标
  • 点击停止后自动开始回放
  • 最长录音 5 分钟
  • 录音只保留最近一次，再次录音会覆盖

录音文件保存在内存中，不写到磁盘。切换到下一张卡片时自动清除。

13.2 播放录音

点击 ▶🎤 按钮回放上一次录音。再次点击可停止播放。

13.3 噪音

点击 N 按钮循环切换：

值行为
N无噪音
N1 / N2 / N3混入三个不同噪音源之一

噪音与视频同步播放和暂停。开启噪音时视频音量自动降到 50%，噪音从随机位置开始，循环播放。

噪音文件来自卡片模板目录下的 u_noise_1.mp3、u_noise_2.mp3、u_noise_3.mp3。

14. 长按操作

17. 选项持久化机制

选项需要保存，下一次打开卡片时恢复。不同平台保存方式不同：

17.1 桌面版

把选项字符串写入卡片字段 Options 或 Tags。需要 Anki 插件 1020366288。

17.2 iPhone / iPad

保存在浏览器的 localStorage 中，键名格式为 卡片ID_series_opts_6。

17.3 Android

同 iPhone，保存在 localStorage。

17.4 编码方式

选项字符串用 base62 编码压缩，再以 a 为分隔符存储各个字段。例如：

字段顺序：语言 / 按钮颜色 / 按钮高度 / 按钮行数 /
播放模式 / 循环模式 / 字幕语言 / 字幕位置 /
角色字幕 / 字幕字体 / 字体大小 / 扮演后重播 /
只看收藏 / 视频高度 / 播放倍速 / 扩展时间轴 /
跳过空白时长 / 单句次数 / 单句间隔 / 多行间隔 /
闪播时长 / 闪播速度列表 / 频道 / 单元 / 播放位置

17.5 收藏单独保存

收藏数据不在选项字符串里，而是单独保存。键名格式：卡片ID_频道_单元。值为一串 7 位数字的拼接，每个数字代表一个收藏点的毫秒时间。

18. Srts 字段格式说明

了解格式有助于手动修改或生成卡片。Srts_00 到 Srts_10 都是纯文本字段，每行一条字幕。

18.1 行格式

时间信息\t原文\t译文
  • 时间信息：逗号分隔，格式为 前缀,季,集,媒体源,开始时间-结束时间
  • 原文：可带标记前缀 [s]、[n]、[a] 等
  • 译文：可为空

18.2 时间信息详解

以 ddm,,053,sf_s05e08,-251093-251873 为例：

部分值含义
前缀ddm时间线字段前缀
季（空）未指定季
集053第 53 单元
媒体源sf_s05e08媒体文件名（可选）
时间范围-251093-251873从 251093ms 到 251873ms

18.3 单元判定

每条字幕的"集"字段决定它属于哪个单元。程序在加载单元时，只把集字段匹配的字幕挑出来显示。

18.4 频道判定

Srts_00 是所有频道的公共索引。Srts_01 到 Srts_10 各自独立，可以是同一集的不同语言版本，也可以是不同集。

19. 常见问题

Q1：卡片打开后一片黑，什么都没有
检查：
  • 卡片是否有 Srts_01 字段内容
  • 卡片 ID 是否能被 document.getElementById("fld-srts-01") 找到
  • 浏览器控制台是否有 JavaScript 错误
Q2：视频不播放
检查：
  • Media 字段是否填写了扩展名
  • 媒体文件是否放在 Anki 的 collection.media 目录下
  • Windows 版本只支持 .webm，其他平台只支持 .mp4
Q3：选项面板打不开
检查按钮面板是否被拖出屏幕。刷新卡片重新打开。
Q4：选项不能保存
检查：
  • 桌面版是否安装了 Anki 插件 1020366288
  • iPhone 是否允许 localStorage（隐私模式下会禁用）
  • 卡片 Tags 字段是否被其他模板占用了
Q5：收藏丢失
收藏按频道和单元分别保存。切换到其他单元时看不到当前单元的收藏。清理浏览器缓存会丢失 localStorage 里的收藏。
Q6：闪播速度列表只有两个
闪播至少需要 2 个速度。如果设置里少于 2 个，会自动回退到默认的 1.25 / 1.75。
Q7：噪音无法播放
确认卡片模板目录下有 u_noise_1.mp3 到 u_noise_3.mp3，并且已加入 Anki 媒体库。
Q8：录音按钮无反应
  • Windows 桌面版不支持录音
  • 其他平台需要授权麦克风权限
  • HTTPS 环境下才能使用录音 API
Q9：长按没反应
长按需要持续 1.5 秒。如果手指稍微移动，会被识别为拖动而不是长按。可以尝试用鼠标（桌面版）或更稳定的手指按压。
Q10：字幕显示不全或错位
  • 检查 Srts 字段每行是否用 Tab 分隔（不是空格）
  • 检查时间信息的逗号数量是否正确
  • 检查字幕是否包含异常字符
Q11：跟读时视频被静音但没有"该你念"的提示
检查"角色字幕"选项是否设为"隐藏"。此模式下扮演行会显示为带边框的方块，是提示而非内容。
Q12：切换到其他单元后播放位置没有重置
这是设计行为。切换单元时若指定了"从头播放"，位置会重置。否则会记住上次的位置。
Q13：显隐译文长按后整个屏幕乱了
长按显隐译文会对屏幕顶部到当前行之间的所有行切换。若不希望这样，短按即可，只切换当前行。
Q14：按钮面板突然变成一行
说明卡片被识别为无媒体卡片（Media 字段为 NaN，或视频文件缺失）。检查 Media 字段和媒体文件。
