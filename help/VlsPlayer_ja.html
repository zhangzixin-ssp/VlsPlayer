1. プログラム概要と画面全体像

1.1 位置づけ

VlsPlayer は語学学習者向けの字幕プレーヤー兼エディターです。再生、字幕編集、波形調整、音声認識、シャドーイング録音、辞書検索、AI 翻訳、Anki エクスポートを 1 つのインターフェースに統合し、「動画を見る — 字幕を編集する — ノートを取る — カードをエクスポートする」という流れを 1 つのウィンドウで完結させます。

1.2 主な機能

  • 波形の可視化：ハンドルを直接ドラッグして字幕タイミングを変更
  • 5 つの再生モード：通常、単文、役割1/2の演じ分け、範囲ループ
  • 文ごとのシャドーイング録音と自動 ASR 採点
  • ディクテーションモード：原文を隠して聞き取り入力
  • カラーマーク（7 色）+ 注釈 + 段落タグ
  • 字幕の校正：最大 4 つの参照字幕を同時に読み込み
  • フィルター表示：注釈 / マークで絞り込み
  • ローカル ASR：sherpa-onnx モデルで字幕セグメントを個別認識
  • 辞書、AI 分析、TTS：内蔵または外部ブラウザーで開く
  • デュアルエンジン再生：MPV（デフォルト）と VLC。オプションで切替可能
  • バイリンガル字幕管理：字幕一（原文）と字幕二（訳文）を個別に編集
  • 3 つの付属ツールボックス：SRT / TXT / ASR
  • 4 言語の UI、16 以上の組み込みテーマ、カスタムテーマ対応

1.3 画面全体のレイアウト

メインウィンドウは上から下へ 4 層に分かれています：

層内容非表示可否
タイトルバーカスタムタイトルバー。ファイル名を表示全画面時に非表示
ツールバーすべてのショートカットボタン全画面時に非表示
メイン領域（上下可変） 上：字幕テーブル
下：メディア画面 + 字幕編集 + 注釈/校正 		テーブルは非表示可能
波形エディター波形エリア + ハンドルエリアメディアなしの場合非表示
録音パネルシャドーイング時に表示シャドーイングオフ時に非表示

1.4 スプリッター

  • SplitterClient：テーブルと下の詳細エリアの間。ドラッグで比率を調整
  • SplitterMedia：動画画面と右側のテキストエリアの間。水平にドラッグ
  • SplitterRe：字幕編集エリアと注釈エリアの間。垂直にドラッグ
  • SplitterBottom：メイン領域と波形エディターの間。垂直にドラッグ

ウィンドウサイズ、スプリッター位置、パネルの表示状態は終了時に INI に保存され、次回起動時に自動復元されます。

2. 字幕ディレクトリとファイル管理

字幕ディレクトリパネルはデフォルトでメインウィンドウの左側にドッキングされ、ツールバー左端のボタンで表示方法を切り替えられます。

2.1 表示モード

モード動作
自動ドッキング（デフォルト）マウスがウィンドウの左端に移動すると自動表示され、離れると非表示
非表示まったく表示しない

ツールバー左端のボタンで切り替えます。自動モードでは、マウスが離れてから 3 秒後に自動的に非表示になります。

2.2 ディレクトリ管理

  • ドロップダウンボックス：保存済みの SRT ディレクトリを選択
  • +：SRT ディレクトリを追加（自動的に重複排除）
  • −：現在選択中のディレクトリを削除

すべてのディレクトリは INI の [SrtDir] セクションに保存され、終了時に書き込まれ、起動時に読み込まれます。

2.3 ファイルリスト

  • 現在のディレクトリ内のすべての .srt ファイルを一覧表示
  • クリックで選択して読み込み
  • 起動時に前回開いたファイルを自動選択
  • 履歴がない場合はリストの最初の項目を選択

2.4 ツールボックスの入口

ディレクトリパネル上部の 3 つのボタンで付属ツールを開きます：

ボタン開くもの
SRT ツールボックスVlsSrtTools.exe（外部プログラム）
TXT ツールボックスプログラム内の TxtTools ウィンドウ
ASR ツールボックスVlsAsrTools.exe（外部プログラム）

3. メディアと字幕を開く

3.1 開く流れ

  1. ファイルリストで .srt ファイルをクリック
  2. プログラムは次の順で読み込みます：
    1. .srt 字幕を読み込む
    2. 同名の .snt ファイル（注釈、段落タグ、書式付きテキスト）を読み込む
    3. 同名の .dic ファイル（ディクテーション内容）を読み込む
    4. 同ディレクトリの ProofSrt.lst（校正ファイルリスト、存在する場合）を読み込む
    5. 現在のフィルター条件に従ってフィルターを適用
  3. 同名のメディアファイルを探し（VIDEO_EXTS 優先、次に AUDIO_EXTS）、自動で読み込む
  4. 同名の .wfm 波形キャッシュファイルを探し、なければ ffmpeg で生成
  5. 前回終了時のそのファイルの再生位置を復元

3.2 対応字幕エンコーディング

SRT 読み込み時に以下のエンコーディングを自動判別します：

  • UTF-8（BOM あり / BOM なし）
  • UTF-16 LE（BOM）
  • UTF-16 BE（BOM）
  • システム既定エンコーディング（ANSI）

BOM がない場合は、まず UTF-8 の妥当性を検証し、不正な場合はシステム既定エンコーディングで読み込みます。

3.3 対応メディア形式

動画：mp4、mkv、avi、mov、flv、webm、3gp、3g2、wmv、asf、vob、mts、m2ts、ts、mpeg、mpg、m4v

音声：wav、mp3、ogg、flac、aac、wma、m4a、aiff、aif、alac、wavpack、ape、mid、midi

3.4 波形キャッシュ

.wfm ファイルは、次のコマンドで生成される 4 kHz モノラル PCM キャッシュです：

ffmpeg.exe -i メディアファイル -ar 4000 -ac 1 -acodec pcm_s16le -f wav -y 出力.wfm

生成は最大 30 秒待機します。生成に失敗した場合、波形エリアは空のままになり、字幕編集には影響しません。

5. 字幕テーブル

5.1 列の定義

5.2 表示モード

ツールバー右端の「字幕を表示」ボタンで 3 つを循環します：

  • 字幕一のみ
  • 字幕二のみ
  • 字幕一 + 字幕二（デフォルト、比率 3:2）

5.3 時間形式

オプションで設定します：

2時なし12:34,567
3時なし、ミリ秒 1 桁12:34,5
4分秒のみ12:34

5.4 行の色

色トリガー

5.5 段落マーク列

色と塗りつぶしスタイルで話者を表現します：

話者番号は段落タグ（ParTag）から自動推測されます。ルールは第 8 節を参照。

5.7 ホイールモード

ツールバーの「ホイール」ボタンで 3 つを循環します：

  • 内容をスクロール（デフォルト）
  • 現在行をスクロール
  • スムーズスクロール（パフォーマンス最適化あり）

6. 字幕編集エリア

詳細エリアの右上にあり、RichEdit コントロールです。

6.1 表示ルール

  • 1 段落目は字幕一（原文）を表示。原文にカラーマークがあれば、対応する色で描画されます
  • 2 段落目は字幕二（訳文）を表示。より小さいフォントを使用
  • ディクテーションモードでは、字幕一は短いダッシュの行で表示（原文を隠す）

6.2 編集動作

  • 直接編集。入力後、フォーカスを失うか 1 秒経過すると SRT に自動保存
  • Enter を押すと 2 段落に分かれます：1 段落目が字幕一、2 段落目が字幕二
  • 編集中の入力はすぐにはディスクに書き込まれず、クールダウン後にコミットされ、頻繁なディスク書き込みを回避します

6.3 フローティング編集ボックス

オプションで「フローティング字幕編集ボックス」を有効にすると：

  • 編集ボックスがパネルから離れ、テーブルの上に浮かびます
  • テーブル行をダブルクリックすると表示されます
  • マウスが離れるかフォーカスを失うと自動的に非表示
  • 位置は行の高さに応じて自動調整
  • 高さは内容に応じて自動調整。最大で画面の 3 分の 2 を超えません

6.4 右クリックメニュー

編集ボックス内で右クリックすると、以下のメニュー項目が表示されます：

メニュー項目ショートカット動作
切り取りCtrl+X選択テキストを切り取る
コピーCtrl+C選択テキストをコピー
貼り付けCtrl+Vカーソル位置に貼り付け
メイン字幕をコピー字幕一（訳文を含まない）をコピー
メディアクリップを書き出し選択字幕に対応する動画クリップを ffmpeg で書き出す
辞書Ctrl+D選択語の意味を調べる
AI 分析Ctrl+I選択テキストを AI 分析に送る
TTS 読み上げCtrl+T選択テキストを Edge TTS で読み上げる

7. 注釈、ディクテーション、校正エリア

詳細エリアの右下にあります。この領域は現在の状態に応じて以下のいずれかを表示します：

  • 注釈（Remark）
  • ディクテーション（Dictation）
  • 校正表示（Proof）
  • ASR 認識結果

7.1 表示ソースの切り替え

上部のボタンバーでどれを表示するかを決めます：

ボタン表示
注釈現在の字幕の Remark
校正 0~3対応する校正ファイルの一致結果
ディクテーション現在の字幕の Dictation（ディクテーションモードで自動切替）

7.2 注釈の編集

  • 注釈は複数行可能。ボックス内に直接入力
  • 入力後、フォーカスを失うか 1 秒経過すると .snt ファイルに自動保存
  • 注釈は「注釈あり」フィルターをトリガーします

7.3 校正表示

RTF の色分けで一致結果を表示します：

色意味
グレーコンテキスト（一致した文の前後 1 文ずつ）
緑完全一致
赤不一致または差異
青差異のある文字

7.4 校正コンテキストの閲覧

校正表示エリアで右クリックし、「さらに字幕を閲覧」を選ぶと、校正ファイル内の現在の時間点の前後 10 件の字幕を表示します。

8. マーク（Flags）

8.1 7 つの色

書式付きテキストタグ <f1> ~ <f7> に対応します。意味はオプションでカスタマイズ可能（デフォルトは重点、表現、発音、文法、スラング、フレーズ、語彙）。

8.2 マークの追加

  1. 字幕編集ボックスでマークするテキストを選択
  2. マークバーで対応する色の旗をクリック
  3. 選択テキストが <fN>テキスト</fN> で包まれ、.snt ファイルに書き込まれる

8.3 マークのクリア

マークされたテキストを選択し、マークバーの最後の「X」アイコンをクリックするとクリアされます。

8.4 表示方法

オプションで設定：

方法効果
カラー文字マークされたテキストが対応する色で表示される
カラー下線マークされたテキストは元の色のまま、下にカラー下線が表示される

8.5 フィルター表示

マークバーの任意の旗をクリックすると、そのマークのフィルター表示を切り替えられます。例えば <f1> を含む字幕のみを表示します。

8.6 段落タグ

7 つのカラーマークのほか、文構造をマークする 3 つの段落タグがあります：

タグ意味話者推測への影響
s新しいシーン開始話者を役割 1 にリセット
nナレーション話者 = 0
a継続行（同じ役割）前の行の話者を引き継ぐ

推測ルールの完全な記述：

if n を含む → Speaker = 0
else if 最初の行 または s を含む → Speaker = 1
else if a を含む → Speaker = 前の行の Speaker
else if 前の行の Speaker ≠ 1 → Speaker = 1
else → Speaker = 2

8.7 段落タグの切り替え

編集ボックスで右クリックすると切り替えられます：

  • 新旧シーン（s）の切り替え
  • ナレーション/歌詞（n）の切り替え
  • 継続行/単一行（a）の切り替え

9.6 ページ送り

  • ページの長さはツールバーの波形幅で決まり、デフォルトは 1 ページ 20 秒
  • ページは 5 秒重複し、ページをまたぐ字幕の欠落を防ぎます
  • 最後のページに達すると自動的に前へ移動し、音声がページ全体を埋めます

9.7 ドラッグの制約

  • 左ハンドルは前の字幕の終了時間 + 1ms を下回らない
  • 右ハンドルは次の字幕の開始時間 − 1ms を上回らない
  • 字幕の最小継続時間はハンドル幅の 2 倍（約 12px に対応する時間）
  • 全体を平行移動する場合、前後の境界が同時に制約されます
ドラッグ中は一時的な変更のみが行われ、マウスボタンを離したときに初めて元に戻せる操作として記録されます。

10. プレーヤーと再生モード

10.1 再生エンジン

エンジン長所短所
MPV（デフォルト）時間精度が高く、再生が滑らかmpv ランタイムが必要
VLC互換性が良い時間精度は約 150ms

エンジンを切り替えた後は、メディアファイルを再読み込みする必要があります。

10.2 再生モード

モード動作
通常現在位置からメディアの最後まで再生

役割2を演じる役割 1 のセリフをミュートし、役割 2 とナレーションのみ再生
範囲ループ選択区間をループ再生（波形エリアでのドラッグでトリガー）

10.3 一時停止設定

単文モードでのみ有効。各文の再生終了後の一時停止時間：

オプション時間

文の長さこの文の再生時間
1s / 2s / 3s / 9s固定時間

10.4 リピート回数

単文モードで有効：1、2、3、6、9、無限。

10.5 音量

  • メディア音量：0 ~ 100%
  • ノイズ音量：0 ~ 100%（メディア音量とミックスして出力）
  • ミックススイッチ：オンにするとメディア再生時に同時に背景ノイズを再生

ノイズ源はプログラムディレクトリの lib\noises\ にある mp3 ファイルからランダムに選ばれます。

10.6 再生終了時の動作

オプション動作
一時停止最後で停止
リプレイ最初から再生し直す
次のエピソードを再生ファイルリストの次の SRT に切り替え

10.7 全画面

  • ショートカット Ctrl+Enter で全画面に入る
  • 全画面時はすべてのパネルが非表示になり、動画が画面全体を占めます
  • Esc または再度 Ctrl+Enter で終了
  • 終了後は元のパネルレイアウトに戻ります

10.8 再生位置の精度

  • MPV：mpv ネイティブの時間を使用し、誤差はごくわずか
  • VLC：自前で維持する高精度タイマーを使用。再生中の誤差は約 50ms で、一時停止後はネイティブ時間を読み取ります

11. シャドーイングと録音

11.1 有効化

ツールバーの「シャドーイング」ボタンをクリックすると、録音パネルがウィンドウ下部に展開し、波形エディターが上に移動します。

ボタン説明

11.4 自動認識

録音停止後：

  1. プログラムが ASR モデルを呼び出して録音を認識
  2. 認識結果を字幕の原文と比較し、単語レベルの類似度を計算
  3. 類似度 ≥ 0.85 は緑、それ以外は赤で表示
  4. 結果は注釈エリアに表示

録音は以下に保存されます：

  1. テーブルで範囲を指定して字幕を選択
  2. 録音パネルの「書き出し」ボタンをクリック
  3. 保存先を選択
  4. プログラムが ffmpeg で録音を 192kbps の MP3 に結合

録音ファイルが存在する字幕のみが書き出され、欠落しているものはスキップされます。

12. ディクテーションモード

12.1 開始

ツールバーの「ディクテーション」ボタンをクリック（アイコンがハイライト状態）。

12.2 画面の変化

  • テーブルの字幕一が、原文と同じ長さの短いダッシュの行に置き換わります
  • 注釈エリアがディクテーション入力ボックスに切り替わり、現在の字幕のディクテーション内容を表示
  • 字幕編集エリアが編集可能な空白エリアになります

12.3 使用方法

  1. 現在の文を再生
  2. 編集エリアに聞き取った内容を入力
  3. フォーカスを失うか 1 秒経過すると .dic ファイルに自動保存
  4. 「次の文」をクリックして続行

12.4 終了

もう一度「ディクテーション」ボタンをクリックすると終了し、テーブルに原文が再表示されます。

12.5 ディクテーション内容の保存場所

ディクテーション内容は SRT と同名の .dic ファイルに保存され、形式は次のとおりです：

@t@:時間ミリ秒
ディクテーション内容

各ディクテーションは @t@ 行で区切られ、プログラムは時間の中間値で対応する字幕にマッチングします。

13. ASR 音声認識

13.1 システム構成

Delphi プログラム
   │
   ├─ sherpa-onnx-offline-websocket-server.exe を起動（ポート 6006）
   │
   ├─ asr_engine.py を起動（Python ブリッジ、ポート 9001）
   │
   └─ HTTP POST WAV → 9001 → WebSocket → 6006 → JSON を返す

13.2 前提条件

  • Python がインストール済みで、pip install numpy websockets を実行済み
  • プログラムディレクトリの sherpa\ に以下がある：
    • sherpa-onnx-offline-websocket-server.exe
    • asr_engine.py
    • モデルディレクトリ（小/中/大、オプションで選択）
  • ポート 6006 と 9001 が他のプログラムに占有されていない

13.3 モデル選択

モデルサイズ読み込み時間
小モデル120 MB約 30 秒
中モデル420 MB約 90 秒
大モデル1.2 GB約 5 分

モデルが大きいほど正確ですが遅くなります。初回読み込み後はメモリに常駐し、以降の呼び出しでは再読み込みが不要です。

13.4 字幕セグメントの認識

  1. テーブルで認識したい字幕行を選択（複数選択すると音声が結合されます）
  2. 注釈ボックス上部の「ASR」ボタンをクリック
  3. プログラムが ffmpeg でセグメント音声を抽出し、ASR を呼び出して認識
  4. 結果は注釈エリアに表示され、認識テキストと類似度を含みます

13.5 結果の意味

色類似度
緑≥ 0.85
赤< 0.85

13.6 認識時間の適用

認識後、ASR が返した正確な開始/終了時間を現在の字幕に適用できます（認識結果が現在の字幕と一致する場合のみ使用可能）。

13.7 シングルトン保護

ASR リソースはシングルトンで、同時に 1 つのプログラムだけが使用できます。すでに 1 つのプログラムが使用している場合、別のプログラムは起動に失敗し、メッセージが表示されます。

14. 字幕の校正

14.1 校正ファイルリスト

SRT と同じディレクトリに ProofSrt.lst を作成し、1 行に 1 件ずつ記述します：

識別子|フォルダパス|字幕タイプ番号
  • 識別子：ボタンに表示される 1 文字（A、B、C、D を推奨）
  • フォルダパス：校正字幕のあるディレクトリ。末尾にスラッシュを付けることを推奨
  • 字幕タイプ番号：0~4。第 5 節の字幕タイプに対応

最大 4 つの校正ファイルを同時に読み込めます。

14.2 オプションからの追加

  1. オプション → 一般 を開く
  2. 「校正フォルダ」エリアで + をクリック
  3. ディレクトリを選択し、識別子と字幕タイプを入力
  4. 確定すると ProofSrt.lst に書き込まれます

14.3 校正の使用

  1. メインの SRT ファイルを開く
  2. 注釈エリア上部の校正ボタン（0~3）をクリック
  3. プログラムはメイン字幕の現在行を使って校正ファイル内を検索
  4. 一致結果はカラー RTF で表示されます

14.4 マッチングアルゴリズム

校正処理はタイムライン整列と同じ検索アルゴリズムを使用します：

  1. 現在の文の先頭文字列でメイン字幕内を特定
  2. 前の文の末尾文字列で特定を補助
  3. 現在の文の単語数で特定
  4. 段階的にフォールバックし、最適な一致を見つける

14.5 表示エリアの色

色意味
グレー一致した文の前後のコンテキスト
緑完全一致
赤一致しない部分
青文字レベルの差異

14.6 コンテキストの閲覧

校正表示エリアで右クリックし、「さらに字幕を閲覧」を選ぶと、校正ファイル内の現在の時間点の前後 10 件の字幕の原文を表示します。

15. フィルター表示

15.1 注釈によるフィルター

ツールバーの「注釈」ボタン：

  • 押下：注釈のある字幕のみ表示
  • 解除：すべての字幕を表示

15.2 マークによるフィルター

ツールバーのマークバーは複数のマークフィルターを同時に有効にできます。ルール：

  • 選択されたマークを少なくとも 1 つ含めば表示
  • 複数のマークは「OR」の関係

15.3 複合フィルター

注釈とマークは同時に有効にでき、これらも「OR」の関係です。

15.4 フィルターモードでの制限

フィルターモード（FUseMapping = True）では以下の操作が禁止されます：
  • 字幕の挿入
  • 字幕の削除
  • 字幕の結合
  • 字幕の分割
  • 時間の一括変更
既存の字幕のテキスト、注釈、マーク、ディクテーション、時間の変更のみが許可されます。

違反した場合、対応するボタンがグレーアウトし、クリックできません。

15.5 フィルターの解除

すべてのフィルター条件を解除すると完全な表示に戻ります。フィルター状態は INI に保存されます。

16. 辞書 / AI / TTS

16.1 辞書

字幕または注釈で調べたい単語やフレーズを選択し、次のいずれかを行います：

  • 右クリック → 辞書
  • またはツールバーの「辞書」ボタンをクリック
  • または Ctrl+D を押す

ローカル辞書

URL Scheme を使ってローカル辞書プログラム（Eudic など）を開きます：

eudic://dict/%s

%s は検索語に置き換えられます。

オンライン辞書

チェックすると順にブラウザーで開きます。プリセットの 8 つの URL に対応し、カスタマイズも可能です。

16.2 AI 分析

操作は辞書と同じです。プログラムは次を行います：

  1. AI Prompt + 選択テキストをクリップボードに入れる
  2. 対応する AI サイトを開く（または既に開いているタブを再利用）
  3. 自動的に貼り付けて送信

プリセット AI サイト

  • ChatGPT（chatgpt.com）
  • Claude（claude.ai）
  • Gemini（gemini.google.com）
  • 通義千問
  • 豆包
  • DeepSeek
  • Kimi

AI Prompt

デフォルトの Prompt は、AI に直訳と英語の知識ポイントの分析を求め、プレーンテキストで出力させます。オプションで変更できます。

16.3 内蔵ブラウザー

「内蔵ブラウザーを使用」をチェックすると：

  • 辞書と AI はプログラムに埋め込まれた Edge WebView2 で開きます
  • 外部ブラウザーに飛び出すことはありません
  • 複数の AI サイトは上部のボタンで切り替えます
  • ブラウザーウィンドウはメインウィンドウとは独立に移動でき、メインウィンドウの端に吸着させることもできます

16.4 TTS 読み上げ

テキストを選択し、右クリック → TTS、または Ctrl+T を押します。

実装方法：

  1. 選択テキストを含む HTML ファイルを生成
  2. Microsoft Edge で開く
  3. Ctrl+Shift+U をシミュレートして Edge の読み上げ機能をトリガー

初回呼び出しで Edge ウィンドウが開き、以降の呼び出しではそのウィンドウを再利用して内容を更新します。

17. ツールボックス

17.1 SRT ツールボックス

字幕リストパネルの SRT ツールボックスボタンをクリックして開きます。独立した外部プログラム VlsSrtTools.exe です。機能には字幕の一括処理、AI 翻訳テキストの生成、字幕による動画分割、Anki エクスポートなどがあります。詳細は付属の『SRT ツールボックス操作マニュアル』を参照してください。

17.2 TXT ツールボックス

プログラム内で小さなウィンドウを開きます。機能：プレーンテキストファイルを文単位に分割し、SRT 字幕を生成します。

使用手順

  1. 処理する TXT ファイルを選択
  2. SRT 出力ディレクトリを選択
  3. 分割基準を設定（例：Chapter。この接頭辞で新しいファイルを開始）
  4. OK をクリック

出力

  • 分割なし：TXT と同名の SRT を 1 つ生成
  • 分割マーカーで分割：複数の SRT を生成し、ファイル名に番号 _01.srt、_02.srt... を付与

時間の割り当て

各文はデフォルトで 10 秒、間隔は 1 秒です。生成されたタイムラインはあくまでプレースホルダーで、ASR 整列で修正できます。

17.3 ASR ツールボックス

字幕リストパネルの ASR ツールボックスボタンをクリックして開きます。独立した外部プログラム VlsAsrTools.exe です。機能にはセグメント ASR による字幕生成、タイムライン整列などがあります。詳細は付属の『音声認識ツールボックス操作マニュアル』を参照してください。

20.2 SNT ファイル形式

@t@:時間中間値ミリ秒
@p@:段落タグ
@f@:書式付きテキスト
注釈 1 行目
注釈 2 行目
@t@:次の項目の時間中間値
...
  • @t@: は 1 件の字幕の開始を表します
  • @p@: 段落タグ（s/n/a）
  • @f@: 書式付きテキスト（<f1>~<f7> マークを含む）
  • その他の行はすべて注釈本文

ある字幕に注釈、タグ、書式付きテキストのいずれもない場合、.snt には書き込まれません。.snt 全体が空の場合は自動的に削除されます。

20.3 DIC ファイル形式

@t@:時間中間値ミリ秒
ディクテーション 1 行目
ディクテーション 2 行目
@t@:次の項目...

22. よくある質問とトラブルシューティング

Q1：字幕リストにファイルが見えない
SRT ディレクトリが正しいか、ディレクトリ内に .srt ファイルがあるかを確認してください。更新方法：ディレクトリを切り替えてから戻す。
Q2：波形エリアが空
原因は通常次のいずれかです：
  • 同じディレクトリにメディアファイルがない
  • メディアファイル名が SRT と異なる
  • プログラムディレクトリの lib フォルダに ffmpeg.exe がない
  • ffmpeg が wfm を生成する際に失敗（メディア形式が非対応、または長すぎる）
Q3：字幕時間を変更した後、プログラムを再起動すると失われる
保存されていません。SRT 変更後は手動で保存（Ctrl+S）するか、自動保存を待つ必要があります。「終了時に自動保存」オプションも使用できます。
Q4：フィルターモードで字幕を挿入できない
これは設計上の動作です。フィルターモードでは字幕構造の変更が禁止されています。まずフィルターを解除してください（ツールバーの注釈/マークフィルターをクリックして解除）。
Q5：ASR 認識が失敗する
以下を確認してください：
  • モデルが sherpa\モデル名\ にダウンロードされているか
  • sherpa\sherpa-onnx-offline-websocket-server.exe が存在するか
  • sherpa\asr_engine.py が存在するか
  • Python がインストールされ、pip install numpy websockets を実行済みか
  • ポート 6006 と 9001 が占有されていないか
Q6：辞書 / AI が開けない
オプションで URL が有効か確認してください。内蔵ブラウザーを使用する場合、Edge WebView2 ランタイムが必要です。
Q7：シャドーイングの採点がいつも低い
確認：
  • マイクが正常に動作し、音量が適切か
  • 録音環境が静かか
  • ASR モデルが正しく読み込まれているか
  • 字幕の原文と録音内容の言語が一致しているか（モデルは英語モデルで、中国語の認識精度は低い）
Q8：カラーマークが失われた
カラーマークは .snt ファイルに保存されます。.snt が保存されていないか失われた場合、マークは通常のテキストに退化します。backup サブディレクトリから復元を試みてください。
Q9：自動保存で変更が上書きされた
プログラムは保存前に backup サブディレクトリへ自動バックアップします。そこからタイムスタンプで過去のバージョンを探せます。
Q10：テーマ切り替え後、一部のコントロールの色がおかしい
一部のサードパーティコントロールはテーマの制御外です。オプションのテーマパネルで色を微調整できます。一部のコントロールはプログラムを再起動しないと完全に反映されません。
Q11：全画面を終了する方法がわからない
Esc または Ctrl+Enter を押してください。
Q12：字幕時間を調整した後、音声とずれる
確認：
  • 再生エンジンが VLC の場合、誤差が大きくなります。MPV に切り替えてみてください
  • 波形エディターでハンドルをドラッグし、正確な位置に調整してください
  • ASR ツールボックスの「タイムライン整列」機能で自動修正してください
Q13：再生中に字幕のスクロールがカクつく
行の高さ計算や再描画の負荷が原因かもしれません。次を試してください：
  • 「字幕を 1 行で表示」をオフにする
  • テーブルの行間隔を小さくする
  • カラーマーク表示をオフにする
Q14：内蔵ブラウザーが開けない
Microsoft Edge WebView2 Runtime をインストールする必要があります。Microsoft の公式サイトからダウンロードできます。
