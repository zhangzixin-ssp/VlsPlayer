1. Program Overview

The ASR Toolbox processes video/audio subtitles and provides two working modes:

ModeFunctionOutput Location
ASR Generate SRT FileUse an ASR model to recognize speech and generate subtitlesASR folder
Align SRT TimelineAlign existing ASR subtitles with source subtitlesSource folder (overwrites original files)

The program supports batch processing of multiple files and can be canceled midway.

2. System Requirements

  • Windows
  • lib\ffmpeg.exe must exist in the program directory
  • When using generation mode, the corresponding ASR model must be downloaded
  • ASR models come in small, medium, and large sizes; larger is more accurate but slower

4. Quick Start

4.1 Generate SRT Subtitles

  1. Select ASR Generate SRT File
  2. Set the Source folder (directory containing media files)
  3. Set the ASR folder (SRT output directory)
  4. In the left list, select the media files to process (multi-select supported)
  5. Check If ASR-generated SRT file exists, overwrite it? as needed
  6. Click OK
  7. Watch the log area and wait for processing to finish
  8. Get the same-named .srt file from the ASR folder

4.2 Align SRT Timeline

  1. Select Align SRT Timeline
  2. Set the Source folder (containing the .srt to be corrected)
  3. Set the ASR folder (containing the same-named ASR .srt)
  4. Check Merge sentence fragments before alignment? as needed
  5. Adjust the four alignment parameters as needed, or click Default
  6. Select files in the left list
  7. Click OK
  8. When finished, the .srt in the Source folder is updated

5. Parameter Details

Time Drift Window (s)

The maximum offset allowed between subtitle timestamps and audio. Default is 30 seconds. If the subtitles are offset overall by a large amount, increase this value appropriately.

Search Text Length

The length of the text window used for matching during alignment. Default is 16. Larger is more stable but slower; smaller is faster but may match inaccurately.

Min Time Gap (ms)

The minimum interval allowed between two subtitles. Default is 1 millisecond. Used to prevent subtitles from overlapping on the timeline.

Max Error Threshold

The maximum error rate allowed during matching. Default is 0.15. Larger is more permissive; smaller is stricter.

6. Processing Flow

6.1 Generation Mode

  1. Open the media file and read the total duration
  2. Split into 120-second segments
  3. Use lib\ffmpeg.exe to extract 16 kHz mono wav
  4. Call the ASR model for recognition
  5. For non-final segments, discard the last sentence to avoid overlap with the next segment
  6. When all done, write to the ASR folder

6.2 Alignment Mode

  1. Read the source SRT and ASR SRT
  2. If checked, merge sentence fragments first
  3. Align according to the four parameters
  4. Write the result back to the source SRT

7. FAQ

Q1: Failed to read media file information
The media file cannot be opened or its format is not supported. Check whether the file is intact and whether the path contains special characters.
Q2: No ASR subtitle file
In align mode, the ASR folder does not contain a file with the same name as the source SRT. Run generation mode first, or confirm that the file names match.
Q3: Automatic speech recognition failed
Model loading failed or audio extraction failed. Check whether the model has been downloaded and whether lib\ffmpeg.exe exists.
Q4: No result for the last few minutes
Possible causes: the total media duration could not be read or was underestimated; a segment failed and caused an interruption; the last segment produced no recognized content. Check the last few lines of the log to see where it stopped.
Q5: Will the SRT in the source folder be overwritten?
Align mode overwrites the source SRT, so back it up first. In generation mode, if an SRT with the same name already exists in the ASR folder and "overwrite" is not checked, it will be skipped.
Q6: Can it be canceled midway?
Yes. After clicking Cancel, it stops when the current segment finishes. Already-recognized parts are not saved.
Q7: Why can't I see a certain file in the file list?
The list only shows supported extensions. Align mode shows only .srt; generation mode shows only video/audio extensions. If the extension is not in the supported list, it will not appear.
Q8: Changes to parameters did not take effect?
Parameters are read when you click OK. After changing them, simply click OK. If an input value is out of range, a dialog will prompt you and correct it automatically.

8. Notes

  1. Processing long files takes a long time; it is recommended to test with a short video first.
  2. Larger models are more accurate but slower and use more memory.
  3. Temporary wav files are deleted automatically, but abnormal exit may leave residue.
  4. Align mode directly rewrites the .srt in the source directory; please back up first.
  5. Current settings are saved when the program exits and restored automatically next time.
  6. It is recommended to keep lib\ffmpeg.exe matching the program version.
