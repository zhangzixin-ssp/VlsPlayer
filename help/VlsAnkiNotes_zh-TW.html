1. 這是什麼

筆記卡是一張單句卡片。每張卡包含一段影片或音訊、一句原文、一句譯文、一條備註。

和 VlsPlayer Series 卡的區別：

對比項Series 卡Notes 卡（本卡）
單元一整季／整單元一句話
字幕區可滾動列表固定顯示當前句
播放範圍整集，可切換單元單句時間區間
典型用途刷劇、連續跟讀精聽、生詞複習
正面／背面整個播放器在正面正面先播放，背面顯示筆記

1.1 主要特徵

  • 卡片正面自動播放目標句子（可關閉）
  • 隱藏譯文，讓學習者先聽後看
  • 循環重複播放，設定次數與間隔
  • 拖動時間軸微調播放區間
  • 沒有影片檔案時自動降級為 TTS 朗讀
  • 背面顯示備註（Remark）與來源（From）
  • 控制列可拖動到任意位置
  • 選項儲存在 localStorage 中

2. 卡片欄位

2.1 五個欄位

欄位作用
Timeline媒體來源 + 時間區間，格式見第 14 節
SrtText1字幕一（通常為英文原文），可含 <f1>~<f7> 彩色標記
SrtText2字幕二（通常為譯文）
SrtNote備註內容，可多行
From來源標籤，例如「某劇 S05E08 12:34」

2.2 製作來源

由桌面版 VlsPlayer 的「匯出到筆記牌組」功能產生。每選一條字幕就產生一張卡片。也可以由 SRT 工具箱的 Anki 匯出功能批次產生。

2.3 學習流程

  1. 顯示正面：自動播放該句音訊，字幕顯示
  2. 你判斷是否聽懂
  3. 點擊「顯示答案」，翻到背面
  4. 背面顯示備註和來源
  5. 選擇「重來／困難／良好／簡單」

3. 介面佈局

3.1 三個區域

區域內容
頂部媒體區影片或音訊（無影片時僅顯示封面，或完全隱藏）
中部文字區
  • 關鍵片語（Key）：從 <fN> 標記擷取
  • 字幕一（Text1）：主字幕
  • 字幕二（Text2）：譯文，可選隱藏
  • 備註（Note）：僅背面顯示
  • 來源（From）：僅背面顯示，右下角
底部控制列可拖動的按鈕 + 時間軸面板

3.2 字幕彩色標記

字幕一中的 <f1> 到 <f7> 標記會顯示為不同顏色（與 Series 卡一致）：

標記顏色
f1紅
f2綠
f3藍
f4黃
f5洋紅
f6橙
f7暗紅

如果卡片有影片，這些標記會額外擷取成「關鍵片語」列表顯示在字幕上方。

3.3 備註格式

備註按行顯示，每行前有一個圓點符號 •。空行自動忽略。

4. 控制列按鈕

控制列是一個可拖動的浮動面板，包含 7 個按鈕和一條時間軸。

4.1 七個按鈕

按鈕圖示功能
牌組▣返回牌組（僅 iOS/Android，單擊無效，需配合手勢）
播放速度選單📊彈出速度選擇選單
播放／暫停▶ / ⏸主播放按鈕
重播↺從起點重新播放
查詢🔍詞典／AI 查詢
倍速切換0.5 / 1.0快捷切換播放速度
選項⚙開啟選項面板

4.2 播放按鈕圖示變化

圖示狀態
▶已暫停，可播放
⏸正在播放
⏸ 旋轉 90°等待中（在重複間隔內）

4.3 點擊非按鈕區域播放／暫停

在控制列以外的地方點擊（按鈕和時間軸滑桿除外），會自動觸發播放／暫停。這是為了方便快速操作。

5. 時間軸與拖動條

5.1 元素說明

元素顏色含義
◁ / ▷ 按鈕黃微調起止時間各 0.5 秒
水平細線暗黃時間軸基準線
兩個黃點黃原始起止時間（不可拖動）
兩個黃滑桿黃當前起止時間（可拖動）
白滑桿灰白播放位置指示器（不可拖動）

5.2 拖動滑桿

  • 拖動左側滑桿調整起始時間
  • 拖動右側滑桿調整結束時間
  • 拖動時立即生效，不需要確認
  • 拖動結束後自動儲存到選項

5.3 微調按鈕

  • 點擊 ◁：起始時間後退 0.5 秒
  • 點擊 ▷：結束時間前進 0.5 秒
  • 長按：沒有效果，只能單擊

5.4 時間軸自動縮放

時間軸總是以「原始起止時間」為中心，向兩側各留出 1/6 的餘量。所以即使微調過起止時間，原始位置仍可以看到。這個縮放是自動的，不需要手動設定。

6. 播放與重複機制

6.1 播放流程

  1. 載入媒體檔案
  2. 定位到起始時間
  3. 播放到結束時間
  4. 暫停，等待重複間隔
  5. 重複次數未到 → 回到起點繼續
  6. 重複次數到了 → 停止，等待手動操作

6.2 重複次數

值行為
1 到 9固定次數
10無限循環，直到手動停止

6.3 重複間隔

值含義
1 到 30固定秒數
31句子時長（本句播放時間）

間隔會自動除以播放速度，所以加速播放時間隔也相應縮短。

6.4 重播按鈕

點擊 ↺ 按鈕：

  • 立即停止當前播放
  • 把重複計數重置為 0
  • 從起點重新開始
  • 臨時的重複次數被設為「無限」（不影響選項裡的設定）

6.5 播放速度

  • 透過 0.5 / 1.0 按鈕在 0.5x 和 1.0x 之間切換
  • 透過 📊 按鈕彈出選單選擇 0.50x 到 2.00x
  • 速度調整立即作用於當前播放

7. 正反面顯示邏輯

7.1 正面顯示

  • 關鍵片語（若有彩色標記）
  • 字幕一（原文）
  • 字幕二（譯文）—— 取決於選項「開啟卡片時顯示譯文」

字幕二預設隱藏，讓學習者先聽原文。

7.2 背面顯示

  • 關鍵片語
  • 字幕一
  • 字幕二（始終顯示）
  • 備註（Note）
  • 來源（From）

7.3 正面自動播放

選項「開啟卡片時自動播放」開啟時（預設開啟）：

  • 正面開啟後，媒體載入完成即自動播放
  • 背面開啟時不自動播放

7.4 關鍵片語的擷取

字幕一裡所有 <fN> 包裹的內容會被擷取出來，逐行顯示在字幕上方。例如：

SrtText1: "I <f1>couldn't agree more</f1> with you."

會顯示為：

couldn't agree more
I couldn't agree more with you.

這是為了讓學習者在看整句之前，先關注重點片語。

8. TTS 語音朗讀

8.1 觸發條件

當 Timeline 欄位的副檔名為 NaN，或媒體檔案缺失時，程式自動切換到 TTS 模式，用系統語音合成朗讀字幕一。

8.2 語音選擇

平台偏好語音
iOS / iPadOSSamantha（美式女聲）
Windows / macOSDavid（美式男聲）
Android任意美式英語語音

如果偏好語音不存在，則選第一個 en-US 語音，再次選任意 en 語音。

8.3 TTS 與媒體播放的差異

  • TTS 模式沒有時間軸拖動功能（時間軸隱藏）
  • TTS 的重複和間隔邏輯與媒體播放一致
  • 速度按播放速度設定（0.1 到 10 之間）
  • 音量固定為 0.8

8.4 TTS 播放控制

  • 播放／暫停按鈕同樣適用於 TTS
  • 重播按鈕會停止當前 TTS 並從頭朗讀
  • 切換卡片時自動停止 TTS

9. 詞典與 AI 查詢

9.1 使用方式

  1. 選取字幕中要查詢的文字
  2. 點擊 🔍 按鈕

如果沒有選取任何文字，預設查詢字幕一的全部內容。

9.2 查詢分流

條件行為
選取文字不含空格（單字）開啟歐路詞典
選取文字含空格（片語）呼叫 AI 分析

9.3 詞典 URL

eudic://dict/選取文字

9.4 AI 分析

  • Windows：把 prompt + 文字複製到剪貼簿，使用者自行貼到 AI
  • iPhone / Android：呼叫豆包 App 直接傳送

Prompt 固定為：「請嚴格直譯並分析其中片語及知識點：」

9.5 選取文字的取得

  • 桌面版：在字幕區用滑鼠選取，放開時記錄
  • iOS / Android：用手指選取，點擊查詢按鈕時讀取

iOS 因為 touch 事件的特殊性，選取文字需要額外記錄。

10.2 三個滑桿

五種顏色可選：黃、綠、橙、粉、白。見下一節。

10.4 關閉選項面板

點擊左上角的 "Close" 或再次點擊 ⚙。

12. 控制列拖動與定位

12.1 拖動方式

  • 長按按鈕列任意空白處（不是按鈕本身）即可拖動
  • 拖動時頁面滾動被禁止
  • 放開後自動儲存新位置

12.2 位置邊界

控制列不會超出畫面邊界。如果被拖出畫面，下一次載入時會自動回到畫面內。

12.3 位置持久化

控制列的位置儲存在選項字串的最後兩個欄位，下次開啟卡片時恢復。

12.4 初始位置

首次開啟時控制列位於畫面水平置中、垂直方向大約 60% 位置（使用 top: 60vh）。

13. 選項持久化

13.1 儲存位置

儲存在瀏覽器的 localStorage，鍵名格式：

卡片ID_vp_notes_opts_1

卡片 ID 從 Timeline 欄位的第一段取得。

13.2 儲存內容

共 10 個欄位，用 | 分隔：

序欄位範圍
0自動播放0 / 1
1先顯示譯文0 / 1
2顯示影片0 / 1
3重複次數1 ~ 10
4重複間隔1 ~ 31
5影片高度32 ~ 320
6播放速度50 ~ 300（即 0.50x ~ 3.00x）
7顏色主題0 ~ 4
8控制列 X 座標像素
9控制列 Y 座標像素

13.3 儲存時機

  • 關閉選項面板時
  • 調整播放速度時
  • 拖動控制列結束時
  • 調整時間軸滑桿結束時

13.4 跨裝置同步

localStorage 是本地的。如果卡片在多個裝置上使用，選項需要分別設定。Anki 同步不會同步 localStorage。

14. Timeline 欄位格式

14.1 基本格式

媒體前綴,季號,集號,標題,副檔名,-開始時間-結束時間

14.2 範例

範例解讀
atomic_habits,,01,,.mp3-0029120-0032325atomic_habits_01.mp3，從 2.912s 到 3.2325s
cwe,,01,,-0005743-0006807-0006829-0007421cwe_01，多段區間
sf,s05,e08,某劇,.mp4-0012345-0023456sf_s05e08.mp4，從 1.2345s 到 2.3456s

14.3 欄位說明

部分說明
媒體前綴媒體檔案名前綴
季號可為空。為空時檔名格式為 前綴_集號
集號單元編號，如 01、053
標題可選。有值時用於 From 欄位
副檔名媒體檔案副檔名。NaN 表示純 TTS 模式
時間區間多個 -時間，單位為毫秒。程式取第一個和最後一個

14.4 檔名產生規則

如果季號為空：

前綴_集號.副檔名

如果季號非空：

前綴_s季號e集號.副檔名

14.5 副檔名缺省

副檔名為空、.mp4 或 webm 時：

  • Windows 使用 .webm
  • 其他平台使用 .mp4

這解決了 Anki 同步時不同平台影片編碼相容問題。

14.6 多區間播放

一個 Timeline 可以包含多個時間點：

前綴,,01,,-0005743-0006807-0006829-0007421-0007710-0008596

程式會取第一個值和最後一個值，中間部分作為播放範圍。用於把多個連續片段合併為一張卡片。

15. 平台差異

15.1 Windows

  • 字型：Segoe UI + STXihei，18px，左右各 12px 邊距
  • 按鈕列高度 32 像素（略小）
  • 影片編碼使用 .webm
  • AI 分析是複製到剪貼簿，不自動跳轉
  • 不支援錄音

15.2 macOS

  • 使用預設系統字型
  • 影片編碼使用 .mp4
  • AI 分析呼叫豆包 App

15.3 iOS / iPadOS

  • 控制列和選單被移到 HTML 根節點，避免渲染問題
  • 使用 Pointer Events 而不是 Mouse Events
  • 字幕選取需要 touch 結束事件記錄
  • 影片編碼使用 .mp4
  • 支援錄音

15.4 Android

  • 支援錄音
  • 影片編碼使用 .mp4
  • 字型大小略大

15.5 時間精度微調

非桌面平台會有一個 0.12 秒的微調偏移，用於補償 iOS/Android 影片播放的延遲。桌面平台偏移為 0。

16. 常見問題

Q1：卡片開啟後一片黑，只有一個控制列
檢查：
  • Timeline 欄位是否有效（逗號數量正確、有時間區間）
  • 媒體檔案是否放在 collection.media 目錄下
  • 副檔名是否匹配當前平台（Windows 用 .webm，其他用 .mp4）
Q2：卡片沒有聲音
  • 檢查 Timeline 裡的時間區間是否超出媒體實際長度
  • Windows 下 .mp4 無法播放，需要轉成 .webm 或純音訊格式
  • 如果副檔名是 NaN，則使用系統 TTS，檢查系統是否有可用的英語語音
Q3：影片畫面顯示不出來
在選項裡開啟「顯示影片」開關。預設是關閉的，只播放音訊。
Q4：正面看不到譯文
這是設計行為。譯文本應在背面顯示。如果想在正面就顯示，在選項裡開啟「先顯示譯文」。
Q5：控制列拖到畫面外找不到了
重新整理卡片。程式會在下一次載入時把控制列自動放回畫面內。也可以清除 localStorage 恢復預設位置。
Q6：選項不能儲存
  • 檢查瀏覽器是否允許 localStorage（隱私模式會停用）
  • 檢查卡片 ID（Timeline 欄位第一段）是否穩定
  • 清除瀏覽器快取會遺失選項
Q7：點了查詢按鈕沒反應
  • 檢查裝置是否安裝了歐路詞典（iOS）或豆包 App（Android/iOS）
  • Windows 下是複製到剪貼簿，需要使用者手動貼上
  • 檢查選取文字是否為空
Q8：TTS 朗讀語言不對
TTS 固定使用英語朗讀。如果 SrtText1 是其他語言，效果會很差。TTS 模式只建議用於英語內容。
Q9：時間軸滑桿拖不動
  • 檢查時間軸是否可見（TTS 模式下時間軸隱藏）
  • 檢查觸控點是否準確落在滑桿上（滑桿比較小）
  • 嘗試重新開啟卡片
Q10：切換到下一張卡時聲音還在響
正常情況不會。程式在載入新卡片時會自動停止上一張。如果出現這種情況，檢查是否有其他擴充功能或瀏覽器行為干擾。重新整理頁面即可。
Q11：重複播放只播一次就停了
  • 檢查「重複次數」選項是否為 1
  • 檢查「重複間隔」是否設定得太長（31 = 句子時長）
  • 檢查是否手動點過播放按鈕（會重置計數）
Q12：時間軸上的黃點和滑桿位置很奇怪
黃點代表原始起止時間，滑桿代表你調整後的起止時間。如果黃點和滑桿重合，說明沒調整過。如果偏移很大，說明你大幅調整過時間範圍。
Q13：關鍵片語區顯示的內容不對
關鍵片語從 SrtText1 裡的 <f1> 到 <f7> 標記擷取。如果沒有標記，只顯示整句。如果想顯示關鍵片語，需要在桌面版 VlsPlayer 裡先用彩色標記標出片語。
Q14：控制列會擋住字幕
拖動控制列到畫面底部或頂部。或者調整影片高度，為控制列留出空間。
