1. 程序简介

语音识别工具箱用于处理视频/音频字幕，提供两种工作模式：

模式作用输出位置
ASR生成SRT字幕文件用 ASR 模型识别语音，生成字幕ASR文件夹
对齐SRT字幕时间线把已有 ASR 字幕与源字幕对齐源文件夹（覆盖原文件）

程序支持多文件批量处理，可中途取消。

2. 运行环境

  • Windows 系统
  • 程序目录下需存在 lib\ffmpeg.exe
  • 使用生成模式时，需已下载对应 ASR 模型
  • ASR 模型分小、中、大三种，越大越准，也越慢

4. 快速开始

4.1 生成 SRT 字幕

  1. 选择 ASR生成SRT字幕文件
  2. 设置 源文件夹（媒体文件所在目录）
  3. 设置 ASR文件夹（SRT 输出目录）
  4. 在左侧列表中选中要处理的媒体文件（可多选）
  5. 按需勾选 如果ASR生成的SRT文件存在，覆盖吗?
  6. 点击 OK
  7. 观察日志区，等待处理完成
  8. 到 ASR文件夹 取同名 .srt 文件

4.2 对齐 SRT 时间线

  1. 选择 对齐SRT字幕时间线
  2. 设置 源文件夹（内含待修正的 .srt）
  3. 设置 ASR文件夹（内含同名 ASR .srt）
  4. 按需勾选 在对齐时间线之前合并句子碎片?
  5. 按需调整四个对齐参数，或点 默认值
  6. 在左侧列表中选择文件
  7. 点击 OK
  8. 完成后，源文件夹中的 .srt 被更新

5. 参数详解

时间漂移窗口 (秒)

允许字幕时间戳与音频之间的最大偏移。默认 30 秒。如果字幕整体偏移较大，可适当调大。

搜索文本长度

对齐时用于匹配的文本窗口长度。默认 16。越大越稳，但越慢；越小越快，但可能匹配不准。

最小时间间隙 (毫秒)

两句字幕之间允许的最小间隔。默认 1 毫秒。用于防止字幕在时间轴上重叠。

最大错误阈值

匹配时允许的最大错误率。默认 0.15。越大越宽松，越小越严格。

6. 处理流程

6.1 生成模式

  1. 打开媒体文件，读取总时长
  2. 按 120 秒 一段切分
  3. 用 lib\ffmpeg.exe 抽取 16kHz 单声道 wav
  4. 调用 ASR 模型识别
  5. 非最后一段丢弃最后一句，避免与下一段重叠
  6. 全部完成后，写入 ASR 文件夹

6.2 对齐模式

  1. 读取源 SRT 和 ASR SRT
  2. 如勾选，先合并句子碎片
  3. 按四个参数对齐
  4. 结果写回源 SRT

7. 常见问题

Q1：读取媒体文件信息失败
媒体文件无法打开或格式不支持。检查文件是否完整、路径是否含特殊字符。
Q2：没有ASR字幕文件
对齐模式下，ASR 文件夹里没有与源 SRT 同名的文件。先跑一次生成模式，或确认文件名一致。
Q3：自动识别语音失败
模型加载失败或音频抽取失败。检查模型是否已下载、lib\ffmpeg.exe 是否存在。
Q4：最后几分钟没有结果
可能原因：媒体总时长读取失败或被低估；某段识别失败导致中断；最后一段没有识别出内容。建议查看日志最后几行，确认停在哪一步。
Q5：源文件夹里的 SRT 会被覆盖吗？
对齐模式会覆盖源 SRT，建议先备份。生成模式下，ASR 文件夹已存在同名 SRT 时，未勾选“覆盖”则跳过。
Q6：可以中途取消吗？
可以。点取消后当前段结束会停止，已识别部分不会保存。
Q7：为什么文件列表里看不到某个文件？
列表只显示支持的扩展名。对齐模式只显示 .srt；生成模式只显示视频/音频扩展名。若扩展名不在支持列表内，不会出现。
Q8：修改参数后没生效？
参数在点击 OK 时读取。修改后直接点 OK 即可。若输入值超出范围，会弹窗提示并自动纠正。

8. 注意事项

  1. 处理长文件耗时较长，建议先用短视频测试。
  2. 模型越大越准，也越慢、越吃内存。
  3. 临时 wav 文件会自动删除，异常退出可能残留。
  4. 对齐模式会直接改写源目录中的 .srt，请先备份。
  5. 程序退出时会保存当前设置，下次启动自动恢复。
  6. 建议保持 lib\ffmpeg.exe 与程序版本匹配。
