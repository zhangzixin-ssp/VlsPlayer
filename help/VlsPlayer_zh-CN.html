1. 程序概述与界面全景

1.1 定位

VlsPlayer 是一款面向语言学习者的字幕播放器与编辑器。它把播放、字幕编辑、波形调整、语音识别、跟读录音、词典查询、AI 翻译、Anki 导出整合在一个界面里，让“看视频—改字幕—做笔记—导出卡片”这条链路可以在一个窗口完成。

1.2 主要能力

  • 波形可视化：直接拖拽滑块修改字幕时间轴
  • 五种播放模式：普通、单句、扮演角色1/2、选区循环
  • 逐句跟读录音，自动 ASR 评分
  • 听写模式：隐藏原文，凭听写输入
  • 彩色标记（7 种颜色）+ 批注 + 段落标签
  • 校对字幕：最多同时加载 4 个参考字幕
  • 过滤显示：按批注 / 标记过滤
  • 本地 ASR：sherpa-onnx 模型，可对字幕片段单独识别
  • 词典、AI 分析、TTS：内置或外置浏览器打开
  • 双引擎播放：MPV（默认）和 VLC，可在选项中切换
  • 双语字幕管理：字幕一（原文）、字幕二（译文）分别编辑
  • 三个配套工具箱：SRT / TXT / ASR
  • 四种语言界面、16+ 内置主题，可自定义主题

1.3 界面整体布局

主窗口从上到下分为四层：

层内容是否可隐藏
标题栏自定义标题栏，显示文件名全屏时隐藏
工具栏所有快捷按钮全屏时隐藏
主区域（上下可调） 上：字幕表格
下：媒体画面 + 字幕编辑 + 批注/校对 		表格可隐藏
波形编辑器波形区 + 滑块区无媒体时隐藏
录音面板跟读时显示跟读关闭时隐藏

1.4 分隔条

  • SplitterClient：表格与下方详情区之间，拖动调整比例
  • SplitterMedia：视频画面与右侧文字区之间，水平拖动
  • SplitterRe：字幕编辑区与批注区之间，垂直拖动
  • SplitterBottom：主区域与波形编辑器之间，垂直拖动

窗口尺寸、分隔条位置、面板可见性都会在退出时保存到 INI，下次启动自动恢复。

2. 字幕目录与文件管理

字幕目录面板默认停靠在主窗口左侧，可通过工具栏最左侧的按钮切换显示方式。

2.1 显示模式

模式行为
自动停靠（默认）鼠标移到窗口左边缘时自动显示，移开后隐藏
隐藏完全不显示

通过工具栏最左侧的按钮切换。自动模式下，鼠标移开后 3 秒自动隐藏。

2.2 目录管理

  • 下拉框：选择已保存的 SRT 目录
  • +：添加 SRT 目录（自动去重）
  • −：删除当前选中目录

所有目录保存在 INI 的 [SrtDir] 段，程序退出时写入，启动时读取。

2.3 文件列表

  • 列出当前目录下所有 .srt 文件
  • 单击选中并加载
  • 程序启动时自动选中上次打开的文件
  • 无历史记录时选中列表中的第一个

2.4 工具箱入口

目录面板顶部的三个按钮打开配套工具：

按钮打开

ASR 工具箱VlsAsrTools.exe（外部程序）

3. 打开媒体与字幕

3.1 打开流程

  1. 在文件列表中单击一个 .srt 文件
  2. 程序按以下顺序加载：
    1. 读取 .srt 字幕
    2. 读取同名 .snt 文件（批注、段落标签、格式化文本）
    3. 读取同名 .dic 文件（听写内容）
    4. 读取同目录 ProofSrt.lst（校对文件列表，若存在）
    5. 按当前过滤条件应用过滤
  3. 查找同名媒体文件（按 VIDEO_EXTS 优先，其次 AUDIO_EXTS），自动加载
  4. 查找同名 .wfm 波形缓存文件，不存在则用 ffmpeg 生成
  5. 恢复上次退出时该文件的播放位置

3.2 支持的字幕编码

读取 SRT 时自动识别以下编码：

  • UTF-8（含 BOM / 无 BOM）
  • UTF-16 LE（BOM）
  • UTF-16 BE（BOM）
  • 系统默认编码（ANSI）

无 BOM 时会先做 UTF-8 合法性验证，不合法则按系统默认编码读取。

3.3 支持的媒体格式

视频：mp4、mkv、avi、mov、flv、webm、3gp、3g2、wmv、asf、vob、mts、m2ts、ts、mpeg、mpg、m4v

音频：wav、mp3、ogg、flac、aac、wma、m4a、aiff、aif、alac、wavpack、ape、mid、midi

3.4 波形缓存

.wfm 文件是用以下命令生成的 4kHz 单声道 PCM 缓存：

ffmpeg.exe -i 媒体文件 -ar 4000 -ac 1 -acodec pcm_s16le -f wav -y 输出.wfm

生成过程最长等 30 秒。生成失败时波形区留空，字幕编辑不受影响。

6. 字幕编辑区

位于详情区右上方，是一个 RichEdit 控件。

6.1 显示规则

  • 第一段显示字幕一（原文），如果原文含彩色标记，会以对应颜色渲染
  • 第二段显示字幕二（译文），使用较小字号
  • 听写模式下字幕一显示为一行短横线（隐藏原文）

6.2 编辑行为

  • 直接编辑，输入后失焦或停留 1 秒自动保存到 SRT
  • 按回车分两段：第一段是字幕一，第二段是字幕二
  • 编辑状态下的输入不会被立即写盘，等冷却时间结束后才提交，避免频繁写盘

6.3 浮动编辑框

选项开启"浮动字幕编辑框"后：

  • 编辑框脱离面板，浮在表格上方
  • 双击表格行弹出
  • 鼠标移开或失焦自动隐藏
  • 位置随行高自动调整
  • 高度随内容自动调整，最大不超过屏幕的三分之二

6.4 右键菜单

在编辑框中右击，出现以下菜单项：

菜单项快捷键行为
剪切Ctrl+X剪切选中文本
复制Ctrl+C复制选中文本
粘贴Ctrl+V粘贴到光标位置
复制主字幕复制字幕一（不含译文）
导出媒体片段用 ffmpeg 导出选中字幕对应的视频片段
词典Ctrl+D查询选中词的释义
AI 分析Ctrl+I把选中文本送到 AI 分析
TTS 朗读Ctrl+T用 Edge TTS 朗读选中文本

7. 批注、听写与校对区

位于详情区右下方。这块区域根据当前状态切换显示以下之一：

  • 批注（Remark）
  • 听写（Dictation）
  • 校对显示（Proof）
  • ASR 识别结果

7.1 切换显示源

上方的按钮条决定显示哪一种：

按钮显示
批注当前字幕的 Remark
校对 0~3对应校对文件的匹配结果
听写当前字幕的 Dictation（听写模式下自动切换）

7.2 批注编辑

  • 批注可以多行，直接在框内输入
  • 输入后失焦或停留 1 秒自动保存到 .snt 文件
  • 批注会触发"有批注"过滤

7.3 校对显示

使用 RTF 颜色编码显示匹配结果：

颜色含义
灰上下文（匹配句前后各一句）
绿完全匹配
红不匹配或差异处
蓝差异字符

7.4 浏览校对上下文

在校对显示区右击，选"浏览更多字幕"，显示校对文件中当前时间点前后各 10 条字幕。

8. 标记（Flags）

8.1 七种颜色

对应格式化文本标签 <f1> ~ <f7>，语义可在选项中自定义（默认对应重点、表达、发音、语法、俚语、短语、词汇）。

8.2 添加标记

  1. 在字幕编辑框中选中要标记的文字
  2. 在标记条上点击对应颜色的旗子
  3. 选中文字被包裹为 <fN>文字</fN>，写入 .snt 文件

8.3 清除标记

选中已标记的文字，点击标记条最后一个"X"图标即可清除。

8.4 显示方式

在选项中设置：

方式效果
彩色文字标记文字显示为对应颜色
彩色下划线标记文字保持原色，下方显示彩色下划线

8.5 过滤显示

点击标记条上任意旗子可以切换该标记的过滤显示，例如只看含 <f1> 的字幕。

8.6 段落标签

除了 7 种颜色标记，还有三种段落标签用于标记句子结构：

标签含义对说话人推断的影响
s新场景开始重置说话人为角色 1
n旁白说话人 = 0
a续行（同一角色）沿用上一条的说话人

推断规则完整描述：

if 含 n → Speaker = 0
else if 是第一条 或 含 s → Speaker = 1
else if 含 a → Speaker = 上一条的 Speaker
else if 上一条 Speaker ≠ 1 → Speaker = 1
else → Speaker = 2

8.7 切换段落标签

在编辑框右击可切换：

  • 切换新/旧场景（s）
  • 切换旁白/歌词（n）
  • 切换续行/单行（a）

9.6 翻页

  • 翻页时长由工具栏的波形宽度决定，默认每页 20 秒
  • 翻页重叠 5 秒，避免跨页字幕丢失
  • 翻到最后一页时自动前移，让音频占满整页

9.7 拖拽约束

  • 左滑块不小于上一条字幕的结束时间 + 1ms
  • 右滑块不大于下一条字幕的起始时间 − 1ms
  • 字幕最小持续时间为滑块宽度的 2 倍（约 12px 对应的时间）
  • 整体平移时，前后边界同时约束
拖拽过程中只做临时修改，松开鼠标才会记录为可撤销操作。

10. 播放器与播放模式

10.1 播放引擎

引擎优点缺点
MPV（默认）时间精度高，播放流畅需要 mpv 运行库
VLC兼容性好时间精度约 150ms

切换引擎后需要重新加载媒体文件。

10.2 播放模式

模式行为
普通从当前位置一直播放到媒体结尾
单句逐句播放，每句结束后按暂停设置处理
扮演角色1遇到角色 2 的台词静音，只播角色 1 和旁白
扮演角色2遇到角色 1 的台词静音，只播角色 2 和旁白
选区循环循环播放选中区间（在波形区拖拽触发）

10.3 暂停设置

仅单句模式下生效。每句播放结束后的暂停时长：

选项时长
暂停不暂停，直接下一句
句长本句的播放时长
1s / 2s / 3s / 9s固定时长

10.4 重复次数

单句模式下生效：1、2、3、6、9、无限。

10.5 音量

  • 媒体音量：0 ~ 100%
  • 噪音音量：0 ~ 100%（与媒体音量混合输出）
  • 混音开关：开启后播放媒体时同时播放背景噪音

噪音源来自程序目录 lib\noises\ 下的 mp3 文件，随机选择。

10.6 播放到结尾的动作

选项行为
暂停停在结尾
重播从头重新播放
播下一集切换到文件列表中的下一个 SRT

10.7 全屏

  • 快捷键 Ctrl+Enter 进入全屏
  • 全屏时隐藏所有面板，视频占满屏幕
  • 按 Esc 或再次 Ctrl+Enter 退出
  • 退出后恢复原来的面板布局

10.8 播放位置精度

  • MPV：使用 mpv 原生时间，误差极小
  • VLC：使用自维护的高精度计时器，播放中误差约 50ms，暂停后读取原生时间

11. 跟读与录音

11.1 开启

点击工具栏的"跟读"按钮，录音面板在窗口底部展开，同时波形编辑器上移。

11.2 录音面板

按钮说明
录音开始 / 停止录音。录音中图标变红
播放录音回放本次录制的音频
自动跟读循环播放当前句，方便反复跟读
导出把选中字幕的所有录音合并为一个 MP3

11.3 录音参数

参数值
采样率16 kHz
声道2（保存时同时输出单声道副本给 ASR）
位深16 bit
最长时长当前字幕时长的 5 倍

11.4 自动识别

录音停止后：

  1. 程序调用 ASR 模型对录音识别
  2. 识别结果与字幕原文对比，计算词级相似度
  3. 相似度 ≥ 0.85 显示绿色，否则红色
  4. 结果显示在批注区域

11.5 录音文件

录音保存在：

程序目录\record\字幕文件名\字幕名_序号.wav

例如：record\某剧集\某剧集_0001.wav。

11.6 导出 MP3

  1. 在表格中选中一段范围的字幕
  2. 点击录音面板的"导出"按钮
  3. 选择保存位置
  4. 程序用 ffmpeg 拼接录音为 192kbps 的 MP3

只导出存在录音文件的字幕，缺失的跳过。

12. 听写模式

12.1 进入

点击工具栏的"听写"按钮（图标是高亮状态）。

12.2 界面变化

  • 表格中的字幕一用一行短横线替代，长度与原文一致
  • 批注区切换为听写输入框，显示当前字幕的听写内容
  • 字幕编辑区变为可编辑的空白区

12.3 使用

  1. 播放当前句
  2. 在编辑区输入听到的内容
  3. 失焦或停留 1 秒自动保存到 .dic 文件
  4. 点"下一句"继续下一句

12.4 退出

再次点击"听写"按钮退出，表格恢复显示原文。

12.5 听写内容保存位置

听写内容保存在与 SRT 同名的 .dic 文件中，格式为：

@t@:时间毫秒
听写内容

每条听写以 @t@ 行分隔，程序通过时间中值匹配到对应字幕。

13. ASR 语音识别

13.1 系统架构

Delphi 程序
   │
   ├─ 启动 sherpa-onnx-offline-websocket-server.exe (端口 6006)
   │
   ├─ 启动 asr_engine.py (Python 桥接, 端口 9001)
   │
   └─ HTTP POST WAV → 9001 → WebSocket → 6006 → 返回 JSON

13.2 前置条件

  • 已安装 Python，且已 pip install numpy websockets
  • 程序目录下 sherpa\ 内有：
    • sherpa-onnx-offline-websocket-server.exe
    • asr_engine.py
    • 模型目录（小/中/大，按选项选择）
  • 端口 6006 和 9001 未被其他程序占用

13.3 模型选择

模型大小加载时间
小模型120 MB约 30 秒
中模型420 MB约 90 秒
大模型1.2 GB约 5 分钟

模型越准越慢。第一次加载后常驻内存，后续调用无需重新加载。

13.4 对字幕片段识别

  1. 在表格中选中要识别的字幕行（可多选，会合并音频）
  2. 点击批注框上方的"ASR"按钮
  3. 程序用 ffmpeg 抽取片段音频，调用 ASR 识别
  4. 结果显示在批注区，包含识别文本和相似度

13.5 结果含义

颜色相似度
绿色≥ 0.85
红色< 0.85

13.6 应用识别时间

识别完成后，可将 ASR 返回的精确起止时间应用到当前字幕（仅当识别结果与当前字幕匹配时可用）。

13.7 单例保护

ASR 资源是单例的，同一时刻只能有一个程序使用。若已有一个程序在用，另一个启动会失败并提示。

14. 校对字幕

14.1 校对文件列表

在 SRT 同目录创建 ProofSrt.lst，每行一条：

标识符|文件夹路径|字幕类型编号
  • 标识符：显示在按钮上的 1 个字符（建议用 A、B、C、D）
  • 文件夹路径：校对字幕所在目录，末尾建议带斜杠
  • 字幕类型编号：0~4，对应第 5 节的字幕类型

最多同时加载 4 个校对文件。

14.2 通过选项添加

  1. 打开选项 → 通用
  2. 在"校对文件夹"区域点击 +
  3. 选择目录，输入标识符和字幕类型
  4. 确定后写入 ProofSrt.lst

14.3 使用校对

  1. 打开主 SRT 文件
  2. 点击批注区上方的校对按钮（0~3）
  3. 程序用主字幕的当前行在校对文件中搜索匹配
  4. 匹配结果用彩色 RTF 显示

14.4 匹配算法

校对过程使用与时间轴对齐相同的搜索算法：

  1. 用当前句头部字符串在主字幕中定位
  2. 用上一句尾部字符串辅助定位
  3. 用当前句单词数定位
  4. 逐级回退，找到最优匹配

14.5 显示区颜色

颜色含义
灰匹配句前后的上下文
绿完全匹配
红不匹配的部分
蓝字符级差异

14.6 浏览上下文

在校对显示区右击，选"浏览更多字幕"，显示校对文件中当前时间点前后各 10 条字幕的原文。

15. 过滤显示

15.1 过滤批注

工具栏的"批注"按钮：

  • 按下：只显示有批注的字幕
  • 弹起：显示所有字幕

15.2 过滤标记

工具栏的标记条可以同时激活多种标记过滤。规则：

  • 至少包含一个被选中的标记即可显示
  • 多个标记之间是"或"关系

15.3 组合过滤

批注和标记可以同时生效，之间也是"或"关系。

15.4 过滤模式下的限制

过滤模式（FUseMapping = True）下禁止以下操作：
  • 插入字幕
  • 删除字幕
  • 合并字幕
  • 分割字幕
  • 批量修改时间
只允许修改现有字幕的：文本、批注、标记、听写、时间。

违反时对应的按钮会变灰，无法点击。

15.5 退出过滤

取消所有过滤条件即回到完整视图。过滤状态会保存到 INI。

16.1 词典

在字幕或批注中选中要查询的单词或短语，然后：

  1. 把 AI Prompt + 选中文本放入剪贴板
  2. 打开对应 AI 网站（或复用已打开的标签页）

  • 通义千问
  • 豆包

默认 Prompt 要求 AI 直译并分析英语知识点，输出纯文本。可在选项中修改。

实现方式：

  1. 生成一个包含选中文本的 HTML 文件
  2. 用 Microsoft Edge 打开
  3. 模拟 Ctrl+Shift+U 触发 Edge 的朗读功能

首次调用会打开 Edge 窗口，后续调用复用该窗口并刷新内容。

17. 工具箱

17.1 SRT 工具箱

点击字幕列表面板的 SRT 工具箱按钮打开，是一个独立的外部程序 VlsSrtTools.exe。功能包括字幕批量处理、AI 翻译文本生成、按字幕分割视频、Anki 导出等。详细说明见配套的《SRT 工具箱操作说明书》。

17.2 TXT 工具箱

在程序内打开一个小窗口。功能：把纯文本文件按句子切分，生成 SRT 字幕。

使用步骤

  1. 选择要处理的 TXT 文件
  2. 选择 SRT 输出目录
  3. 设置分割依据（如 Chapter，遇该前缀则开始新文件）
  4. 点击 OK

输出

  • 不分割：生成一个与 TXT 同名的 SRT
  • 按分割标志拆分：生成多个 SRT，文件名带序号 _01.srt、_02.srt...

时间分配

每句默认 10 秒，间隔 1 秒。生成后的时间轴仅作占位，可用 ASR 对齐修正。

17.3 ASR 工具箱

点击字幕列表面板的 ASR 工具箱按钮打开，是一个独立的外部程序 VlsAsrTools.exe。功能包括分段 ASR 生成字幕、时间轴对齐等。详细说明见配套的《语音识别工具箱操作说明书》。

20. 文件格式与目录结构

20.1 关联文件

扩展名内容
.srt字幕正文
.snt批注 + 段落标签 + 格式化文本
.dic听写内容
.wfm波形缓存
ProofSrt.lst校对文件列表（可选）

20.2 SNT 文件格式

@t@:时间中值毫秒
@p@:段落标签
@f@:格式化文本
批注第一行
批注第二行
@t@:下一条的时间中值
...
  • @t@: 表示一条字幕的开始
  • @p@: 段落标签（s/n/a）
  • @f@: 格式化文本（含 <f1>~<f7> 标记）
  • 其余行都是批注正文

若某条字幕无批注、无标签、无格式化文本，则不会写入 .snt。整个 .snt 为空时自动删除。

20.3 DIC 文件格式

@t@:时间中值毫秒
听写第一行
听写第二行
@t@:下一条...

20.4 目录结构示例

字幕目录\
├── 某剧集.srt
├── 某剧集.snt
├── 某剧集.dic
├── 某剧集.wfm
├── 某剧集.mp4
├── ProofSrt.lst
└── backup\
    ├── 某剧集_20240101_1200.srt
    └── 某剧集_20240101_1200.snt

位于程序目录的 VlsPlayer.ini。主要段：

段内容
[Main]语言、主题、播放器、ASR模型、自动保存、备份数、AI设置
[Display]字幕显示方式、过滤、行距、对齐、时间格式
[Play]播放模式、倍速、重复、暂停、音量、噪音
[SrtDir]最近使用的 SRT 目录列表
[Theme]自定义主题
[WfEditor]波形分页时长、振幅
[Last]窗口位置、上次打开的字幕、播放时间

22. 常见问题与排错

Q1：字幕列表里看不到文件
检查 SRT 目录是否正确，目录下是否有 .srt 文件。刷新方式：切换目录再切回。
Q2：波形区为空
原因通常是以下之一：
  • 同目录下没有媒体文件
  • 媒体文件名与 SRT 不同名
  • 程序目录的 lib 文件夹下没有 ffmpeg.exe
  • ffmpeg 生成 wfm 时失败（媒体格式不支持或时长过长）
Q3：修改字幕时间后重开程序丢失
未保存。SRT 修改后需要手动保存（Ctrl+S）或等自动保存。也可以使用"退出时自动保存"选项。
Q4：过滤模式下无法插入字幕
这是设计行为。过滤模式下禁止改变字幕结构，先取消过滤（点掉工具栏的批注/标记过滤）。
Q5：ASR 识别失败
检查以下项：
  • 模型是否已下载到 sherpa\模型名\
  • sherpa\sherpa-onnx-offline-websocket-server.exe 是否存在
  • sherpa\asr_engine.py 是否存在
  • Python 是否安装并已 pip install numpy websockets
  • 端口 6006 和 9001 是否被占用
Q6：词典 / AI 打开失败
在选项中检查 URL 是否有效。使用内置浏览器时，需安装 Edge WebView2 运行库。
Q7：跟读评分总是很低
检查：
  • 麦克风是否正常工作、音量是否合适
  • 录音环境是否安静
  • ASR 模型是否正确加载
  • 字幕原文与录音内容语言是否一致（模型是英文模型，对中文识别效果差）
Q8：彩色标记丢失
彩色标记保存在 .snt 文件中。若 .snt 未保存或丢失，标记会退化为普通文本。可尝试从 backup 子目录找回。
Q9：自动保存把修改覆盖了
程序保存前会自动备份到 backup 子目录，可在那里按时间戳找回历史版本。
Q10：切换主题后部分控件颜色不对
部分第三方控件不受主题控制。可在选项的主题面板中自定义颜色微调。某些控件需要重启程序才完全生效。
Q11：全屏后不知道怎么退出
按 Esc 或 Ctrl+Enter。
Q12：字幕时间调整后与音频不对齐
检查：
  • 播放引擎是 VLC 时误差较大，切到 MPV 试试
  • 使用波形编辑器拖拽滑块调整到精确位置
  • 使用 ASR 工具箱的"时间轴对齐"功能自动修正
Q13：播放时字幕滚动卡顿
可能是行高计算或重绘开销大。尝试：
  • 关闭"单行显示字幕"
  • 减小表格行间距
  • 关闭彩色标记显示
Q14：内置浏览器无法打开
需要安装 Microsoft Edge WebView2 Runtime。可从 Microsoft 官网下载。
