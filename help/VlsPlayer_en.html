1. Program Overview and Interface Panorama

1.1 Positioning

VlsPlayer is a subtitle player and editor for language learners. It integrates playback, subtitle editing, waveform adjustment, speech recognition, shadowing and recording, dictionary lookup, AI translation, and Anki export into a single interface, so the whole chain of "watch video — edit subtitles — take notes — export cards" can be completed in one window.

1.2 Main Capabilities

  • Waveform visualization: drag handles directly to modify subtitle timing
  • Five playback modes: normal, single sentence, role-play 1/2, selection loop
  • Sentence-by-sentence shadowing with automatic ASR scoring
  • Dictation mode: hide the original text and type what you hear
  • Color flags (7 colors) + remarks + paragraph tags
  • Proofreading subtitles: load up to 4 reference subtitles at once
  • Filtered display: filter by remark / flag
  • Local ASR: sherpa-onnx models, can recognize individual subtitle segments
  • Dictionary, AI analysis, TTS: opened in an internal or external browser
  • Dual-engine playback: MPV (default) and VLC, switchable in options
  • Bilingual subtitle management: Subtitle 1 (original) and Subtitle 2 (translation) edited separately
  • Three companion toolboxes: SRT / TXT / ASR
  • Four UI languages, 16+ built-in themes, customizable themes

3. Opening Media and Subtitles

3.1 Opening Flow

  1. Click an .srt file in the file list
  2. The program loads in the following order:
    1. Read the .srt subtitle
    2. Read the same-named .snt file (remarks, paragraph tags, formatted text)
    3. Read the same-named .dic file (dictation content)
    4. Read ProofSrt.lst in the same directory (proofreading file list, if present)
    5. Apply filtering according to the current filter conditions
  3. Find the same-named media file (VIDEO_EXTS first, then AUDIO_EXTS) and load it automatically
  4. Find the same-named .wfm waveform cache file; if it does not exist, generate it with ffmpeg
  5. Restore the playback position of that file from the last exit

3.2 Supported Subtitle Encodings

When reading SRT, the following encodings are detected automatically:

  • UTF-8 (with BOM / without BOM)
  • UTF-16 LE (BOM)
  • UTF-16 BE (BOM)
  • System default encoding (ANSI)

When there is no BOM, UTF-8 validity is checked first; if invalid, it is read using the system default encoding.

3.3 Supported Media Formats

Video: mp4, mkv, avi, mov, flv, webm, 3gp, 3g2, wmv, asf, vob, mts, m2ts, ts, mpeg, mpg, m4v

Audio: wav, mp3, ogg, flac, aac, wma, m4a, aiff, aif, alac, wavpack, ape, mid, midi

3.4 Waveform Cache

The .wfm file is a 4 kHz mono PCM cache generated with the following command:

ffmpeg.exe -i mediafile -ar 4000 -ac 1 -acodec pcm_s16le -f wav -y output.wfm

Generation waits up to 30 seconds. If generation fails, the waveform area is left empty and subtitle editing is unaffected.

6. Subtitle Editing Area

Located at the upper right of the detail area, this is a RichEdit control.

6.1 Display Rules

  • The first paragraph shows Subtitle 1 (original text); if the original text contains color flags, they are rendered in the corresponding colors
  • The second paragraph shows Subtitle 2 (translation) in a smaller font
  • In dictation mode, Subtitle 1 is shown as a line of dashes (hiding the original text)

6.2 Editing Behavior

  • Edit directly; input is saved to the SRT on focus loss or after 1 second of inactivity
  • Pressing Enter splits into two paragraphs: the first is Subtitle 1, the second is Subtitle 2
  • Input during editing is not written to disk immediately; it is committed after the cooldown, avoiding frequent disk writes

6.3 Floating Edit Box

When the "Floating subtitle edit box" option is enabled:

  • The edit box detaches from the panel and floats above the table
  • Double-clicking a table row opens it
  • It hides automatically when the mouse moves away or loses focus
  • Its position adjusts automatically with the row height
  • Its height adjusts automatically with the content, up to two-thirds of the screen

8. Flags

8.1 Seven Colors

Corresponding to the formatted text tags <f1> ~ <f7>; the meanings can be customized in options (by default: key point, expression, pronunciation, grammar, slang, phrase, vocabulary).

8.2 Adding a Flag

  1. Select the text to flag in the subtitle edit box
  2. Click the flag of the corresponding color on the flag bar
  3. The selected text is wrapped as <fN>text</fN> and written to the .snt file

8.3 Clearing a Flag

Select the flagged text and click the last "X" icon on the flag bar to clear it.

8.4 Display Modes

Set in options:

ModeEffect
Colored textFlagged text is displayed in the corresponding color
Colored underlineFlagged text keeps its original color with a colored underline below

8.5 Filtered Display

Click any flag on the flag bar to toggle filtered display for that flag, e.g. show only subtitles containing <f1>.

8.6 Paragraph Tags

Besides the 7 color flags, there are three paragraph tags used to mark sentence structure:

TagMeaningEffect on Speaker Inference
sNew scene beginsResets Speaker to Role 1
nNarrationSpeaker = 0
aContinuation (same role)Keeps the previous line's Speaker

Full inference rule:

if contains n → Speaker = 0
else if first line or contains s → Speaker = 1
else if contains a → Speaker = previous line's Speaker
else if previous line's Speaker ≠ 1 → Speaker = 1
else → Speaker = 2

8.7 Toggling Paragraph Tags

Right-click in the edit box to toggle:

  • Toggle new/old scene (s)
  • Toggle narration/lyrics (n)
  • Toggle continuation/single line (a)

9.6 Page Flipping

  • The page duration is determined by the toolbar's waveform width, 20 seconds per page by default
  • Pages overlap by 5 seconds to avoid losing subtitles across pages
  • When reaching the last page, it shifts back automatically so the audio fills the whole page

9.7 Drag Constraints

  • The left handle is not less than the previous subtitle's end time + 1 ms
  • The right handle is not greater than the next subtitle's start time − 1 ms
  • The minimum subtitle duration is twice the handle width (the time corresponding to about 12 px)
  • When shifting as a whole, both front and back boundaries are constrained at the same time
During dragging, only temporary changes are made; the operation is recorded as undoable only when the mouse button is released.

11.4 Automatic Recognition

After recording stops:

  1. The program calls the ASR model to recognize the recording
  2. The result is compared with the subtitle's original text to compute word-level similarity
  3. Similarity ≥ 0.85 is shown in green, otherwise in red
  4. The result is displayed in the remark area

11.5 Recording Files

Recordings are saved at:

Program directory\record\subtitle file name\subtitle name_index.wav

For example: record\SomeSeries\SomeSeries_0001.wav.

11.6 Exporting MP3

  1. Select a range of subtitles in the table
  2. Click the "Export" button on the recording panel
  3. Choose the save location
  4. The program concatenates the recordings into a 192 kbps MP3 with ffmpeg

Only subtitles with recording files are exported; missing ones are skipped.

12. Dictation Mode

12.1 Entering

Click the "Dictation" button on the toolbar (the icon is highlighted).

12.2 Interface Changes

  • Subtitle 1 in the table is replaced by a line of dashes matching the original length
  • The remark area switches to a dictation input box showing the current subtitle's dictation content
  • The subtitle editing area becomes an editable blank area

12.3 Usage

  1. Play the current sentence
  2. Type what you hear in the editing area
  3. Input is saved to the .dic file on focus loss or after 1 second of inactivity
  4. Click "Next sentence" to continue

12.4 Exiting

Click the "Dictation" button again to exit; the table shows the original text again.

12.5 Where Dictation Content Is Saved

Dictation content is saved in a .dic file with the same name as the SRT, in the format:

@t@:time in milliseconds
dictation content

Each dictation entry is separated by an @t@ line; the program matches it to the corresponding subtitle by the median time.

13. ASR Speech Recognition

13.1 System Architecture

Delphi program
   │
   ├─ Launch sherpa-onnx-offline-websocket-server.exe (port 6006)
   │
   ├─ Launch asr_engine.py (Python bridge, port 9001)
   │
   └─ HTTP POST WAV → 9001 → WebSocket → 6006 → return JSON

13.2 Prerequisites

  • Python installed, with pip install numpy websockets already run
  • In the program directory's sherpa\:
    • sherpa-onnx-offline-websocket-server.exe
    • asr_engine.py
    • Model directory (small/medium/large, selected per options)
  • Ports 6006 and 9001 not occupied by other programs

13.3 Model Selection

ModelSizeLoad Time
Small120 MBAbout 30 seconds
Medium420 MBAbout 90 seconds
Large1.2 GBAbout 5 minutes

The larger the model, the more accurate but slower. After the first load it stays in memory, so subsequent calls need no reload.

13.4 Recognizing Subtitle Segments

  1. Select the subtitle lines to recognize in the table (multi-select merges the audio)
  2. Click the "ASR" button above the remark box
  3. The program extracts the segment audio with ffmpeg and calls ASR to recognize it
  4. The result is displayed in the remark area, including the recognized text and similarity

13.5 Meaning of Results

ColorSimilarity
Green≥ 0.85
Red< 0.85

13.6 Applying Recognized Times

After recognition, the precise start/end times returned by ASR can be applied to the current subtitle (available only when the recognition result matches the current subtitle).

13.7 Singleton Protection

ASR resources are singleton; only one program can use them at a time. If one program is already using them, another will fail to start and show a prompt.

14. Proofreading Subtitles

14.1 Proofreading File List

Create ProofSrt.lst in the same directory as the SRT, one entry per line:

identifier|folder path|subtitle type number
  • Identifier: a single character shown on the button (A, B, C, D recommended)
  • Folder path: the directory containing the proofreading subtitle; a trailing slash is recommended
  • Subtitle type number: 0~4, corresponding to the subtitle types in Section 5

Up to 4 proofreading files can be loaded at the same time.

14.2 Adding via Options

  1. Open Options → General
  2. In the "Proofreading folders" area, click +
  3. Select the directory, enter the identifier and subtitle type
  4. Confirm to write it into ProofSrt.lst

14.3 Using Proofreading

  1. Open the main SRT file
  2. Click a proofreading button (0~3) above the remark area
  3. The program searches the proofreading file using the current line of the main subtitle
  4. The match result is displayed in colored RTF

14.4 Matching Algorithm

The proofreading process uses the same search algorithm as timeline alignment:

  1. Locate using the head string of the current sentence in the main subtitle
  2. Aid location using the tail string of the previous sentence
  3. Locate using the word count of the current sentence
  4. Fall back level by level to find the best match

14.5 Display Area Colors

ColorMeaning
GrayContext before and after the matched sentence
GreenExact match
RedMismatched part
BlueCharacter-level difference

14.6 Browsing Context

Right-click in the proofreading display area and choose "Browse more subtitles" to show the original text of the 10 subtitles before and after the current time point in the proofreading file.

15. Filtered Display

15.1 Filtering by Remark

The "Remark" button on the toolbar:

  • Pressed: show only subtitles with remarks
  • Released: show all subtitles

15.2 Filtering by Flag

The flag bar on the toolbar can activate multiple flag filters at the same time. Rules:

  • Showing requires containing at least one of the selected flags
  • Multiple flags are in an "OR" relationship

15.3 Combined Filtering

Remark and flag filters can be active at the same time, also in an "OR" relationship.

15.4 Restrictions in Filter Mode

In filter mode (FUseMapping = True) the following operations are prohibited:
  • Insert subtitle
  • Delete subtitle
  • Merge subtitles
  • Split subtitle
  • Batch modify time
Only editing existing subtitles' text, remarks, flags, dictation, and time is allowed.

When violated, the corresponding buttons are grayed out and cannot be clicked.

15.5 Exiting Filter Mode

Cancel all filter conditions to return to the full view. Filter state is saved to the INI.

16. Dictionary / AI / TTS

16.1 Dictionary

Select the word or phrase to look up in the subtitle or remark, then:

  • Right-click → Dictionary
  • Or click the "Dictionary" button on the toolbar
  • Or press Ctrl+D

Local Dictionary

Opens a local dictionary program (such as Eudic) using a URL Scheme:

eudic://dict/%s

%s is replaced with the query word.

Online Dictionary

When checked, opens in the browser in sequence. Supports 8 preset URLs and can be customized.

16.2 AI Analysis

Operation is the same as the dictionary. The program will:

  1. Put the AI Prompt + selected text into the clipboard
  2. Open the corresponding AI site (or reuse an already open tab)
  3. Paste and send automatically

Preset AI Sites

  • ChatGPT (chatgpt.com)
  • Claude (claude.ai)
  • Gemini (gemini.google.com)
  • Tongyi Qianwen
  • Doubao
  • DeepSeek
  • Kimi

AI Prompt

The default Prompt asks the AI to translate literally and analyze English knowledge points, outputting plain text. It can be modified in options.

16.3 Built-in Browser

When "Use built-in browser" is checked:

  • Dictionary and AI are opened in the program's embedded Edge WebView2
  • It does not jump out to an external browser
  • Multiple AI sites are switched with the top buttons
  • The browser window can be moved independently of the main window or snapped to the main window's edge

16.4 TTS Read-Aloud

Select text, right-click → TTS, or press Ctrl+T.

How it works:

  1. Generate an HTML file containing the selected text
  2. Open it with Microsoft Edge
  3. Simulate Ctrl+Shift+U to trigger Edge's read-aloud feature

The first call opens an Edge window; subsequent calls reuse that window and refresh the content.

17. Toolboxes

17.1 SRT Toolbox

Opened by clicking the SRT Toolbox button on the subtitle list panel; it is a separate external program, VlsSrtTools.exe. Features include batch subtitle processing, AI translation text generation, splitting video by subtitle, Anki export, and more. See the companion SRT Toolbox User Manual for details.

17.2 TXT Toolbox

Opens a small window within the program. Function: split a plain text file by sentence to generate SRT subtitles.

Steps

  1. Select the TXT file to process
  2. Select the SRT output directory
  3. Set the split criterion (e.g. Chapter; a new file starts when this prefix is encountered)
  4. Click OK

Output

  • No split: generates one SRT with the same name as the TXT
  • Split by marker: generates multiple SRTs with numbered file names _01.srt, _02.srt, ...

Time Allocation

Each sentence defaults to 10 seconds with a 1-second gap. The generated timeline is only a placeholder and can be corrected with ASR alignment.

17.3 ASR Toolbox

Opened by clicking the ASR Toolbox button on the subtitle list panel; it is a separate external program, VlsAsrTools.exe. Features include segmented ASR subtitle generation, timeline alignment, and more. See the companion ASR Toolbox User Manual for details.

19.6 Theme Inheritance

Some built-in themes (such as Light Warm) inherit from the Light theme, overriding only the foreground and background colors while using the parent theme for the rest. Custom themes do not inherit; they are independent and complete.

20.2 SNT File Format

@t@:median time in milliseconds
@p@:paragraph tag
@f@:formatted text
remark first line
remark second line
@t@:next entry's median time
...
  • @t@: marks the beginning of a subtitle entry
  • @p@: paragraph tag (s/n/a)
  • @f@: formatted text (containing <f1>~<f7> flags)
  • All other lines are remark body text

If a subtitle has no remark, no tag, and no formatted text, it is not written to .snt. If the whole .snt is empty, it is deleted automatically.

20.3 DIC File Format

@t@:median time in milliseconds
dictation first line
dictation second line
@t@:next entry...

22. FAQ and Troubleshooting

Q1: No files visible in the subtitle list
Check whether the SRT directory is correct and whether there are .srt files in it. To refresh: switch the directory away and back.
Q2: The waveform area is empty
Usually one of the following:
  • There is no media file in the same directory
  • The media file name differs from the SRT name
  • There is no ffmpeg.exe in the program directory's lib folder
  • ffmpeg failed when generating the wfm (unsupported media format or too long)
Q3: Subtitle time changes are lost after restarting the program
They were not saved. After modifying the SRT, save manually (Ctrl+S) or wait for auto-save. You can also use the "auto-save on exit" option.
Q4: Cannot insert subtitles in filter mode
This is by design. Filter mode prohibits changing the subtitle structure; cancel the filter first (click off the toolbar's remark/flag filters).
Q5: ASR recognition fails
Check the following:
  • Whether the model has been downloaded to sherpa\model name\
  • Whether sherpa\sherpa-onnx-offline-websocket-server.exe exists
  • Whether sherpa\asr_engine.py exists
  • Whether Python is installed and pip install numpy websockets has been run
  • Whether ports 6006 and 9001 are occupied
Q6: Dictionary / AI fails to open
Check in options whether the URL is valid. When using the built-in browser, the Edge WebView2 runtime must be installed.
Q7: Shadowing scores are always low
Check:
  • Whether the microphone works properly and the volume is appropriate
  • Whether the recording environment is quiet
  • Whether the ASR model is loaded correctly
  • Whether the language of the subtitle's original text matches the recording content (the model is an English model and performs poorly on Chinese)
Q8: Color flags are lost
Color flags are saved in the .snt file. If the .snt is not saved or is lost, the flags degrade to plain text. Try to recover from the backup subdirectory.
Q9: Auto-save overwrote my changes
The program automatically backs up to the backup subdirectory before saving; you can find historical versions there by timestamp.
Q10: Some control colors are wrong after switching themes
Some third-party controls are not controlled by the theme. You can fine-tune colors in the options' theme panel. Some controls require restarting the program to take full effect.
Q11: I don't know how to exit fullscreen
Press Esc or Ctrl+Enter.
Q12: Subtitles are not aligned with the audio after time adjustment
Check:
  • With VLC as the playback engine the error is larger; try switching to MPV
  • Use the waveform editor to drag the handles to the precise position
  • Use the ASR Toolbox's "Align timeline" feature to correct automatically
Q13: Subtitle scrolling stutters during playback
This may be due to high row-height calculation or redraw overhead. Try:
  • Turning off "Single-line subtitle display"
  • Reducing the table row spacing
  • Turning off color flag display
Q14: The built-in browser won't open
Microsoft Edge WebView2 Runtime must be installed. It can be downloaded from the Microsoft website.
