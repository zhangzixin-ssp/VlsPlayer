1. What this is

The Notes card is a single-sentence card. Each card contains one video or audio clip, one source line, one translation line, and one note.

How it differs from the VlsPlayer Series card:

ItemSeries cardNotes card (this one)
UnitA whole season / unitOne sentence
Subtitle areaScrollable listShows only the current sentence
Playback rangeWhole episode, can switch unitsSingle-sentence time range
Typical useBinge-watch, continuous shadowingIntensive listening, vocabulary review
Front / backWhole player on the frontFront plays first, back shows notes

1.1 Main features

  • Front of the card auto-plays the target sentence (can be disabled)
  • Translation hidden so the learner listens first, then reads
  • Loop repeat with configurable count and interval
  • Drag the timeline to fine-tune the playback range
  • Falls back to TTS reading when no video file exists
  • Back shows the note (Remark) and source (From)
  • Control bar can be dragged anywhere on screen
  • Options stored in localStorage

2. Card fields

2.1 Five fields

FieldPurpose
TimelineMedia source + time range, format in section 14
SrtText1Subtitle 1 (usually the English source), may contain <f1>~<f7> color tags
SrtText2Subtitle 2 (usually the translation)
SrtNoteNote content, can be multiple lines
FromSource label, e.g. "Some Show S05E08 12:34"

2.2 Where cards come from

Generated by the desktop VlsPlayer's "Export to notes deck" feature. Each selected subtitle line becomes one card. They can also be batch-generated by the SRT Toolbox's Anki export.

2.3 Study flow

  1. Front is shown: the audio plays automatically, subtitle displayed
  2. You decide whether you understood it
  3. Click "Show Answer" to flip to the back
  4. Back shows the note and source
  5. Choose Again / Hard / Good / Easy

3.3 Note format

Notes display line by line, each prefixed with a bullet •. Empty lines are ignored.

4. Control bar buttons

The control bar is a draggable floating panel containing 7 buttons and one timeline.

4.1 Seven buttons

4.2 Play button icon states

IconState
▶Paused, ready to play

4.3 Tapping outside the buttons toggles play/pause

Tapping anywhere outside the control bar (except buttons and timeline sliders) automatically toggles play/pause. This is for quick operation.

5. Timeline and sliders

5.1 Elements

ElementColorMeaning
◁ / ▷ buttonsYellowFine-tune start/end time by 0.5 s each
Horizontal thin lineDark yellowTimeline baseline
Two yellow dotsYellowOriginal start/end times (not draggable)
Two yellow slidersYellowCurrent start/end times (draggable)
White sliderOff-whitePlayback position indicator (not draggable)

5.2 Dragging sliders

  • Drag the left slider to adjust the start time
  • Drag the right slider to adjust the end time
  • Takes effect immediately, no confirmation needed
  • Auto-saved to options when the drag ends

5.3 Fine-tune buttons

  • Tap ◁: start time moves back 0.5 s
  • Tap ▷: end time moves forward 0.5 s
  • Long press: no effect, tap only

5.4 Auto-scaling timeline

The timeline is always centered on the "original start/end times", with 1/6 margin on each side. So even after adjusting the start/end, the original position remains visible. Scaling is automatic — no manual setup needed.

6. Playback and repeat logic

6.1 Playback flow

  1. Load the media file
  2. Seek to the start time
  3. Play to the end time
  4. Pause, wait for the repeat interval
  5. Repeat count not reached → back to start and continue
  6. Repeat count reached → stop and wait for user action

6.2 Repeat count

ValueBehavior
1 to 9Fixed count
10Infinite loop until manually stopped

6.3 Repeat interval

ValueMeaning
1 to 30Fixed seconds
31Sentence duration (this sentence's playback time)

The interval is automatically divided by the playback speed, so faster playback shortens the wait accordingly.

6.4 Replay button

Tapping ↺:

  • Stops current playback immediately
  • Resets the repeat counter to 0
  • Starts again from the beginning
  • Sets the temporary repeat count to "infinite" (does not affect the option)

6.5 Playback speed

  • Toggle between 0.5x and 1.0x with the 0.5 / 1.0 button
  • Popup menu via 📊 offers 0.50x to 2.00x
  • Speed changes apply immediately to the current playback

7. Front / back display logic

7.1 Front

  • Key phrases (if color tags exist)
  • Subtitle 1 (source)
  • Subtitle 2 (translation) — depends on the "show translation at first" option

Subtitle 2 is hidden by default so the learner listens to the source first.

7.2 Back

  • Key phrases
  • Subtitle 1
  • Subtitle 2 (always shown)
  • Note
  • From

7.3 Auto-play on the front

When the "auto play on open" option is on (default):

  • After the front opens, playback begins as soon as the media is loaded
  • The back does not auto-play

7.4 Key phrase extraction

Everything wrapped in <fN> in Subtitle 1 is extracted and displayed line by line above the subtitle. Example:

SrtText1: "I <f1>couldn't agree more</f1> with you."

Displays as:

couldn't agree more
I couldn't agree more with you.

This lets learners focus on the key phrases before seeing the full sentence.

8. TTS playback

8.1 When TTS kicks in

When the Timeline field's extension is NaN, or the media file is missing, the program automatically switches to TTS mode and reads Subtitle 1 using the system speech synthesizer.

8.2 Voice selection

PlatformPreferred voice
iOS / iPadOSSamantha (US female)
Windows / macOSDavid (US male)
AndroidAny US English voice

If the preferred voice isn't available: first en-US voice, then any en voice.

8.3 Differences from media playback

  • No timeline dragging in TTS mode (timeline hidden)
  • Repeat and interval logic identical to media playback
  • Speed follows the playback speed setting (0.1 to 10)
  • Volume fixed at 0.8

8.4 TTS playback controls

  • Play/pause button works for TTS too
  • Replay stops current TTS and starts from the beginning
  • Switching cards stops TTS automatically

9. Dictionary and AI lookup

9.1 How to use

  1. Select the text you want to look up
  2. Tap the 🔍 button

If nothing is selected, the entire Subtitle 1 is queried by default.

9.2 Lookup routing

ConditionAction
Selected text has no space (single word)Open EuDic dictionary
Selected text contains a space (phrase)Send to AI for analysis

9.3 Dictionary URL

eudic://dict/selected_text

9.4 AI analysis

  • Windows: copies prompt + text to the clipboard; user pastes into AI manually
  • iPhone / Android: launches the Doubao app and sends directly

The prompt is fixed: "Please translate literally and analyze the phrases and knowledge points:"

9.5 Getting the selected text

  • Desktop: select with the mouse in the subtitle area; recorded on release
  • iOS / Android: select with a finger; read when the lookup button is tapped

On iOS, because of how touch events work, the selection is recorded separately.

12. Dragging and positioning the control bar

12.1 How to drag

  • Long-press any blank area of the button bar (not a button itself) to drag
  • Page scrolling is disabled while dragging
  • New position is saved on release

12.2 Boundaries

The control bar never leaves the screen. If dragged off-screen, it returns into view on next load.

12.3 Position persistence

The control bar's position is stored in the last two fields of the options string and restored the next time the card opens.

12.4 Initial position

On first open, the control bar is horizontally centered and about 60% down the screen (top: 60vh).

13. Options persistence

13.1 Where it's stored

Stored in the browser's localStorage, key format:

cardID_vp_notes_opts_1

The card ID comes from the first segment of the Timeline field.

13.2 What is stored

Ten fields, separated by |:

#FieldRange
0Auto play0 / 1
1Show translation at first0 / 1
2Show video0 / 1
3Repeat count1 – 10
4Repeat interval1 – 31
5Video height32 – 320
6Playback speed50 – 300 (i.e. 0.50x – 3.00x)
7Color theme0 – 4
8Control bar Xpixels
9Control bar Ypixels

13.3 When it saves

  • When the options panel closes
  • When playback speed changes
  • When the control bar drag ends
  • When a timeline slider drag ends

13.4 Cross-device sync

localStorage is local. If the card is used on multiple devices, each device needs its own settings. Anki sync does not sync localStorage.

14. Timeline field format

14.1 Basic format

media_prefix,season,episode,title,ext,-start-end

14.2 Examples

ExampleMeaning
atomic_habits,,01,,.mp3-0029120-0032325atomic_habits_01.mp3, from 2.912 s to 3.2325 s
cwe,,01,,-0005743-0006807-0006829-0007421cwe_01, multiple ranges
sf,s05,e08,Some Show,.mp4-0012345-0023456sf_s05e08.mp4, from 1.2345 s to 2.3456 s

14.3 Field details

PartDescription
Media prefixMedia filename prefix
SeasonCan be empty. When empty, filename format is prefix_episode
EpisodeUnit number, e.g. 01, 053
TitleOptional. When set, used for the From field
ExtensionMedia extension. NaN means pure TTS mode
Time rangeOne or more -time values in milliseconds. The program uses the first and last

14.4 Filename generation

If season is empty:

prefix_episode.ext

If season is non-empty:

prefix_s##e##.ext

14.5 Extension fallback

When the extension is empty, .mp4, or webm:

  • Windows uses .webm
  • Other platforms use .mp4

This solves the video codec compatibility issue across platforms during Anki sync.

14.6 Multi-range playback

A single Timeline can contain multiple time points:

prefix,,01,,-0005743-0006807-0006829-0007421-0007710-0008596

The program uses the first and last, and the range in between is the playback span. Useful for merging several consecutive clips into one card.

15. Platform differences

15.1 Windows

  • Font: Segoe UI + STXihei, 18 px, 12 px margins on both sides
  • Button bar height 32 px (slightly smaller)
  • Video codec uses .webm
  • AI analysis copies to clipboard, no auto-launch
  • Recording not supported

15.2 macOS

  • Uses default system font
  • Video codec uses .mp4
  • AI analysis launches the Doubao app

15.3 iOS / iPadOS

  • Control bar and menus are moved to the HTML root to avoid rendering issues
  • Uses Pointer Events instead of Mouse Events
  • Subtitle selection requires a touch-end event to record
  • Video codec uses .mp4
  • Recording supported

15.4 Android

  • Recording supported
  • Video codec uses .mp4
  • Font size slightly larger

15.5 Time precision tuning

Non-desktop platforms have a 0.12 s offset to compensate for iOS/Android video playback latency. Desktop offset is 0.

16. FAQ

Q1: Card opens to a black screen with only the control bar
Check:
  • Is the Timeline field valid (correct comma count, has a time range)?
  • Is the media file in collection.media?
  • Does the extension match the current platform (Windows uses .webm, others .mp4)?
Q2: Card has no sound
  • Check whether the Timeline's time range exceeds the actual media length
  • On Windows, .mp4 won't play — convert to .webm or a pure-audio format
  • If the extension is NaN, TTS is used — verify the system has an English voice installed
Q3: Video doesn't display
Enable the "Show video" option. It's off by default, so only audio plays.
Q4: No translation on the front
By design — the translation appears on the back. To show it on the front, enable "Show translation at first".
Q5: Control bar dragged off-screen and lost
Refresh the card. On next load, the control bar is automatically brought back into view. You can also clear localStorage to reset to default position.
Q6: Options won't save
  • Check whether the browser allows localStorage (disabled in private mode)
  • Check whether the card ID (first segment of Timeline) is stable
  • Clearing browser cache loses the options
Q7: Tapping lookup does nothing
  • Check whether EuDic (iOS) or Doubao (Android/iOS) is installed
  • On Windows it copies to clipboard — user must paste manually
  • Check whether the selected text is empty
Q8: TTS reads in the wrong language
TTS is fixed to English. If SrtText1 is in another language, quality will be poor. TTS mode is only recommended for English content.
Q9: Timeline sliders won't drag
  • Check whether the timeline is visible (hidden in TTS mode)
  • Check whether the touch point is exactly on the slider (sliders are small)
  • Try reopening the card
Q10: Sound keeps playing when switching to the next card
Normally it doesn't. The program stops the previous card when loading a new one. If it happens, check for interfering extensions or browser behavior. Refresh the page.
Q11: Repeat plays only once and stops
  • Check whether "Repeat count" is 1
  • Check whether "Repeat interval" is too long (31 = sentence duration)
  • Check whether you manually tapped play (which resets the counter)
Q12: Yellow dots and sliders are in strange positions
Yellow dots are the original start/end times; sliders are the adjusted ones. If they overlap, no adjustment has been made. A large offset means the range was adjusted significantly.
Q13: Key phrase area shows the wrong content
Key phrases are extracted from <f1> through <f7> tags in SrtText1. Without tags, only the full sentence is shown. To display key phrases, mark them with color tags in desktop VlsPlayer first.
Q14: Control bar blocks the subtitle
Drag the control bar to the bottom or top of the screen, or adjust the video height to make room for it.
