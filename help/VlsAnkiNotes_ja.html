1. これは何か

ノートカードは一文単位のカードです。1 枚のカードに、1 つの動画または音声、1 行の原文、1 行の訳文、1 つのメモが含まれます。

VlsPlayer Series カードとの違い：

項目Series カードNotes カード（本カード）
単位1 シーズン／1 ユニット全体一文
字幕エリアスクロール可能なリスト現在の一文のみ表示
再生範囲エピソード全体、ユニット切替可一文の時間範囲
主な用途連続視聴、連続シャドーイング精聴、単語の復習
表／裏プレイヤー全体が表側表で再生、裏でメモ表示

1.1 主な特徴

  • カードの表で対象文を自動再生（無効化可）
  • 訳文を隠し、まず音声を聞いてから読む
  • 回数と間隔を設定してリピート再生
  • タイムラインをドラッグして再生範囲を微調整
  • 動画ファイルがない場合は TTS 読み上げに自動降格
  • 裏面にメモ（Remark）と出典（From）を表示
  • コントロールバーを任意の位置にドラッグ可能
  • オプションは localStorage に保存

2. カードフィールド

2.1 5 つのフィールド

フィールド役割
Timelineメディアソース + 時間範囲。形式はセクション 14 参照
SrtText1字幕 1（通常は英文原文）。<f1>~<f7> の色タグを含められる
SrtText2字幕 2（通常は訳文）
SrtNoteメモ。複数行可
From出典ラベル。例「某ドラマ S05E08 12:34」

2.2 カードの生成元

デスクトップ版 VlsPlayer の「ノートデッキにエクスポート」機能で生成されます。字幕 1 行につき 1 枚のカード。SRT ツールボックスの Anki エクスポートでも一括生成できます。

2.3 学習の流れ

  1. 表を表示：音声が自動再生され、字幕が表示される
  2. 聞き取れたかどうか判断
  3. 「答えを表示」をクリックして裏へ
  4. 裏にメモと出典が表示される
  5. 「もう一度／難しい／普通／簡単」を選択

3. 画面構成

3.1 3 つのエリア

エリア内容
上部メディアエリア動画または音声（動画なしの場合はカバーのみ、または完全に非表示）
中央テキストエリア
  • 重要フレーズ（Key）：<fN> タグから抽出
  • 字幕 1（Text1）：メイン字幕
  • 字幕 2（Text2）：訳文。非表示可
  • メモ（Note）：裏面のみ
  • 出典（From）：裏面のみ、右下
下部コントロールバードラッグ可能なボタン + タイムラインパネル

3.2 字幕の色タグ

字幕 1 内の <f1> ～ <f7> タグは色付きで表示されます（Series カードと同じ）：

タグ色
f1赤
f2緑
f3青
f4黄
f5マゼンタ
f6オレンジ
f7暗赤

カードに動画がある場合、これらのタグが追加で「重要フレーズ」リストとして抽出され、字幕の上に表示されます。

3.3 メモの形式

メモは 1 行ずつ表示され、各行の先頭にビュレット • が付きます。空行は自動的に無視されます。

4. コントロールバーのボタン

コントロールバーはドラッグ可能なフローティングパネルで、7 つのボタンと 1 本のタイムラインを含みます。

4.1 7 つのボタン

ボタンアイコン機能
デッキ▣デッキに戻る（iOS/Android のみ。単発タップは無効で、ジェスチャが必要）
再生速度メニュー📊速度選択メニューをポップアップ
再生／一時停止▶ / ⏸メイン再生ボタン
リプレイ↺先頭から再再生
検索🔍辞書／AI 検索
速度切替0.5 / 1.0再生速度のクイック切替
オプション⚙オプションパネルを開く

4.2 再生ボタンのアイコン変化

アイコン状態
▶一時停止中、再生可能
⏸再生中
⏸ 90° 回転待機中（リピート間隔内）

4.3 ボタン以外の場所をタップで再生／一時停止

コントロールバーの外側（ボタンとタイムラインスライダーを除く）をタップすると、自動で再生／一時停止が切り替わります。素早い操作のためです。

5. タイムラインとスライダー

5.1 要素の説明

要素色意味
◁ / ▷ ボタン黄開始・終了時刻をそれぞれ 0.5 秒微調整
水平の細線暗黄タイムラインの基準線
2 つの黄点黄元の開始・終了時刻（ドラッグ不可）
2 つの黄スライダー黄現在の開始・終了時刻（ドラッグ可）
白スライダーオフホワイト再生位置インジケータ（ドラッグ不可）

5.2 スライダーのドラッグ

  • 左スライダーをドラッグして開始時刻を調整
  • 右スライダーをドラッグして終了時刻を調整
  • 即時反映、確認不要
  • ドラッグ終了時にオプションへ自動保存

5.3 微調整ボタン

  • ◁ をタップ：開始時刻が 0.5 秒戻る
  • ▷ をタップ：終了時刻が 0.5 秒進む
  • 長押し：無効。タップのみ

5.4 タイムラインの自動スケール

タイムラインは常に「元の開始・終了時刻」を中心とし、両側にそれぞれ 1/6 の余白を取ります。開始・終了を調整しても元の位置が見えるようになっています。スケールは自動で、手動設定は不要です。

6. 再生とリピートの仕組み

6.1 再生の流れ

  1. メディアファイルを読み込む
  2. 開始時刻にシーク
  3. 終了時刻まで再生
  4. 一時停止、リピート間隔を待つ
  5. リピート回数未満 → 先頭に戻って継続
  6. リピート回数に到達 → 停止、手動操作待ち

6.2 リピート回数

値動作
1 ～ 9固定回数
10手動停止まで無限ループ

6.3 リピート間隔

値意味
1 ～ 30固定秒数
31文の長さ（この一文の再生時間）

間隔は再生速度で自動的に除算されるため、速度を上げると待ち時間も短くなります。

6.4 リプレイボタン

↺ をタップ：

  • 現在の再生を即座に停止
  • リピートカウントを 0 にリセット
  • 先頭から再開
  • 一時的にリピート回数が「無限」に設定される（オプション設定には影響しない）

6.5 再生速度

  • 0.5 / 1.0 ボタンで 0.5x と 1.0x を切替
  • 📊 ボタンで 0.50x ～ 2.00x のメニューを表示
  • 速度変更は即座に現在の再生に反映

7. 表裏の表示ロジック

7.1 表の表示

  • 重要フレーズ（色タグがある場合）
  • 字幕 1（原文）
  • 字幕 2（訳文）── オプション「カードを開いたときに訳文を表示」に依存

字幕 2 はデフォルトで非表示。学習者がまず原文を聞くようにしています。

7.2 裏の表示

  • 重要フレーズ
  • 字幕 1
  • 字幕 2（常に表示）
  • メモ（Note）
  • 出典（From）

7.3 表での自動再生

オプション「カードを開いたときに自動再生」が ON のとき（デフォルト ON）：

  • 表を開くと、メディア読み込み完了と同時に自動再生
  • 裏を開いたときは自動再生しない

7.4 重要フレーズの抽出

字幕 1 内の <fN> で囲まれた内容が抽出され、字幕の上に 1 行ずつ表示されます。例：

SrtText1: "I <f1>couldn't agree more</f1> with you."

表示結果：

couldn't agree more
I couldn't agree more with you.

学習者が全文を見る前に、重要フレーズに注目できるようにしています。

8. TTS 読み上げ

8.1 発動条件

Timeline フィールドの拡張子が NaN の場合、またはメディアファイルが見つからない場合、プログラムは自動的に TTS モードに切り替え、システムの音声合成で字幕 1 を読み上げます。

8.2 音声の選択

プラットフォーム優先音声
iOS / iPadOSSamantha（US 女性）
Windows / macOSDavid（US 男性）
Android任意の US 英語音声

優先音声がない場合：最初の en-US、次に任意の en 音声。

8.3 メディア再生との違い

  • TTS モードではタイムラインのドラッグは不可（タイムライン非表示）
  • リピートと間隔のロジックはメディア再生と同一
  • 速度は再生速度設定に従う（0.1 ～ 10）
  • 音量は 0.8 固定

8.4 TTS の再生操作

  • 再生／一時停止ボタンは TTS にも有効
  • リプレイボタンは現在の TTS を停止して先頭から読み上げ
  • カードを切り替えると TTS は自動停止

9. 辞書と AI 検索

9.1 使い方

  1. 字幕の中から調べたいテキストを選択
  2. 🔍 ボタンをタップ

何も選択していない場合は、字幕 1 の全体が検索対象になります。

9.2 検索の振り分け

条件動作
選択テキストにスペースなし（単語）欧路辞書を開く
選択テキストにスペースあり（フレーズ）AI 分析を呼び出す

9.3 辞書 URL

eudic://dict/選択テキスト

9.4 AI 分析

  • Windows：プロンプト + テキストをクリップボードにコピー。ユーザーが手動で AI に貼り付け
  • iPhone / Android：豆包アプリを呼び出して直接送信

プロンプトは固定：「請嚴格直譯並分析其中片語及知識點：」

9.5 選択テキストの取得

  • デスクトップ：字幕エリアでマウス選択、離したときに記録
  • iOS / Android：指で選択、検索ボタンをタップしたときに読み取り

iOS は touch イベントの特殊性から、選択テキストは別途記録する必要があります。

12. コントロールバーのドラッグと位置

12.1 ドラッグ方法

  • ボタンバーの空白部分（ボタン自体ではない）を長押ししてドラッグ
  • ドラッグ中はページスクロールが無効化される
  • 離したときに新しい位置が自動保存される

12.2 位置の境界

コントロールバーは画面外に出ません。画面外にドラッグされた場合は、次回読み込み時に自動で画面内に戻ります。

12.3 位置の保存

コントロールバーの位置はオプション文字列の最後の 2 つのフィールドに保存され、次にカードを開いたときに復元されます。

12.4 初期位置

初回表示時は水平中央、垂直方向に約 60% の位置（top: 60vh）。

13. オプションの保存

13.1 保存先

ブラウザの localStorage に保存。キー形式：

cardID_vp_notes_opts_1

カード ID は Timeline フィールドの最初のセグメントから取得します。

13.2 保存内容

10 個のフィールドを | で区切って保存：

#フィールド範囲
0自動再生0 / 1
1先に訳文を表示0 / 1
2動画を表示0 / 1
3リピート回数1 ～ 10
4リピート間隔1 ～ 31
5動画の高さ32 ～ 320
6再生速度50 ～ 300（0.50x ～ 3.00x）
7カラーテーマ0 ～ 4
8コントロールバー Xピクセル
9コントロールバー Yピクセル

13.3 保存タイミング

  • オプションパネルを閉じたとき
  • 再生速度を変更したとき
  • コントロールバーのドラッグが終わったとき
  • タイムラインスライダーのドラッグが終わったとき

13.4 デバイス間同期

localStorage はローカルです。カードを複数デバイスで使う場合、オプションはそれぞれのデバイスで設定が必要です。Anki の同期では localStorage は同期されません。

14. Timeline フィールドの形式

14.1 基本形式

メディア接頭辞,シーズン,エピソード,タイトル,拡張子,-開始-終了

14.2 例

例意味
atomic_habits,,01,,.mp3-0029120-0032325atomic_habits_01.mp3、2.912 秒 ～ 3.2325 秒
cwe,,01,,-0005743-0006807-0006829-0007421cwe_01、複数区間
sf,s05,e08,某ドラマ,.mp4-0012345-0023456sf_s05e08.mp4、1.2345 秒 ～ 2.3456 秒

14.3 フィールドの説明

部分説明
メディア接頭辞メディアファイル名の接頭辞
シーズン空でも可。空の場合のファイル名は 接頭辞_エピソード
エピソードユニット番号。例 01、053
タイトル任意。設定時は From フィールドに使用
拡張子メディアの拡張子。NaN は純粋な TTS モードを意味
時間範囲-時間（ミリ秒）を複数。プログラムは最初と最後を使用

14.4 ファイル名の生成規則

シーズンが空の場合：

接頭辞_エピソード.拡張子

シーズンが非空の場合：

接頭辞_s##e##.拡張子

14.5 拡張子のデフォルト

拡張子が空、.mp4、または webm の場合：

  • Windows は .webm
  • その他のプラットフォームは .mp4

これは Anki 同期時の動画コーデック互換問題を解決します。

14.6 複数区間の再生

1 つの Timeline に複数の時間点を含められます：

接頭辞,,01,,-0005743-0006807-0006829-0007421-0007710-0008596

プログラムは最初と最後の値を使用し、その間の範囲を再生範囲とします。連続した複数のクリップを 1 枚のカードにまとめたいときに使います。

15. プラットフォーム別の違い

15.1 Windows

  • フォント：Segoe UI + STXihei、18px、左右 12px の余白
  • ボタンバーの高さ 32 px（やや小さめ）
  • 動画コーデックは .webm
  • AI 分析はクリップボードにコピー、自動遷移なし
  • 録音は非対応

15.2 macOS

  • デフォルトのシステムフォントを使用
  • 動画コーデックは .mp4
  • AI 分析は豆包アプリを呼び出す

15.3 iOS / iPadOS

  • コントロールバーとメニューが HTML ルートに移動され、レンダリング問題を回避
  • Mouse Events ではなく Pointer Events を使用
  • 字幕選択には touch 終了イベントの記録が必要
  • 動画コーデックは .mp4
  • 録音対応

15.4 Android

  • 録音対応
  • 動画コーデックは .mp4
  • フォントサイズはやや大きめ

15.5 時間精度の調整

非デスクトッププラットフォームでは iOS/Android の動画再生遅延を補償するため 0.12 秒のオフセットがあります。デスクトップは 0 です。

16. よくある質問

Q1：カードが真っ黒で、コントロールバーだけが表示される
確認：
  • Timeline フィールドが有効か（カンマ数が正しい、時間範囲がある）
  • メディアファイルが collection.media にあるか
  • 拡張子が現在のプラットフォームに合っているか（Windows は .webm、他は .mp4）
Q2：音が出ない
  • Timeline の時間範囲がメディアの実際の長さを超えていないか確認
  • Windows では .mp4 が再生できないため、.webm または音声のみの形式に変換
  • 拡張子が NaN の場合は TTS。システムに英語音声があるか確認
Q3：動画が表示されない
オプションで「動画を表示」を ON にしてください。デフォルトは OFF で、音声のみ再生されます。
Q4：表で訳文が見えない
設計上の挙動です。訳文は本来裏で表示されるものです。表でも見たい場合は、オプションで「先に訳文を表示」を ON にしてください。
Q5：コントロールバーを画面外にドラッグしてしまった
カードを再読み込みしてください。次回読み込み時にコントロールバーが自動で画面内に戻ります。localStorage を消去してデフォルト位置に戻すこともできます。
Q6：オプションが保存されない
  • ブラウザが localStorage を許可しているか（プライベートモードでは無効）
  • カード ID（Timeline フィールドの最初のセグメント）が安定しているか
  • ブラウザキャッシュを消去するとオプションが失われます
Q7：検索ボタンをタップしても反応しない
  • 端末に欧路辞書（iOS）または豆包アプリ（Android/iOS）がインストールされているか
  • Windows ではクリップボードにコピーされるので、ユーザーが手動で貼り付ける必要あり
  • 選択テキストが空でないか
Q8：TTS の読み上げ言語が違う
TTS は英語固定です。SrtText1 が他言語の場合、品質は大きく下がります。TTS モードは英語コンテンツにのみ推奨します。
Q9：タイムラインのスライダーが動かない
  • タイムラインが表示されているか確認（TTS モードでは非表示）
  • タッチ点が正確にスライダー上にあるか（スライダーは小さい）
  • カードを開き直してみる
Q10：次のカードに切り替えても音が鳴り続ける
通常は起こりません。新しいカードの読み込み時に前のカードを自動停止します。発生する場合は、干渉する拡張機能やブラウザ動作がないか確認してください。ページを再読み込みすれば解決します。
Q11：リピートが 1 回で止まる
  • 「リピート回数」が 1 になっていないか
  • 「リピート間隔」が長すぎないか（31 = 文の長さ）
  • 手動で再生ボタンをタップしていないか（カウントがリセットされます）
