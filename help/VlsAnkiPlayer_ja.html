1. これは何か

これは、シーズン全体またはユニット全体の字幕データを 1 枚のカードに詰め込んだ特殊な Anki カードです。復習時にエピソードごとにカードをめくる必要はなく、1 枚のカード内で次のことができます：

  • 動画を見ながら字幕を同期表示する
  • 文ごとにシャドーイング、精聴、ディクテーションを行う
  • ロールプレイ：あなたが一方の役を読み、プレーヤーがもう一方の役を読む
  • フラッシュ再生：区間全体を速度を変えて速く再生し、素早く通す
  • お気に入りの文をマークして後で集中的に復習する
  • 録音して比較する

これはデスクトップ版 VlsPlayer とは別物です。VlsPlayer は Windows アプリケーションで、このカードテンプレートは Anki 内部で動作する JavaScript です。両者は同じ字幕ファイル形式と字幕ツールボックスを共有しています。

1.1 主な特徴

  • 黒背景に黄色のボタン。長時間の動画学習向けに設計
  • ボタンパネルはドラッグ可能、上部/下部にドッキング可能、2 行に折りたたみ可能
  • 設定はすべてカードのフィールド、または iOS では localStorage に保存される
  • デスクトップ、iPhone、iPad、Android、macOS に対応
  • Windows ではクリップボード API のために Anki アドオン 1020366288 が必要

2. カードのフィールドと作成

2.1 カードのフィールド

フィールド役割
Titleシリーズタイトル。メインタイトル、シーズン/章、エピソード/ユニットの 3 部分で構成
Mediaメディア拡張子 + ポスター（任意）。| で区切る
Optionsオプション文字列（デスクトップ Anki のみ。第 17 節参照）
Srts_00インデックス/概要トラック。字幕なし。ユニット数のみ記録
Srts_01 ～ Srts_10最大 10 チャンネル。各チャンネルは同じエピソードの多言語/複数シーズンの字幕
Tagsオプションもここに保存される（base62 エンコード）

2.2 作成元

カードはデスクトップ版 VlsPlayer の「Anki プレーヤーテキスト」エクスポート機能、または SRT ツールボックスの Anki エクスポート機能で生成されます。フィールド内容は自動で入力され、手書きは不要です。

2.3 読み込みの流れ

  1. カードの表面を表示（実際にはプレーヤー全体が表面にある）
  2. Title と Media を解析
  3. Srts_01 ～ Srts_10 をスキャンしてチャンネルリストを構築
  4. Srts_00 からユニット番号の範囲を読み取る
  5. 前回のオプションと再生位置を読み込む
  6. 前回のチャンネルとユニットを開く
  7. 200 ミリ秒後に自動的に再生開始

3. 画面レイアウト

3.1 3 つの領域

領域内容
上部メディア領域動画映像。動画のない音声カードではレコードアイコンを表示
中央字幕領域行ごとに字幕を表示。スクロール可能。各行に役割を示す色付きドット
下部ボタン領域再生コントロールとオプション入口。ドラッグとドッキング可能

3.2 字幕行の視覚的エンコード

色行クラス意味
オレンジのドットsrt1役割 1
緑のドットsrt2役割 2
灰色のドットsrtNナレーション
黄色のドットsrtT歌詞/字幕グループ
ピンクのドットsrtGその他のマーク

各字幕行の右側にハートアイコンがあります：空心 ♡ は未お気に入り、実心 ♥ はお気に入り済み。クリックで切り替えます。

3.3 字幕内のカラーマーク

字幕行には <f1> から <f7> のマークを含めることができ、異なる色で描画されます：

マーク色
f1赤
f2緑
f3青
f4黄
f5マゼンタ
f6オレンジ
f7暗赤

3.4 時間情報

動画画面をタップすると、下部に表示されます：

  • 左側：現在の再生時間（hh:mm:ss）
  • 右側：合計時間
  • 中央：進行バー。ドラッグでシーク可能

5 秒後に自動的に非表示になります。

4. ボタンパネル

ボタンパネルは 3 行あり、2 行に折りたたむことも、ウィンドウの上部または下部にドラッグすることもできます。すべての設定はカードオプションに保存され、次にカードを開いたときに自動的に復元されます。

4.1 3 行レイアウト

デフォルトは 3 行。左から右へ：

行ボタン
1 行目 － / ＋ 折りたたみ/展開   1.0 / 2.0 速度切替   ⏮ 前の文   ↺ リプレイ   ⏭ 次の文   AB 選択区間を再生   🔍 辞書/AI
2 行目 M 再生モード   0.5 / 1.5 速度切替   ⬆AB 画面上端の行から現在行まで再生   ▶ 再生/一時停止   ⬇AB 現在行から画面下端の行まで再生   ⚡² 上端からフラッシュ再生   N ノイズ
3 行目 📊 再生速度メニュー   ♡ お気に入り切替   ▶🎤 録音を再生   🎤 録音   🌐 訳文の表示/非表示   ⚡ フラッシュ再生   ⚙ オプション

4.2 2 行レイアウト

オプションで「2 行ボタン」を選ぶと、レイアウトは 2 行になり、ボタンがより大きくタップしやすくなります。スマートフォンの縦画面に適しています。

4.3 メディアなしカード

カードに音声のみ、またはメディアファイルが欠落している場合、ボタンパネルは 1 行に縮小され、次のものだけが残ります：

  • デッキに戻る
  • お気に入り切替
  • 辞書/AI
  • 訳文の表示/非表示
  • オプション

4.4 パネルのドラッグ

ボタンパネル上で任意のボタンを長押し（前/次の文ボタンを除く）1.5 秒すると、ドラッグモードに入ります。次のことができます：

  • ウィンドウの下部へドラッグ → 下部にドッキング
  • ウィンドウの上部へドラッグ → 上部にドッキング（ボタンが上下反転）
  • 中央へドラッグ → フロート

4.5 折りたたみ/展開

－ または ＋ をクリックして 3 行と 2 行を切り替えます。展開時には、元の「リプレイ」ボタンが「再生」ボタンに変わります。

5. 単文モードとタイムライン

単文モードでは、ボタンパネルの上にタイムラインが表示され、現在の文の調整可能な再生範囲を示します。

5.1 タイムラインの要素

要素色意味
2 つの黄色い点黄色元の再生区間
2 つの灰色のスライダー灰色現在調整可能な開始/終了時間
白いスライダー白再生位置インジケーター
両端の短い縦線暗黄色タイムラインの境界装飾
◁ ▷ ボタン黄色開始/終了時間をそれぞれ 0.5 秒ずつ微調整

5.2 開始/終了時間の調整

  • 左側の灰色スライダーをドラッグして開始時間を調整
  • 右側の灰色スライダーをドラッグして終了時間を調整
  • ◁ をクリックして開始時間を 0.5 秒戻す
  • ▷ をクリックして終了時間を 0.5 秒進める

調整は即座に反映され、次回の再生は新しい位置から始まります。

5.3 「タイムライン拡張」オプションとの併用

オプションの「タイムライン拡張」はミリ秒単位で、各字幕の開始/終了時間を両側に少しずつ拡張し、字幕境界がきつすぎて音が途切れるのを防ぎます。拡張量は隣接する字幕との間隔の半分を超えません。

6. 再生モード

M ボタンをクリックするとモードメニューが開きます。現在のモード文字がボタンに表示されます。

6.1 5 つのモード

ボタンモード動作
M通常モード区間全体を順番に再生し、字幕を自動スクロール
Ms単文モード文ごとに再生し、各文の終了時にリピート設定に従って処理
Mo奇数行を演じる奇数行（srt1）はミュートされ、あなたが読む
Me偶数行を演じる偶数行（srt2）はミュートされ、あなたが読む
Ma全行を演じるすべてミュートされ、あなたが読む

6.2 モード切替の影響

  • 通常/単文モードとロールプレイモードの間で切り替えると、現在のユニットが再読み込みされます
  • その他の場合は、現在の行を選択し直すだけで、再読み込みは行いません
  • タイムラインは単文モードで表示され、その他のモードでは非表示になります

7. ループモードとチャンネル/ユニット

7.1 チャンネルとユニット

  • 1 枚のカードには最大 10 個のチャンネルを含めることができます（Srts_01 ～ Srts_10 に対応）
  • 各チャンネルには複数のユニットがあります（エピソードや章に対応）
  • 現在再生中のユニットは字幕領域の上部に表示されます

7.2 チャンネル/ユニットの切替

オプションパネルの下部にチャンネルとユニットのセレクターがあります：

  • 左側はチャンネルリスト（チャンネルが 1 つだけの場合は自動的に非表示）
  • 右側はユニットグリッド。クリックで切替

切り替えると、そのユニットにジャンプして最初から再生されます。

7.3 ループモード

ユニットの末尾に達したときの動作を決定します：

モード動作
現在のユニット再生後、このユニットの先頭に戻る
現在のチャンネル再生後、次のユニットへジャンプ。チャンネルの末尾でこのチャンネルの先頭に戻る
すべてのコンテンツチャンネルをまたいで連続再生。末尾で最初のチャンネルに戻る

オプションパネルでループモードを選択します。
