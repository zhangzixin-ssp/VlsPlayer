1. 這是什麼

這是一張特殊的 Anki 卡片，把整季或整單元的字幕資料裝進一張卡裡。複習時你不需要一集一集地翻卡片，而是在一張卡片裡就能：

  • 看影片並同步顯示字幕
  • 逐句跟讀、精聽、聽寫
  • 角色扮演：你念一個角色，讓播放器念另一個角色
  • 閃播：變速快放整段，快速過一遍
  • 標記收藏句，回頭集中複習
  • 錄音對比

它和桌面版 VlsPlayer 不是一回事。VlsPlayer 是 Windows 應用程式，這個卡片模板是執行在 Anki 內部的 JavaScript，兩邊共享相同的字幕檔案格式和字幕工具箱。

1.1 主要特徵

  • 黑底黃鍵，為長時間看影片學習設計
  • 按鈕面板可拖動、可停靠頂部/底部、可收起為兩行
  • 設定全部儲存在卡片欄位裡，或 iOS 端的 localStorage 中
  • 支援桌面、iPhone、iPad、Android、macOS
  • Windows 下需要 Anki 外掛 1020366288 提供剪貼簿 API

2. 卡片欄位與製作

2.1 卡片欄位

欄位作用
Title劇集標題，由三段組成：主標題、季/章節、集/單元
Media媒體副檔名 + 海報（可選），用 | 分隔
Options選項字串（僅桌面 Anki 使用，見第 17 節）
Srts_00索引/總覽軌道，無字幕，只記錄單元數
Srts_01 到 Srts_10最多 10 個頻道，每個頻道是同一集的多語言/多季字幕
Tags選項也儲存在這裡（用 base62 編碼）

2.2 製作來源

卡片由桌面版 VlsPlayer 的「Anki 播放器文字」匯出功能生成，或由 SRT 工具箱的 Anki 匯出功能生成。欄位內容自動填充，不需要手寫。

2.3 載入流程

  1. 顯示卡片正面（其實整個播放器就在正面）
  2. 解析 Title 和 Media
  3. 掃描 Srts_01 到 Srts_10，建立頻道清單
  4. 讀取 Srts_00 裡的單元號範圍
  5. 載入上次的選項和播放位置
  6. 開啟上次所在的頻道和單元
  7. 200 毫秒後自動開始播放

3. 介面佈局

3.1 三個區域

區域內容
頂部媒體區影片畫面。無影片的音訊卡片顯示一個唱片圖示
中部字幕區按行顯示字幕，可捲動。每行有顏色圓點表示角色
底部按鈕區播放控制和選項入口，可拖動和停靠

3.2 字幕行的視覺編碼

綠色圓點srt2角色 2
灰色圓點srtN旁白
黃色圓點srtT歌詞/字幕組
粉色圓點srtG其他標記

每條字幕行右側有一個心形圖示：空心 ♡ 表示未收藏，實心 ♥ 表示已收藏。點擊即可切換。

3.3 字幕內的彩色標記

字幕行內可包含 <f1> 到 <f7> 標記，渲染為不同顏色：

標記顏色
f1紅
f2綠
f3藍
f4黃
f5洋紅
f6橙
f7暗紅

3.4 時間資訊

點一下影片畫面，底部會顯示：

  • 左側：目前播放時間（hh:mm:ss）
  • 右側：總時長
  • 中間：進度條，可拖動定位

5 秒後自動隱藏。

4. 按鈕面板

按鈕面板有三行，可以收起為兩行，也可以拖到視窗頂部或底部。所有設定都儲存在卡片選項裡，下次開啟卡片時自動恢復。

4.1 三行佈局

預設三行，從左到右：

行按鈕
第一行 － / ＋ 收起/展開   1.0 / 2.0 倍速切換   ⏮ 上一句   ↺ 重播   ⏭ 下一句   AB 播放已選區   🔍 詞典/AI
第二行 M 播放模式   0.5 / 1.5 倍速切換   ⬆AB 從螢幕頂行播到當前行   ▶ 播放/暫停   ⬇AB 從當前行播到螢幕底行   ⚡² 從頂部閃播   N 噪音
第三行 📊 播放速度選單   ♡ 收藏切換   ▶🎤 播放錄音   🎤 錄音   🌐 顯隱譯文   ⚡ 閃播   ⚙ 選項

4.2 兩行佈局

在選項裡選「兩行按鈕」後，佈局變為兩行，按鈕更大、更易點。適合手機直向螢幕。

4.3 無媒體卡片

當卡片只有音訊、或媒體檔案缺失時，按鈕面板收縮為一行，只保留：

  • 返回牌組
  • 收藏切換
  • 詞典/AI
  • 顯隱譯文
  • 選項

4.4 拖動面板

在按鈕面板上長按任意按鈕（上下句按鈕除外）1.5 秒，進入拖動模式。可以：

  • 拖到視窗底部 → 自動停靠在底部
  • 拖到視窗頂部 → 自動停靠在頂部（按鈕會上下翻轉）
  • 拖到中間 → 懸浮

4.5 收起/展開

點擊 － 或 ＋ 在三行與兩行之間切換。展開時，原本「重播」按鈕會變成「播放」按鈕。

5. 單句模式與時間軸

單句模式下，按鈕面板上方會出現一條時間軸，顯示目前句的可調整播放範圍。

5.1 時間軸元素

元素顏色含義
兩個黃點黃色原始播放區間
兩個灰色滑桿灰目前可調整的起止時間
白色滑桿白播放位置指示器
兩端短豎線暗黃時間軸的邊界裝飾
◁ ▷ 按鈕黃起止時間各前後微調 0.5 秒

5.2 調整起止時間

  • 拖動左側灰色滑桿調整起始時間
  • 拖動右側灰色滑桿調整結束時間
  • 點擊 ◁ 起始時間後退 0.5 秒
  • 點擊 ▷ 結束時間前進 0.5 秒

調整後立即生效，下次播放從新位置開始。

5.3 與「擴展時間軸」選項配合

選項裡的「擴展時間軸」會以毫秒為單位，把每條字幕的起止時間向兩側各擴展一點，避免字幕邊界太緊導致的聲音截斷。擴展量不會超過相鄰字幕間距的一半。

6. 播放模式

點擊 M 按鈕彈出選單，選擇播放模式。目前模式字母會顯示在按鈕上。

6.1 五種模式

按鈕模式行為
M普通模式順序播放整段，自動捲動字幕
Ms單句模式逐句播放，每句結束按重複設定處理
Mo扮演奇數行播放到奇數行（srt1）靜音，你念
Me扮演偶數行播放到偶數行（srt2）靜音，你念
Ma扮演全部行全部靜音，你念

6.2 模式切換的影響

  • 在普通/單句模式與扮演模式之間切換時，會重新載入目前單元
  • 在其他情況下，只重新選中目前行，不重新載入
  • 單句模式下時間軸可見，其他模式隱藏

7. 循環模式與頻道/單元

7.1 頻道與單元

  • 一張卡片最多包含 10 個頻道（對應 Srts_01 到 Srts_10）
  • 每個頻道有多個單元（對應集數或章節）
  • 目前播放的單元顯示在字幕區頂部

7.2 切換頻道/單元

在選項面板底部有頻道和單元選擇器：

  • 左側是頻道清單（若只有一個頻道，清單自動隱藏）
  • 右側是單元網格，點選即可切換

切換後自動跳轉到該單元並從頭播放。

7.3 循環模式

決定播放到單元末尾時的行為：

模式行為
目前單元播完後回到本單元開頭
目前頻道播完後跳到下一單元，頻道末尾後回到本頻道開頭
所有內容跨頻道連續播放，到末尾回到第一個頻道

在選項面板中選擇循環模式。

8. 跟讀與角色扮演

8.1 角色判定

字幕的角色由行內標記推斷：

標記角色
[n]旁白（不被扮演）
[t]歌詞/字幕組（不被扮演）
[g]其他（不被扮演）
[a]延續上一行角色
[s]新場景開始
[p]段落分隔
無標記交替 srt1 / srt2

8.2 扮演流程

選好扮演模式（奇數/偶數/全部）後，播放時：

  1. 播放到你要念的行 → 自動暫停並靜音 → 該行加 speaking 高亮
  2. 你念完後再次點擊播放 → 從該行結束處繼續
  3. 若選項裡開啟了「扮演後重播原聲」，會倒回該行開始位置，播放原聲
  4. 原聲播放完畢後繼續下一句

8.3 跳過空白區

「扮演時跳過空白區時長」選項：當兩句之間的靜音間隔超過設定秒數時，自動跳過。例如設為 5 秒，則間隔大於 5 秒的部分會被跳過，節省時間。

8.4 角色字幕顯示

「角色字幕」選項決定扮演行的高亮方式：

選項效果
預設扮演行整行高亮
譯文顯示譯文，隱藏原文
隱藏每個單詞加邊框，隱藏具體內容

「隱藏」模式適合聽寫練習：你能看到句子長度和斷詞，但看不到具體單詞。

9. 閃播

閃播是一種變速快放整段的功能，用於快速過一遍已經熟悉的內容。

9.1 兩種閃播

按鈕行為
⚡從目前句開始，逐塊變速快放
⚡²從螢幕頂部行開始，逐塊變速快放

9.2 分塊機制

  • 把字幕按「至少 N 秒一塊」切分（N 由「閃播塊最小時長」決定）
  • 每塊按不同速度播放（速度清單由「閃播播放速度」決定）
  • 塊與塊之間有間隔（由「多行重複間隔」決定）

9.3 閃播速度清單

最多支援 6 個速度，每個速度在 1.00x 到 3.00x 之間。預設 4 個：1.25x、2.00x、2.25x、2.50x。

也可以使用快捷模板：

  • A：塊 10 秒，速度 1.25x / 1.75x
  • B：塊 20 秒，速度 1.25x / 1.75x / 2.00x
  • C：塊 30 秒，速度 1.25x / 1.75x / 2.00x / 2.00x

9.4 結束條件

閃播到最後一個速度後，回到塊起點，重新開始新一輪，直到手動停止。

10. 重複播放與間隔

10.1 重複次數

單句模式下，每句重複播放的次數：

  • 1 到 9：固定次數
  • 10：無限循環，直到手動停止

10.2 單句間隔

單句重複之間的間隔：

值含義
1 到 30固定秒數
31本句時長（念完後停等一會兒）
32下一句時長
33停止播放（等使用者點播放才繼續）

10.3 多行間隔

當一段有多個連續句時（例如你選了從螢幕頂行到當前行播放），段與段之間的間隔，單位秒，範圍 1 到 30。

10.4 典型配置

場景重複次數單句間隔多行間隔
逐句跟讀1本句時長—
精聽新內容無限暫停3 秒
快速過一遍11 秒1 秒

11. 收藏

11.1 新增收藏

每條字幕行右側有一個心形圖示，點擊即可切換：

  • 空心 ♡ → 實心 ♥：把該句加入收藏
  • 實心 ♥ → 空心 ♡：取消收藏

收藏點儲存的是該句的時間中點，因此即使字幕內容修改，只要時間還在同一區間，收藏依然有效。

11.2 只看收藏

點擊 ♡ 按鈕切換到 ♥，只顯示收藏的字幕。再點一次恢復全部顯示。

11.3 收藏範圍

收藏按頻道和單元分別儲存。切換到其他單元時，只顯示該單元的收藏。

11.4 儲存方式

  • iPhone/iPad：儲存在 localStorage，按卡片 ID + 頻道 + 單元劃分
  • Android：同上
  • 桌面版：呼叫 Anki 外掛寫入卡片欄位

12. 字幕顯示與語言

12.1 顯示模式

「顯示字幕」選項控制：

模式顯示
英文只顯示原文
譯文只顯示譯文
雙語原文 + 譯文同時顯示

12.2 快速切換

點擊 🌐 按鈕：

  • 短按：切換目前行的顯示語言（英文 → 譯文 → 雙語循環）
  • 長按 1.5 秒：對螢幕頂部到當前行之間的所有行執行同樣切換

12.3 字幕位置

「字幕位置」選項控制目前行捲動到螢幕的哪個位置：

模式行為
預設僅當目前行不在可視區時才捲動
頂部總是把目前行捲到螢幕頂部
中部總是把目前行捲到螢幕中部

12.4 字幕字體

在選項中可切換 4 種字體：預設、Verdana、Helvetica、Times New Roman。

12.5 字體大小

4 個等級：預設（18px）、稍大（19.5px）、較大（21px）、最大（22.5px）。

13. 錄音與噪音

13.1 錄音

點擊 🎤 按鈕開始錄音：

  • 需要瀏覽器授權麥克風權限
  • 錄音中圖示變為停止錄製圖示
  • 點擊停止後自動開始回放
  • 最長錄音 5 分鐘
  • 錄音只保留最近一次，再次錄音會覆蓋

錄音檔案儲存在記憶體中，不寫到磁碟。切換到下一張卡片時自動清除。

13.2 播放錄音

點擊 ▶🎤 按鈕回放上一次錄音。再次點擊可停止播放。

13.3 噪音

點擊 N 按鈕循環切換：

值行為
N無噪音
N1 / N2 / N3混入三個不同噪音源之一

噪音與影片同步播放和暫停。開啟噪音時影片音量自動降到 50%，噪音從隨機位置開始，循環播放。

噪音檔案來自卡片模板目錄下的 u_noise_1.mp3、u_noise_2.mp3、u_noise_3.mp3。

14. 長按操作

17. 選項持久化機制

選項需要儲存，下一次開啟卡片時恢復。不同平台儲存方式不同：

17.1 桌面版

把選項字串寫入卡片欄位 Options 或 Tags。需要 Anki 外掛 1020366288。

17.2 iPhone / iPad

儲存在瀏覽器的 localStorage 中，鍵名格式為 卡片ID_series_opts_6。

17.3 Android

同 iPhone，儲存在 localStorage。

17.4 編碼方式

選項字串用 base62 編碼壓縮，再以 a 為分隔符儲存各個欄位。例如：

欄位順序：語言 / 按鈕顏色 / 按鈕高度 / 按鈕行數 /
播放模式 / 循環模式 / 字幕語言 / 字幕位置 /
角色字幕 / 字幕字體 / 字體大小 / 扮演後重播 /
只看收藏 / 影片高度 / 播放倍速 / 擴展時間軸 /
跳過空白時長 / 單句次數 / 單句間隔 / 多行間隔 /
閃播時長 / 閃播速度清單 / 頻道 / 單元 / 播放位置

17.5 收藏單獨儲存

收藏資料不在選項字串裡，而是單獨儲存。鍵名格式：卡片ID_頻道_單元。值為一串 7 位數字的拼接，每個數字代表一個收藏點的毫秒時間。

18. Srts 欄位格式說明

了解格式有助於手動修改或生成卡片。Srts_00 到 Srts_10 都是純文字欄位，每行一條字幕。

18.1 行格式

時間資訊\t原文\t譯文
  • 時間資訊：逗號分隔，格式為 前綴,季,集,媒體源,開始時間-結束時間
  • 原文：可帶標記前綴 [s]、[n]、[a] 等
  • 譯文：可為空

18.2 時間資訊詳解

以 ddm,,053,sf_s05e08,-251093-251873 為例：

部分值含義
前綴ddm時間線欄位前綴
季（空）未指定季
集053第 53 單元
媒體源sf_s05e08媒體檔案名（可選）
時間範圍-251093-251873從 251093ms 到 251873ms

18.3 單元判定

每條字幕的「集」欄位決定它屬於哪個單元。程式在載入單元時，只把集欄位匹配的字幕挑出來顯示。

18.4 頻道判定

Srts_00 是所有頻道的公共索引。Srts_01 到 Srts_10 各自獨立，可以是同一集的不同語言版本，也可以是不同集。

19. 常見問題

Q1：卡片開啟後一片黑，什麼都沒有
檢查：
  • 卡片是否有 Srts_01 欄位內容
  • 卡片 ID 是否能被 document.getElementById("fld-srts-01") 找到
  • 瀏覽器控制台是否有 JavaScript 錯誤
Q2：影片不播放
檢查：
  • Media 欄位是否填寫了副檔名
  • 媒體檔案是否放在 Anki 的 collection.media 目錄下
  • Windows 版本只支援 .webm，其他平台只支援 .mp4
Q3：選項面板打不開
檢查按鈕面板是否被拖出螢幕。重新整理卡片重新開啟。
Q4：選項不能儲存
檢查：
  • 桌面版是否安裝了 Anki 外掛 1020366288
  • iPhone 是否允許 localStorage（隱私模式下會禁用）
  • 卡片 Tags 欄位是否被其他模板占用了
Q5：收藏遺失
收藏按頻道和單元分別儲存。切換到其他單元時看不到目前單元的收藏。清理瀏覽器快取會遺失 localStorage 裡的收藏。
Q6：閃播速度清單只有兩個
閃播至少需要 2 個速度。如果設定裡少於 2 個，會自動回退到預設的 1.25 / 1.75。
Q7：噪音無法播放
確認卡片模板目錄下有 u_noise_1.mp3 到 u_noise_3.mp3，並且已加入 Anki 媒體庫。
Q8：錄音按鈕無反應
  • Windows 桌面版不支援錄音
  • 其他平台需要授權麥克風權限
  • HTTPS 環境下才能使用錄音 API
Q9：長按沒反應
長按需要持續 1.5 秒。如果手指稍微移動，會被識別為拖動而不是長按。可以嘗試用滑鼠（桌面版）或更穩定的手指按壓。
Q10：字幕顯示不全或錯位
  • 檢查 Srts 欄位每行是否用 Tab 分隔（不是空格）
  • 檢查時間資訊的逗號數量是否正確
  • 檢查字幕是否包含異常字元
Q11：跟讀時影片被靜音但沒有「該你念」的提示
檢查「角色字幕」選項是否設為「隱藏」。此模式下扮演行會顯示為帶邊框的方塊，是提示而非內容。
Q12：切換到其他單元後播放位置沒有重置
這是設計行為。切換單元時若指定了「從頭播放」，位置會重置。否則會記住上次的位置。
Q13：顯隱譯文長按後整個螢幕亂了
長按顯隱譯文會對螢幕頂部到當前行之間的所有行切換。若不希望這樣，短按即可，只切換當前行。
Q14：按鈕面板突然變成一行
說明卡片被識別為無媒體卡片（Media 欄位為 NaN，或影片檔案缺失）。檢查 Media 欄位和媒體檔案。
