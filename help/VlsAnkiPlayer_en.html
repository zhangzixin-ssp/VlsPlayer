1. What This Is

This is a special Anki card that packs the subtitle data of an entire season or unit into a single card. During review you don't need to flip through cards episode by episode—within one card you can:

  • Watch the video with synchronized subtitles
  • Shadow sentence by sentence, do intensive listening, or take dictation
  • Role-play: you read one role while the player reads the other
  • Flash play: speed through a whole passage at varying speeds
  • Mark favorite sentences for focused review later
  • Record yourself for comparison

It is not the same as the desktop VlsPlayer. VlsPlayer is a Windows application; this card template is JavaScript running inside Anki. Both share the same subtitle file format and subtitle toolbox.

1.1 Key Features

  • Black background with yellow buttons, designed for long video study sessions
  • Button panel is draggable, dockable to top/bottom, and collapsible to two rows
  • All settings are saved in card fields or, on iOS, in localStorage
  • Supports desktop, iPhone, iPad, Android, and macOS
  • On Windows, Anki add-on 1020366288 is required for the clipboard API

2. Card Fields and Creation

2.1 Card Fields

FieldPurpose
TitleSeries title, composed of three parts: main title, season/chapter, episode/unit
MediaMedia extension + poster (optional), separated by |
OptionsOptions string (desktop Anki only, see Section 17)
Srts_00Index/overview track, no subtitles, only records the number of units
Srts_01 to Srts_10Up to 10 channels; each channel holds multiple languages or seasons of the same episode
TagsOptions are also stored here (in base62 encoding)

2.2 Source

Cards are generated by the desktop VlsPlayer's "Anki Player Text" export function, or by the SRT toolbox's Anki export function. Field contents are filled automatically; no manual writing is needed.

2.3 Loading Sequence

  1. The front of the card is displayed (the whole player is on the front)
  2. Title and Media are parsed
  3. Srts_01 through Srts_10 are scanned to build the channel list
  4. The unit number range is read from Srts_00
  5. Last-used options and playback position are loaded
  6. The last channel and unit are opened
  7. Playback starts automatically after 200 milliseconds

4. Button Panel

The button panel has three rows, can be collapsed to two rows, and can be dragged to the top or bottom of the window. All settings are saved in the card options and restored automatically the next time the card is opened.

4.1 Three-Row Layout

Three rows by default, left to right:

RowButtons
Row 1 － / ＋ Collapse/Expand   1.0 / 2.0 Speed toggle   ⏮ Previous sentence   ↺ Replay   ⏭ Next sentence   AB Play selection   🔍 Dictionary/AI
Row 2 M Playback mode   0.5 / 1.5 Speed toggle   ⬆AB Play from top visible line to current line   ▶ Play/Pause   ⬇AB Play from current line to bottom visible line   ⚡² Flash play from top   N Noise
Row 3 📊 Speed menu   ♡ Favorite toggle   ▶🎤 Play recording   🎤 Record   🌐 Toggle translation   ⚡ Flash play   ⚙ Options

4.2 Two-Row Layout

If "Two-row buttons" is selected in options, the layout becomes two rows with larger, easier-to-tap buttons. Good for portrait phone screens.

4.3 Media-Less Cards

When the card has only audio, or the media file is missing, the button panel shrinks to a single row keeping only:

  • Return to deck
  • Favorite toggle
  • Dictionary/AI
  • Toggle translation
  • Options

4.4 Dragging the Panel

Long-press any button on the panel (except previous/next sentence) for 1.5 seconds to enter drag mode. You can:

  • Drag to the bottom of the window → docks to the bottom
  • Drag to the top of the window → docks to the top (buttons flip vertically)
  • Drag to the middle → floats

4.5 Collapse/Expand

Click － or ＋ to switch between three and two rows. When expanded, the "Replay" button becomes a "Play" button.

5. Single-Sentence Mode and Timeline

In single-sentence mode, a timeline appears above the button panel showing the adjustable playback range of the current sentence.

5.1 Timeline Elements

ElementColorMeaning
Two yellow dotsYellowOriginal playback interval
Two gray handlesGrayCurrent adjustable start/end times
White handleWhitePlayback position indicator
Short vertical lines at both endsDark yellowTimeline border decoration
◁ ▷ buttonsYellowFine-tune start/end times by 0.5 seconds each

5.2 Adjusting Start/End Times

  • Drag the left gray handle to adjust the start time
  • Drag the right gray handle to adjust the end time
  • Click ◁ to move the start time back 0.5 seconds
  • Click ▷ to move the end time forward 0.5 seconds

Changes take effect immediately; the next playback starts from the new position.

5.3 Combined with the "Extend Timeline" Option

The "Extend timeline" option in milliseconds extends each subtitle's start and end times slightly to both sides, avoiding clipped audio from tight subtitle boundaries. The extension never exceeds half the gap to the adjacent subtitle.

6. Playback Modes

Click the M button to open the mode menu. The current mode letter is shown on the button.

6.1 Five Modes

ButtonModeBehavior
MNormal modePlays the whole passage in order, auto-scrolling subtitles
MsSingle-sentence modePlays sentence by sentence; each sentence is handled per the repeat settings
MoRole-play odd linesOdd lines (srt1) are muted; you read them
MeRole-play even linesEven lines (srt2) are muted; you read them
MaRole-play all linesAll lines muted; you read them

6.2 Effects of Switching Modes

  • Switching between Normal/Single-sentence and Role-play modes reloads the current unit
  • In other cases only the current line is re-selected, without reloading
  • The timeline is visible in single-sentence mode and hidden in other modes

7. Loop Mode and Channels/Units

7.1 Channels and Units

  • A card can contain up to 10 channels (corresponding to Srts_01 through Srts_10)
  • Each channel has multiple units (corresponding to episodes or chapters)
  • The currently playing unit is shown at the top of the subtitle area

7.2 Switching Channels/Units

At the bottom of the options panel are the channel and unit selectors:

  • Left: channel list (hidden automatically if there is only one channel)
  • Right: unit grid; click to switch

After switching, the player jumps to that unit and plays from the beginning.

7.3 Loop Modes

Determines behavior when playback reaches the end of a unit:

ModeBehavior
Current unitReturns to the start of this unit when finished
Current channelJumps to the next unit when finished; at the end of the channel returns to the start of this channel
All contentPlays continuously across channels; at the end returns to the first channel

Select the loop mode in the options panel.

8. Shadowing and Role-Play

8.1 Role Determination

A subtitle's role is inferred from inline markers:

MarkerRole
[n]Narration (not role-played)
[t]Lyrics / fansub group (not role-played)
[g]Other (not role-played)
[a]Continues the previous line's role
[s]New scene begins
[p]Paragraph separator
No markerAlternates srt1 / srt2

8.2 Role-Play Flow

After choosing a role-play mode (odd/even/all), during playback:

  1. When playback reaches a line you should read → it pauses automatically and mutes → the line is highlighted with speaking
  2. After you finish reading, click play again → playback continues from the end of that line
  3. If "Replay original audio after role-play" is enabled in options, it rewinds to the start of the line and plays the original audio
  4. After the original audio finishes, it continues to the next sentence

8.3 Skipping Silent Gaps

The "Skip silent gaps during role-play" option: when the silence between two sentences exceeds the set number of seconds, it is skipped automatically. For example, if set to 5 seconds, any gap longer than 5 seconds is skipped, saving time.

8.4 Role Subtitle Display

The "Role subtitle" option determines how role-play lines are highlighted:

OptionEffect
DefaultThe whole role-play line is highlighted
TranslationShows the translation, hides the original text
HiddenEach word is boxed; the actual content is hidden

"Hidden" mode is good for dictation practice: you can see sentence length and word breaks but not the actual words.

9. Flash Play

Flash play is a variable-speed fast playback of a whole passage, used to quickly run through content you already know.

9.1 Two Kinds of Flash Play

ButtonBehavior
⚡Starts from the current sentence, plays block by block at varying speeds
⚡²Starts from the top visible line, plays block by block at varying speeds

9.2 Blocking Mechanism

  • Subtitles are split into blocks of "at least N seconds each" (N is set by "Minimum flash-play block length")
  • Each block is played at a different speed (the speed list is set by "Flash-play speeds")
  • There is an interval between blocks (set by "Multi-line repeat interval")

9.3 Flash-Play Speed List

Supports up to 6 speeds, each between 1.00x and 3.00x. Default is 4: 1.25x, 2.00x, 2.25x, 2.50x.

Quick templates are also available:

  • A: block 10 s, speeds 1.25x / 1.75x
  • B: block 20 s, speeds 1.25x / 1.75x / 2.00x
  • C: block 30 s, speeds 1.25x / 1.75x / 2.00x / 2.00x

9.4 End Condition

After flash play reaches the last speed, it returns to the block start and begins a new round, until stopped manually.

10. Repeat Playback and Intervals

10.1 Repeat Count

In single-sentence mode, the number of times each sentence is repeated:

  • 1 to 9: fixed number of times
  • 10: infinite loop until stopped manually

10.2 Single-Sentence Interval

The interval between repeats of a single sentence:

ValueMeaning
1 to 30Fixed number of seconds
31Duration of this sentence (pause briefly after reading)
32Duration of the next sentence
33Stop playback (waits for the user to click play)

10.3 Multi-Line Interval

When a passage has multiple consecutive sentences (for example, you chose to play from the top visible line to the current line), the interval between passages, in seconds, range 1 to 30.

10.4 Typical Configurations

ScenarioRepeat countSingle-sentence intervalMulti-line interval
Sentence-by-sentence shadowing1Duration of this sentence—
Intensive listening to new contentInfiniteStop3 s
Quick run-through11 s1 s

11. Favorites

11.1 Adding Favorites

Each subtitle line has a heart icon on the right; click to toggle:

  • Empty ♡ → filled ♥: adds the sentence to favorites
  • Filled ♥ → empty ♡: removes it from favorites

A favorite stores the midpoint time of that sentence, so even if the subtitle content changes, the favorite remains valid as long as the time stays in the same interval.

11.2 Favorites Only

Click the ♡ button to switch to ♥ and show only favorited subtitles. Click again to restore all.

11.3 Favorite Scope

Favorites are saved separately per channel and unit. When switching to another unit, only that unit's favorites are shown.

11.4 Storage

  • iPhone/iPad: stored in localStorage, keyed by card ID + channel + unit
  • Android: same as above
  • Desktop: uses an Anki add-on to write into card fields

Four fonts can be switched in options: Default, Verdana, Helvetica, Times New Roman.

Four levels: Default (18 px), Slightly larger (19.5 px), Larger (21 px), Largest (22.5 px).

13. Recording and Noise

13.1 Recording

Click the 🎤 button to start recording:

  • Requires browser microphone permission
  • The icon changes to a stop-recording icon while recording
  • After clicking stop, playback starts automatically
  • Maximum recording length is 5 minutes
  • Only the most recent recording is kept; recording again overwrites it

The recording is kept in memory and not written to disk. It is cleared automatically when switching to the next card.

13.2 Playing the Recording

Click the ▶🎤 button to play back the last recording. Click again to stop playback.

13.3 Noise

Click the N button to cycle through:

ValueBehavior
NNo noise
N1 / N2 / N3Mixes in one of three different noise sources

Noise plays and pauses in sync with the video. When noise is on, the video volume automatically drops to 50%, and the noise starts from a random position and loops.

Noise files come from u_noise_1.mp3, u_noise_2.mp3, u_noise_3.mp3 in the card template directory.

17. Options Persistence

Options need to be saved and restored the next time the card is opened. Different platforms use different storage methods:

17.1 Desktop

Writes the options string into the card fields Options or Tags. Requires Anki add-on 1020366288.

17.2 iPhone / iPad

Stored in the browser's localStorage, with a key name of the form cardID_series_opts_6.

17.3 Android

Same as iPhone; stored in localStorage.

17.4 Encoding

The options string is compressed with base62 encoding and stored with a as the field separator. For example:

Field order: language / button color / button height / button rows /
playback mode / loop mode / subtitle language / subtitle position /
role subtitle / subtitle font / font size / replay after role-play /
favorites only / video height / playback speed / extend timeline /
skip gap duration / single-sentence count / single-sentence interval / multi-line interval /
flash-play duration / flash-play speed list / channel / unit / playback position

17.5 Favorites Stored Separately

Favorite data is not in the options string; it is stored separately. Key name format: cardID_channel_unit. The value is a concatenation of 7-digit numbers, each representing the millisecond time of a favorite point.

18. Srts Field Format

Understanding the format helps when manually editing or generating cards. Srts_00 through Srts_10 are plain-text fields, one subtitle per line.

18.1 Line Format

time info\toriginal text\ttranslation
  • Time info: comma-separated, format prefix,season,episode,media source,start-end
  • Original text: may carry a marker prefix such as [s], [n], [a], etc.
  • Translation: may be empty

18.2 Time Info in Detail

Taking ddm,,053,sf_s05e08,-251093-251873 as an example:

PartValueMeaning
PrefixddmTimeline field prefix
Season(empty)No season specified
Episode053Unit 53
Media sourcesf_s05e08Media file name (optional)
Time range-251093-251873From 251093 ms to 251873 ms

18.3 Unit Determination

The "episode" field of each subtitle determines which unit it belongs to. When loading a unit, the program picks out only the subtitles whose episode field matches.

18.4 Channel Determination

Srts_00 is the common index for all channels. Srts_01 through Srts_10 are independent; they may be different language versions of the same episode, or different episodes.

19. FAQ

Q1: The card opens completely black with nothing there
Check:
  • Whether the card has Srts_01 field content
  • Whether the card ID can be found by document.getElementById("fld-srts-01")
  • Whether there are JavaScript errors in the browser console
Q2: The video does not play
Check:
  • Whether the Media field includes a file extension
  • Whether the media file is in Anki's collection.media directory
  • Windows only supports .webm; other platforms only support .mp4
Q3: The options panel won't open
Check whether the button panel has been dragged off-screen. Refresh the card and reopen it.
Q4: Options are not saved
Check:
  • Whether Anki add-on 1020366288 is installed on desktop
  • Whether the iPhone allows localStorage (disabled in private mode)
  • Whether the card's Tags field is occupied by another template
Q5: Favorites are lost
Favorites are saved separately per channel and unit. When switching to another unit, the current unit's favorites are not visible. Clearing the browser cache loses favorites stored in localStorage.
Q6: The flash-play speed list has only two entries
Flash play requires at least 2 speeds. If fewer than 2 are set, it falls back to the default 1.25 / 1.75.
Q7: Noise won't play
Confirm that u_noise_1.mp3 through u_noise_3.mp3 are in the card template directory and have been added to the Anki media library.
Q8: The record button does nothing
  • Windows desktop does not support recording
  • Other platforms require microphone permission
  • The recording API requires an HTTPS environment
Q9: Long press does nothing
A long press must last 1.5 seconds. If your finger moves slightly it will be recognized as a drag instead. Try a mouse (on desktop) or a steadier finger press.
Q10: Subtitles are incomplete or misaligned
  • Check whether each line of the Srts field is separated by Tab (not space)
  • Check whether the number of commas in the time info is correct
  • Check whether the subtitles contain abnormal characters
Q11: During shadowing the video is muted but there is no "your turn" prompt
Check whether the "Role subtitle" option is set to "Hidden". In this mode role-play lines are shown as bordered blocks—that is the prompt, not the content.
Q12: After switching to another unit, the playback position is not reset
This is by design. When switching units, if "play from beginning" is specified, the position is reset. Otherwise the last position is remembered.
Q13: After a long press on toggle-translation the whole screen is a mess
A long press on toggle-translation applies show/hide to all lines from the top visible line to the current line. If you don't want this, short-press instead; it toggles only the current line.
Q14: The button panel suddenly becomes a single row
This means the card has been recognized as a media-less card (Media field is NaN, or the video file is missing). Check the Media field and the media file.
